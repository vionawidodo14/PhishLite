<p>It certainly is a version with more features and updated you can find. Includes everything you can expect (score to sing, party mode, easily add new songs, etc) with a lot of improvements and new features.</p>
</div>

<p>You can find all the information on the <a href="/en/descargas/ultrastar-deluxe-worldparty">UltraStar Deluxe WorldParty</a> section.</p>
