<h2>ABOUT <br/></h2><h4 class="responsive-design-title">RESPONSIVE DESIGN</h4>
<p>Internet use is no longer limited to desktop devices of yesteryear. Rather users access the internet from their home, their tablets, and their phones. Responsive design gives your website the flexibility to attractively display content regardless of device size.</p>
<h3>So, What Exactly Is a Responsive Design?</h3>
<p><a href="https://mediag.com/blog/responsive-design-checker-by-media-genesis-is-your-site-responsive/" target="_blank">Responsive design</a> simply refers to a website layout that responds (scales itself) automatically to an array of devices (screen sizes) and  <a href="https://mediag.com/blog/popular-screen-resolutions-designing-for-all/" target="_blank">resolutions</a>. Basically, it’s mobile and tablet friendly.<br/>
<br/>
           That way, whether you’re using a personal laptop, a notebook computer, or you phone, you can access the same website on all of them without losing quality. The idea of responsive design is that the same website will look great while you’re browsing the web on your phone and on your computer without sacrificing any of the quality or ease of navigation.<br/>
<br/>
	    		 It’s important to stay up-to-date with the most popular screen sizes and resolutions when designing web and mobile sites. Learn more in our <a href="https://mediag.com/blog/popular-screen-resolutions-designing-for-all/" target="_BLANK">blog article here</a>.
	    		 </p>
</div>
</div>
</section>

<div class="wrap-thumbnails">
<h4>Responsive Design: What to Expect</h4>
<div class="column3">
<img alt="" src="images/illustration-01.jpg"/>
<h3 class="rd-box-title">Start with the End in Mind</h3>
<p>Designers and developers work together to wireframe, or outline, the website. This <a href="https://mediag.com/blog/what-to-consider-before-designing-a-website/" target="_BLANK">phase</a> must consider user experience (UX), interaction with site elements, and results in a basic design concept.  </p>
</div>
<div class="column3">
<img alt="" src="images/illustration-02.jpg"/>
<h3 class="rd-box-title">Create Complimentary Layouts</h3>
<p>With basic elements determined, designers craft designs for various screen sizes while maintaining brand integrity, layout and user experience consistency. As screen sizes decrease, elements often stack, scale or collapse into expandable sections.</p>
</div>
<div class="column3">
<img alt="" src="images/illustration-03.jpg"/>
<h3 class="rd-box-title">Expect Some Shifts</h3>
<p>Everything from image and font sizes to <a href="https://mediag.com/blog/navigation-in-2018-whats-the-right-direction/" target="_BLANK">navigation</a> structure may need to change between screen sizes to ensure a quality user experience.</p>
</div>
<div class="column3">
<img alt="" src="images/illustration-04.jpg"/>
<h3 class="rd-box-title">Programming Magic</h3>
<p><a href="https://mediag.com/blog/understanding-websites-a-developers-perspective/" target="_BLANK">Developers</a> use the design parameters to write the website code. Media queries are included to validate the size of the user’s screen and to then display the appropriate layout.</p>
</div>
<div class="column3">
<img alt="" src="images/illustration-05.jpg"/>
<h3 class="rd-box-title">Evolution</h3>
<p>Today’s <a href="https://mediag.com/blog/top-10-reasons-your-website-needs-a-redesign/" target="_BLANK">web development</a> is not about one-size fits all solutions.  It’s about taking advantage of the opportunities presented by new technologies and using them to craft meaningful and effective user experience. </p>
</div>
<div class="column3">
<img alt="" src="images/illustration-06.jpg"/>
<h3 class="rd-box-title">Responsive Check-ups</h3>
<p>With technology constantly changing and evolving, it is important to <a href="https://mediag.com/blog/is-your-website-responsive-why-mobile-friendly-sites-are-important-and-how-to-check-if-your-site-meets-the-standard/" target="_BLANK">check-up on your responsive design</a> at least quarterly. This gives you an opportunity to identify if there are any responsive issues with your website and make any necessary updates.  </p>
</div>

<h2>ABOUT <br/></h2><h4 class="responsive-design-title">MEDIA GENESIS</h4>

<p>Responsive Design Checker was initially created in 2012 as an exercise for Media Genesis developers to see if they could create a tool that could be used to test websites for mobile design. Essentially, developers wanted to see how well certain websites could adapt when viewed on mobile device (like a phone) rather than just on a computer desktop.<br/>
<br/>
					 	As it turned out, it was a smash hit! But not necessarily with developers. Responsive Design Checker was appreciated more by non-development web users as it was able to determine if a website would be responsive while in mobile format.<br/>
<br/>
					 	Later updates to the system were made in 2015 in order to include a variety of preset screen sizes such as the 27-inch Dell Monitor U2711, 17-inch Workstation, 15-inch Macbook Pro, 11-inch Macbook Air, and the portrait and landscape modes of Apple’s iPad and iPhone, and the Nexus7.</p>

<br/>
					 	Not to mention, mobile usage counts for just about 50% of all website traffic, so it’s essential that your site is able to not only meet user demands but also adapt to any device screen.<br/>
<br/>
					 	That’s where Responsive Design Checker comes in. You can discover how your website looks on a variety of different screens, including desktops, laptops, tablets, and smartphones. It’s as simple as typing in your web domain and hitting “enter.”</p>

function validate_url()
{
	//Get the URL
	var url =  jQuery("#url").val();
	var submit_form = true;
	//If URL is Blank
	if (url.trim() == "")
	{
		//Change CSS of URL Box
		jQuery("#blank_url").css('color','#000000');

		jQuery("#blank_url").show().html("<p>Please enter a valid URL below</p>").addClass('url-validation');
		//Add a Message Somewhere

		submit_form = false;
	}

	return submit_form;
}
