<div class="page-title"><h2>Мотоциклы и квадроциклы из Японии и Америки. Магазин мотоэкипировки и мотозапчастей.</h2></div>
<div class="cms-home">
<h3>ПРОДАЖА МОТОЦИКЛОВ И КВАДРОЦИКЛОВ. Отправка в любой регион России.</h3>
<p align="justify">Наша специализация - это продажа мотоциклов б/у и подержанных квадроциклов из Японии и Америки. Все мотоциклы, продажа которых осуществляется непосредственно из наличия в Москве, прошли предпродажную подготовку и не имеют неисправностей. Продажа мотоциклов производится как из наличия в Москве, так и на этапе отправки с нашего склада в Америке или на этапе транспортировки. Чтобы ознакомиться с нашим ассортиментом, пожалуйста, выберите интересующий вас раздел в строке навигации выше. Для мото и квадро это будут соответственно <a _title="Мотоциклы" href="motocikly">"Мотоциклы"</a> и <a _title="Квадроциклы" href="atv-kvadrocikly">"Квадроциклы"</a>, а остальные разделы - это интернет-магазин и ассортимент наших магазинов экипировки и запчастей.
</p>
</div>
<div class="divider dotted-hr-line"></div>
<div class="cms-home">
<h3>Интернет-магазин Мотозапчастей и Мотоэкипировки. ДОСТАВКА ПО РОССИИ.</h3>
<p align="justify">Мы предлагаем отличный выбор самых необходимых запчастей, мотоэкипировки и аксессуаров из наличия. Мы не поставляем запчасти под заказ, так как теперь значительный ассортимент запчастей находится у нас на складе в Москве. «Неоригинал» (аналоги особо востребованных оригинальных запчастей) для мототехники практически любой известной марки, как правило, есть у нас в наличии.
</p>
<p align="justify">Мотоэкипировка представлена такими марками как мотошлемы Scorpion EXO, мотокуртки Furygan, недорогие мотокуртки RUSH, чопперные куртки River Road, защита Thor и Axo, - и масса других товаров. На все заказы запчастей и экипировки через интернет распространяется действие бонусной программы DRIVE-бонус.
</p>
</div>
<div class="divider dotted-hr-line"></div>
<div class="cms-home">
<h3>ОПТОВЫЕ ПРОДАЖИ: Мотоциклы, Квадроциклы, Запчасти и Экипировка</h3>
<p align="justify">
У нас есть отличные предложения для мотобизнесменов - <a href="wholesale" title="мотоциклы б/у оптом">мотоциклы б/у оптом</a> и <a href="wholesaleparts" title="мотозапчасти оптом, мотоэкипировка">оптовая продажа мотоэкипировки, мотозапчастей</a>, и аксессуаров. Мы предлагаем различные схемы работы для оптовиков в зависимости от потребностей и возможностей наших партнеров. Любой регулярно совершающий закупки покупатель независимо от объема - для нас оптовый покупатель. Мы предлагаем уникальные условия работы, которые вам гарантировано понравятся!<br/>
В ассортименте мотосалона вы всегда найдёте мотоциклы Honda, Kawasaki, Suzuki и Yamaha, квадроциклы Polaris, Honda, Yamaha, Kawasaki, Suzuki, а также огромный выбор запчастей, тюнинга и экипировки.
</p>
</div>
<div class="divider dotted-hr-line"></div>
<div class="cms-home">
<h3>КВАДРОЦИКЛЫ. Утилитарные и Спортивные.</h3>
<p align="justify">ДрайвБайк начал заниматься продажей квадроциклов еще в 2008 году, когда мы открыли очередное направление деятельности компании - <a href="atv-kvadrocikly" title="продажа квадроциклов">продажа квадроциклов</a> б/у из Америки. Мы по-прежнему поставляем американские, канадские и японские подержанные квадроциклы б/у различных марок и моделей. Представлены как утилитарные, так и спортивные модели.<br/>
Разумеется, мы занимаемся и обслуживанием квадроциклов и поставляем запчасти к ним.
</p>
</div>
<div class="divider dotted-hr-line"></div>
<div class="cms-home">
<div class="col-lg-6 col-md-6 col-sm-6 col-xs-12">
<h4>МОТОЦИКЛЫ ПОД ЗАКАЗ</h4>
<p align="justify">Продажа мотоциклов по большей части осуществляется из уже закупленного нами ассортимента. Но если вы не нашли подходящего мотоцикла у нас в продаже, мы можем выполнить ваш <a href="bikerequest" title="заказ мотоцикла из Америки">заказ мотоцикла из Америки</a> с любого из мотоаукционов, с которыми мы работаем. Мы также выкупаем мототехнику непосредственно у частных лиц в США в шататх Флорида и Джорджия, и при этом имеем возможность проверить ее состояние и предоставить вам фотоотчет сразу после покупки. Это позволяет приобрести любую мототехнику по вашим требованиям и получить ее в РФ разумные сроки и с гарантией состояния.
</p>
<p>Мототехнику следующих производителей мы поставляем преимущественно под заказ:</p>
<ul style="padding-left: 20px; list-style-type:square;">
<li>Harley Davidson</li>
<li>Buell</li>
<li>Victory Motorcycles</li>
<li>Aprilia</li>
<li>Ducati</li>
<li>Triumph</li>
</ul>
<p> </p>
</div>
<div class="col-lg-6 col-md-6 col-sm-6 col-xs-12">
<h4>МОТОСЕРВИС. Ремонт и обслуживание мотоциклов.</h4>
<p align="justify">Наш мотосервис производит качественный ремонт мототехники любой сложности - от установки мотосигнализаций до ремонта двигателей. Мотосервис «Драйвбайк» проводит регулярное техобслуживание мотоциклов, восстановление техники после аварий, ремонт вышедших из строя агрегатов и узлов.<br/>
<strong>МЫ УСТАНАВЛИВАЕМ ВСЕ, ЧТО ПРОДАЕМ</strong>.
</p>

    Product.Options.prototype = {
        initialize : function(config){
            this.config = config;
            this.reloadPrice();
        },
        reloadPrice : function(){
            price = new Number();
            config = this.config;
            skipIds = [];
            $$('.product-custom-option').each(function(element){
                var optionId = 0;
                element.name.sub(/[0-9]+/, function(match){
                    optionId = match[0];
                });
                if (this.config[optionId]) {
                    if (element.type == 'checkbox' || element.type == 'radio') {
                        if (element.checked) {
                            if (config[optionId][element.getValue()]) {
                                price += parseFloat(config[optionId][element.getValue()]);
                            }
                        }
                    } else if(element.hasClassName('datetime-picker') && !skipIds.include(optionId)) {
                        dateSelected = true;
                        $$('.product-custom-option[id^="options_' + optionId + '"]').each(function(dt){
                            if (dt.getValue() == '') {
                                dateSelected = false;
                            }
                        });
                        if (dateSelected) {
                            price += parseFloat(this.config[optionId]);
                            skipIds[optionId] = optionId;
                        }
                    } else if(element.type == 'select-one' || element.type == 'select-multiple') {
                        if (element.options) {
                            $A(element.options).each(function(selectOption){
                                if (selectOption.selected) {
                                    if (this.config[optionId][selectOption.value]) {
                                        price += parseFloat(this.config[optionId][selectOption.value]);
                                    }
                                }
                            });
                        }
                    } else {
                        if (element.getValue().strip() != '') {
                            price += parseFloat(this.config[optionId]);
                        }
                    }
                }
            });
            try {
                optionsPrice.changePrice('options', price);
                optionsPrice.reload();
            } catch (e) {

            }
        }
    }
