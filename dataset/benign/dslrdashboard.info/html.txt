<div class="entry-meta">
<span class="entry-date"><a href="https://dslrdashboard.info/qdslrdashboard-v3-5-9-and-controlmycamera-v1-0-2/" rel="bookmark"><time class="entry-date" datetime="2019-06-19T11:16:53+02:00">2019-06-19</time></a></span> <span class="byline"><span class="author vcard"><a class="url fn n" href="https://dslrdashboard.info/author/hubaiz_u9py079x/" rel="author">hubaiz_u9py079x</a></span></span> </div><!-- .entry-meta -->

<div class="entry-content">
<p>

Released qDslrDashboard V3.5.9 and ControlMyCamera 1.0.2 today</p>
<p>most notable changes:<br/>– ability to capture in RAW format and have quick image review using the camera JPG preview image. Only works with the ‘quick image review’ option. Only works with Nikon cameras<br/>– ability to capture in RAW format in LRTimelapse screen and have the camera JPG preview image used for analysis and display. You can enable this in settings with the ‘Allow RAW only in LRTimelapse-mode (Nikon) option. This only works with Nikon cameras.<br/>– added a master/slave option if 2 or more cameras are connected.
