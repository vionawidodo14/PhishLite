<h1><a href="https://jeka.by/post/1102/KnpMenu-symfony4-categories-and-subcategories/">KnpMenuBundle: строим меню для категорий и подкатегорий в symfony 4</a></h1>
<div class="content">
<p>
	Меню-билдер в лучших традициях симфони лучше объявить как сервис.</p>
<p>
	Создаем сервис "объявим сервис app.knp.sidebar_menu в файле config/packages/knp_menu.yaml:</p>
<p>
	Содержимое config/packages/knp_menu.yaml:</p>
<pre class="brush:bash;">knp_menu:
    twig:
        template: custom_knp_menu.html.twig

parameters:
    knp_menu.renderer.twig.options:
        currentClass: sel

services:
    app.knp.sidebar_menu:
        class: Knp\Menu\MenuItem
        factory: ['@App\Menu\MenuBuilder', createSidebarMenu]
        arguments: ["@request_stack"]
        tags:
            - { name: knp_menu.menu, alias: sidebar_menu }
</pre>
<p>

<h1><a href="https://jeka.by/post/1100/mysql-analyze-performance-schema/">Анализ производительности MySQL с использованием performance_schema</a></h1>
<div class="content">
<p>
	performance_schema — мощный встроенный в MySQL инструмент, который вы можете использовать для анализа запросов, производительности и, как следствие, для улучшения производительности базы данных.</p>
<p>
	По своей сути, performance_schema, это автоматически созданная MySQL база данных, которая внутри себя содержит множество служебных таблиц, в которые MySQL любезно пишет данные.</p>

<h1><a href="https://jeka.by/post/1094/dao-vs-active-record-vs-data-mapper/">DAO vs Active Record vs Data Mapper паттерны при работе с базой данных</a></h1>
<div class="content">
<p>
	В популярных фреймворках для работы с базой данных, как правило, используется ORM, которая представляет собой вспомогательную прослойку между приложением и базой данных.</p>
<p>
	В зависимости от фреймворка, ORM может реализовывать паттерн Active Record (например, kohana framework) или Data Mapper (например, doctrine в symfony). ORM фреймворка также может реализовывать другой паттерн или гибрид.</p>
<p>
<strong>ORM</strong> <span style="font-family: sans-serif;">—</span> Object Relational Mapping. Говоря самым простым языком, ряды из таблиц в базе данных, будут представлены в виде объектов, проперти которых соответствуют именам полей из таблиц, а значения пропертей объекта - значениям из базы данных.</p>
</div>
