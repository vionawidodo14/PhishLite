<h2>Home</h2>
<div class="splitcontentleft">
<div class="wiki">
<p>The <strong>Osmocom</strong> project is an umbrella project regarding <strong>Open source mobile communications</strong>.  This includes software and tools implementing a variety of mobile communication standards, including GSM, DECT, TETRA and others.</p>


This website is the <em>redmine</em> project management system which we use for
	<ul>
<li>Wiki</li>
<li>Issues (bugs / features / roadmap)</li>
<li>News items</li>
</ul>
<p>Please select the project you're interested in from our <a href="/projects">List of Projects</a></p>
<p>The best starting point for 2G and 3G core network + BSS is the <a class="wiki-page" href="/projects/cellular-infrastructure/wiki">Cellular Network Infrastructure project's wiki</a>.</p>


Please also see the following other web sites which are <em>not</em> integrated into redmine:
	<ul>
<li>Our Mailing list server at <a class="external" href="https://lists.osmocom.org/">https://lists.osmocom.org/</a></li>
<li>Our git repositories with web interface at <a class="external" href="http://git.osmocom.org/">http://git.osmocom.org/</a></li>
<li>Our planet (blog aggregator) at <a class="external" href="http://planet.osmocom.org/">http://planet.osmocom.org/</a></li>
<li>Personal files of individual developers at <a class="external" href="http://people.osmocom.org/">http://people.osmocom.org/</a></li>
</ul>
