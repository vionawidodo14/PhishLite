<h2>Статьи и другие материалы по ремонту материнских плат</h2> <div class="content"><a id="Remont-MB"></a>
<b>Проблемы с материнской платой?</b> Тогда Вы попали<s>!</s> по адресу - <a href="http://www.rom.by/forum/Remont_materinskih_plat" title="Самый (без преувеличения) крупный в интернете (даже по сравнению с буржуйнетом) форум по ремонту материнских плат">форум по ремонту материнских плат</a>. У Вас есть уникальная возможность почитать просто огромное количество описаний самых изощрённых способов <s>убийства</s> восстановления своего железа. Профессиональные ремонтники и известные представители сервисных центров, признанные эксперты и просто грамотные специалисты - всегда смогут <s>забанить</s> поделиться своим опытом и <s>отправить читать факи</s> помочь советом.
Тысячи реальных ремонтов, <a title="Главная отличие ROM.by по сравнению с другими сайтами схожей тематики - наличие обширной отсортированной базы данных ремонтов">упорядоченных</a> по фирмам и моделям материнских плат, номерам посткодов, типам неисправностей и даже по элементной базе - <a title="Как минимум - морально...">помогут</a> каждому (грамотному) читателю отремонтировать или хотя бы найти причину проблем.
<ul>
<li>Вопросы вопрошать - на <a href="http://www.rom.by/forum/Remont_materinskih_plat" title="Форум по проблемам и ремонту материнских плат">форуме по ремонту материнских плат</a>.
</li>
</ul>
<b>Как починить материнскую плату?</b> Обычно - паяльником. Но часто хватает отвёртки и/или <a title="Ооооочень умного и задумчевого">пристального</a> взгляда. А иногда даже просто нужного количества обращений ко всевозможным родственникам данной <a title="По её же линии">матери</a>. Универсального способа (мануала) нет и не будет. Так как... В общем - нет.
Понимая эту грустную деталь ограниченности человеческого сознания, материалы на сайте разделены на несколько условных уровней (сложности/применимости/назначения) - для <i>начинающих</i>, <u>продолжающих</u> и <b>специалистов</b>.
<ul>
<li>Для тех, кто вздрагивает от слова "<a title="и пока ещё путает тестер с тостером">паяльник</a>" - <a href="http://www.rom.by/book/Rukovodstvo_po_remontu_materinskih_plat_0#1" title="Азбука по ремонту материнских плат">Азбука по ремонту материнских плат</a>, которая поможет разобраться, куда, собственно, тыкать т<s>о</s><span style="position: relative; left: -8px; top: -10px; font: bold; ">е</span><span style="position: relative; left: -10px;">стером, как выглядят беременные конденсаторы и чем их после заменить.</span>
</li>
<li>Для тех, кто с паяльником на "ты", уже не помнит, что <a title="Bosch GHG 660 LCD?">феном</a> <a title="Это - суровая правда!...">сушат</a> <a title="Факт!">волосы</a>, а от сайта <a href="" onfocus="this.href='ht' + 'tp://' + 'www.' + 'razvodka-mostov.ru';" onmousemove="this.href='ht' + 'tp://' + 'www.' + 'razvodka-mostov.ru';" target="_blank">www.razvodka-mostov.ru</a> просто впадает в ступор, не обнаружив там ни <a title="82801EB">Intel</a>, ни <a title="IXP460 218S4RBSA12G">AMD</a>, ни <a title="NF4 NF-SLI-A3">nVidia</a> - для всех таких могут подойти статьи, написанные <a title="LKA">автором</a> известного сайта <b>mamkaboard.narod.ru</b>, материалы которого перенесены на <b>www</b>.<b>ROM.by</b> (и продолжают редактироваться/дополняться). Имея хорошую сноровку плюс некоторую подготовку, а также в распоряжении пусть даже только лишь тестер с паяльником - с помощью "<a href="http://www.rom.by/book/Samouchitel_po_remontu_materinskih_plat" title="Самоучитель по ремонту материнских плат">Самоучителя по ремонту материнских плат</a>" они смогут починить (почти) любую неисправность и не только "забесплатно", но и "за деньги".
</li>
<li>Наконец, для тех, кто хочет обстоятельно разобраться, получить некоторую (или дополнительную) теоретическую подготовку, чтобы не только устранить проблему, но и детально понять причины её возникновения - читайте "<a href="http://www.rom.by/book/Samouchitel_po_remontu_materinskih_plat" title="Самоучитель по ремонту материнских плат">Пособие по ремонту материнских плат</a>".
</li>
</ul>
