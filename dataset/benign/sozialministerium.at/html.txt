<p><strong><a href="https://broschuerenservice.sozialministerium.at/Home/Search?Search.SearchTerm=publicationid:636" tabindex="0" target="_blank">Das österreichische Gesundheitssystem</a></strong><br/>Das wichtigste Prinzip der österreichischen Gesundheitspolitik ist, für alle Einwohnerinnen und  Einwohner – unabhängig von Alter, Geschlecht, Herkunft, sozialem Status oder Einkommen – den gleichen, zielgruppengerechten und barrierefreien Zugang zu hochwertiger Gesundheitsversorgung zu sichern.</p>
</div><div aria-hidden="true" class="tab-pane fade slick-slide" data-slick-index="1" role="option" style="width: 858px; position: relative; left: -858px; top: 0px; z-index: 998; opacity: 0;" tabindex="-1">
<p><strong><a href="/cms/site/attachments/9/1/5/CH3434/CMS1533893861892/sozialstaatoesterreich_web_neu2.pdf" tabindex="-1" target="_blank">Sozialstaat Österreich 2018</a></strong><br/>Die vorliegende Publikation stellt eine Zusammenschau über das österreichische 
Sozialsystem dar. Im Zentrum stehen die Sozialausgaben, die Sozialleistungen 
sowie deren Finanzierung. In den einzelnen Kapiteln werden die wesentlichen Sozialleistungen vorgestellt. Zahlreiche Hinweise auf weiterführende Websites und Servicestellen erleichtern eine Recherche bzw. Vertiefung des jeweiligen Themas.
Da Daten und Werte sich in regelmäßigen Abständen ändern und die Publikation dennoch ein möglichst aktuelles Bild des Sozialstaats geben sollte, ersuchen wir Sie, die jeweiligen Hinweise in den Boxen auf weiterführende Websites zu nutzen. Auf diesen finden Sie die jeweils aktuellen Daten bzw. den aktuellen gesetzlichen Stand bzw.aktuelle  Werte. Die vorliegende Publikation bildet den gesetzlichen Stand 1. Jänner 2018 ab.</p>
</div><div aria-hidden="true" class="tab-pane fade slick-slide" data-slick-index="2" role="option" style="width: 858px; position: relative; left: -1716px; top: 0px; z-index: 998; opacity: 0;" tabindex="-1">
<p><strong><a href="https://broschuerenservice.sozialministerium.at/Home/Search?Search.SearchTerm=publicationid:673" tabindex="-1" target="_blank">Österreichischer Pflegevorsorgebericht 2017</a></strong><br/>Dem Pflegesystem kommt ein hoher Stellenwert zu und es hat große Bedeutung  für die gesamte österreichische Bevölkerung. Deshalb sind Pflege und Betreuung älterer Menschen sowie die Situation der pflegenden Angehörigen auch eines der zentralen Themen in der österreichischen Sozialpolitik.

Mit der im Jahr 1993 abgeschlossenen Vereinbarung gemäß Art. 15a B-VG über gemeinsame Maßnahmen des Bundes und der Länder für pflegebedürftige Personen wurde auch ein Arbeitskreis für Pflegevorsorge eingerichtet, der zumindest einmal jährlich jeweils alternierend vom Bundesministerium für Arbeit, Soziales, Gesundheit und Konsumentenschutz und den Ländern einberufen wird.
Zu den Aufgaben des Arbeitskreises zählt auch die Erstellung eines gemeinsamen Jahresberichtes über die Pflegevorsorge. Der Umfang der Berichte wurde im Laufe der Jahre sukzessive erweitert und gliedert sich nunmehr in fünf Teile:
• im Allgemeinen Teil werden aktuelle Entwicklungen und neue Auswertungsergebnisse präsentiert,
• der Qualitätsteil gibt einen Überblick über qualitätssichernde Maßnahmen, die vom Bund und den Ländern durchgeführt werden,
• im Abschnitt „Demenz“ wird über die Umsetzung der Demenzstrategie und Demenzprojekte der Bundesländer berichtet,
• der Geldleistungsteil enthält zahlreiche Daten über Bezieherinnen und Bezieher von Pflegegeld und Pflegekarenzgeld sowie den finanziellen Aufwand
• der fünfte Teil „Soziale Dienstleistungen“ beinhaltet Auswertungen aus der Pflegedienstleistungsstatistik.</p>

<p><strong><a href="https://broschuerenservice.sozialministerium.at/Home/Search?Search.SearchTerm=publicationid:681" tabindex="-1" target="_blank">Arbeitsmarktpolitische Zielvorgaben</a></strong><br/>Zielvorgaben der Bundesministerin an das AMS zur Durchführung der Arbeitsmarktpolitik</p>
</div><div aria-hidden="true" class="tab-pane fade slick-slide" data-slick-index="4" role="option" style="width: 858px; position: relative; left: -3432px; top: 0px; z-index: 998; opacity: 0;" tabindex="-1">
<p><strong><a href="https://broschuerenservice.sozialministerium.at/Home/Search?Search.SearchTerm=publicationid:506" tabindex="-1" target="_blank">Impfplan Österreich 2019</a></strong><br/>Der Impfplan wurde in enger Zusammenarbeit zwischen dem Bundesministerium für Arbeit, Soziales, Gesundheit und Konsumentenschutz (BMASGK) mit Expertinnen und Experten des Nationalen Impfgremiums erarbeitet und aktualisiert. Ziel ist es, einen Überblick über derzeit zur Verfügung stehende Impfungen zu geben und für diese einheitliche, evidenzbasierte Empfehlungen auszusprechen.</p>
</div><div aria-hidden="true" class="tab-pane fade slick-slide" data-slick-index="5" role="option" style="width: 858px; position: relative; left: -4290px; top: 0px; z-index: 998; opacity: 0;" tabindex="-1">
<p><strong><a href="https://broschuerenservice.sozialministerium.at/Home/Search?Search.SearchTerm=publicationid:372" tabindex="-1" target="_blank">Sozialbericht Berichtszeitraum 2015 - 2016</a></strong><br/>Der Sozialbericht wird alle zwei Jahre vom Sozialministerium herausgegeben und dokumentiert in einem ersten Teil aktuelle sozialpolitische Entwicklungen und Maßnahmen in den Bereichen Arbeit und Beschäftigung, Soziales, Konsumentenpolitik sowie europäische und internationale Zusammenarbeit. Der aktuelle Bericht über den Zeitraum 2015 - 2016 enthält darüber hinaus eine Vielzahl weiterer sozialpolitischer Analysen.</p>
</div><div aria-hidden="true" class="tab-pane fade slick-slide" data-slick-index="6" role="option" style="width: 858px; position: relative; left: -5148px; top: 0px; z-index: 998; opacity: 0;" tabindex="-1">
<p><strong><a href="https://broschuerenservice.sozialministerium.at/Home/Search?Search.SearchTerm=publicationid:652" tabindex="-1" target="_blank">Grundlagen des österreichischen Pensionssystems</a></strong><br/>Das österreichische Sozialsystem ist eine Erfolgsgeschichte. Im internationalen Vergleich kann das österreichische Pensionssystem als ein umfassendes und auch leistungsstarkes System bezeichnet werden. In dieser Broschüre werden Grundbegriffe der gesetzlichen Pensionsversicherung verständlich erläutert.</p>

/**
 * Add link handler which uri encodes the query parameter to fix an 
 * Internet Explorer issue where IE sometimes uses the wrong encoding
 * for query parameters. This has the effect that special characters
 * like umlauts are sometimes sent as ISO-8859-1 and sometimes as UTF-8
 * depending if the link is openened in a new window/tab or the same window.
 * With this event handler internal links are URI-Encoded in the documents
 * charset (UTF-8) which is also the charset the server uses.
 */
$(document).on('click', 'a', function () {
    var elem = $(this)[0];
    // get and normalize the current hostname
    var currentHostname = window.location.hostname;
    // remove www
    if (currentHostname.indexOf('www') === 0) {
        currentHostname = currentHostname.substring(4);
    }
    // check if the hostname of the link matches the current hostname because we want to do 
    // this only for internal links. Also ignore link elements without search query parameters.
    if(elem.hostname.indexOf(currentHostname, elem.hostname.length - currentHostname.length) && elem.search && elem.search.length > 0) {
        var modified = false;
        var searchString = "?";
        // get the searchString without the "?" and split it into the parameter=value pairs
        elem.search.substring(1).split('&').forEach(function (paramValue, idx, arr) {
            // split the param=value pair into its components
            var components = paramValue.split('=');
            // check if a value exists and if it already contains url encoded characters
            if (components[1] && components[1].length > 0 && !components[1].match(/%[0-9A-Fa-f]{2,}/g)) {
                // if there are no url encoded characters in the value encode the value,
                // store it back to the searchString
                searchString += components[0] + '=' + encodeURIComponent(components[1]);
                // and set the modified flag
                modified = true;
            } else {
                // if this is a query param without value or the value is already encoded
                // add the param=value pair back to the searchString as it is
                searchString += paramValue;
            }
            // only add the ampersand if its not the last element in the array
            if (idx < arr.length - 1) {
                searchString += '&';
            }
        });
        // only write the searchString back to the element if it was modified
        if (modified) {
            elem.search = searchString;
        }
    }
});
