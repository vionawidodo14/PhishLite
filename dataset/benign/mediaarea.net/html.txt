<section id="intro">
<h1>MediaArea</h1>
<p>MediaArea is an open source software company focused on digital media analysis. We develop and support tools that aid developers in integrating digital media file investigation into their work.</p>
<p>We do mostly open source code, without rejecting proprietary code on request.</p>
<p><a href="/en/MediaInfo">MediaInfo</a> is our flagship product with 4 000 downloads per day, we also currently work on <a href="/MediaConch">MediaConch</a>, and we worked in the past on <a href="/QCTools">QCTools</a>, <a href="/BWFMetaEdit">BWF MetaEdit</a> and some other <a href="#projects">projects</a>.</p>
</section>

<section class="anchor" id="projects">
<h2>Our projects</h2>
<p>Different levels of involvement, from self-funding, self-management, and full development to external funding, external management, and partial development.</p>
<p>These projects are open source, you can participate too; additionnally, if you don't like what we do of these projects, just fork and offer a better version.</p>
<div class="col-xs-12 col-sm-6">
<div class="featureBox">
<header style="height: 132px;">
<h3><a href="/en/MediaInfo">MediaInfo</a></h3>
<span class="featureDescription">Convenient unified display of the most relevant technical and tag data for video and audio files.</span>
<span class="featureDescription">Designed, led and fully developed by MediaArea.</span>
</header>
<div class="featureInfos row">
<a class="btn btn-default" href="/en/MediaInfo">Learn more</a>
</div>
</div>
</div>
<div class="col-xs-12 col-sm-6">
<div class="featureBox">
<header>
<h3><a href="/MediaConch">MediaConch</a></h3>
<span class="featureDescription">Implementation checker, policy checker, &amp; reporter.</span>
<span class="featureDescription">Funded by the <a href="http://www.preforma-project.eu/" target="_blank">PREFORMA</a> project co-funded by the <a href="http://europa.eu/" target="_blank">European Commission</a>; designed, led and fully developed by MediaArea.</span>
</header>
<div class="featureInfos row">
<a class="btn btn-default" href="/MediaConch">Learn more</a>
</div>
</div>
</div>
<div class="clearfix"></div>
<div class="col-xs-12 col-sm-6">
<div class="featureBox">
<header style="height: 162px;">
<h3><a href="/MediaTrace">MediaTrace</a></h3>
<span class="featureDescription">Technical report that expresses the binary architecture of a file.</span>
<span class="featureDescription">Designed in collaboration by MediaArea and <a href="https://www.moma.org/" target="_blank">MoMA</a>; led and developed by MediaArea.</span>
</header>
<div class="featureInfos row">
<a class="btn btn-default" href="/MediaTrace">Learn more</a>
</div>
</div>
</div>
<div class="col-xs-12 col-sm-6">
<div class="featureBox">
<header>
<h3><a href="/QCTools">QCTools</a></h3>
<span class="featureDescription">Helps users analyze and understand their digitized video files through use of audiovisual analytics and filtering.</span>
<span class="featureDescription">Funded by the <a href="https://www.neh.gov/" target="_blank">National Endowment for the Humanities</a> and the <a href="http://www.knightfoundation.org" target="_blank">Knight Foundation</a>; designed and led by Dave Rice and the <a href="https://www.bavc.org/" target="_blank">Bay Area Video Coalition</a>; developed by MediaArea, <a href="https://github.com/utzig">Fabio Utzig</a>, <a href="https://github.com/ElderOrb">Alexander Ivash</a>.</span>
</header>
<div class="featureInfos row">
<a class="btn btn-default" href="/QCTools">Learn more</a>
</div>
</div>
</div>
<div class="clearfix"></div>
<div class="col-xs-12 col-sm-6">
<div class="featureBox">
<header style="height: 192px;">
<h3><a href="/BWFMetaEdit">BWF MetaEdit</a></h3>
<span class="featureDescription">Supports embedding, validating, and exporting of metadata in Broadcast WAVE Format (BWF) files. It supports the <a href="http://www.digitizationguidelines.gov/" target="_blank">FADGI (Federal Agencies Digitization Guidelines Initiative)</a> for embedded metadata in the bext and INFO chunks.</span>
<span class="featureDescription">Initially funded by the <a href="https://www.loc.gov/" target="_blank">Library of Congress</a> and <a href="http://www.digitizationguidelines.gov/" target="_blank">FADGI</a>; designed and led by <a href="http://avpreserve.com/" target="_blank">AVPreserve</a>, developed by MediaArea.</span>
</header>
<div class="featureInfos row">
<a class="btn btn-default" href="/BWFMetaEdit">Learn more</a>
</div>
</div>
</div>
<div class="col-xs-12 col-sm-6">
<div class="featureBox">
<header>
<h3><a href="/AVIMetaEdit">AVI MetaEdit</a></h3>
<span class="featureDescription">Supports embedding, validating, and exporting of metadata in AVI (Standard and OpenDML) files. This tool can also enforce file structure and metadata recommendations and specifications from U.S. National Archives, Microsoft, and IBM.</span>
<span class="featureDescription">Initially funded by <a href="http://www.archives.gov/preservation/products/" target="_blank">NARA (National Archives and Records Administration)</a> supported by the <a href="http://www.digitizationguidelines.gov/" target="_blank">FADGI</a>; designed and led by <a href="http://avpreserve.com/" target="_blank">AVPreserve</a>; developed by MediaArea.</span>
</header>
<div class="featureInfos row">
<a class="btn btn-default" href="/AVIMetaEdit">Learn more</a>
</div>
</div>
</div>
<div class="clearfix"></div>
<div class="col-xs-12 col-sm-6">
<div class="featureBox">
<header style="height: 192px;">
<h3><a href="/MOVMetaEdit">MOV MetaEdit</a></h3>
<span class="featureDescription">Supports the embedding and editing of metadata in MOV (Apple QuickTime) or MP4 (ISO/IEC 14496-14 a.k.a. MPEG-4 Part 14) files. It is currently focused on Universal Ad ID metadata but could be expanded on request.</span>
<span class="featureDescription">Sponsored by <a href="https://ad-id.org">Ad-ID</a>; designed, led and fully developed by MediaArea.</span>
</header>
<div class="featureInfos row">
<a class="btn btn-default" href="/MOVMetaEdit">Learn more</a>
</div>
</div>
</div>
<div class="col-xs-12 col-sm-6">
<div class="featureBox">
<header>
<h3><a href="/DVAnalyzer">DV Analyzer</a></h3>
<span class="featureDescription">Technical quality control and reporting tool that  examines DV streams in order to report errors in the tape-to-file  transfer process, such as video error concealment information, invalid  audio samples, timecode inconsistency, inconsistent use of arbitrary  bits in video DIF blocks, and DIF structural problems.</span>
<span class="featureDescription">Initially funded, designed and led by <a href="https://www.avpreserve.com/dvanalyzer/" target="_blank">AVPreserve</a>; developed by MediaArea.</span>
</header>
<div class="featureInfos row">
<a class="btn btn-default" href="/DVAnalyzer">Learn more</a>
</div>
</div>

    $(document).ready(function() {
        // Adapt height of featureBox header to have buttons on the same line
        var featureBoxHeight = function() {
            var previousElem;
            // Apply only on medium screen and up
            if ($(window).width() >= 768) {
                $('.featureBox header').each(function(index, elem) {
                    if (index % 2) {
                        if (previousElem.clientHeight > elem.clientHeight) {
                            $(elem).height(previousElem.clientHeight);
                        }
                        else if (elem.clientHeight > previousElem.clientHeight) {
                            $(previousElem).height(elem.clientHeight);
                        }
                    }
                    else {
                        previousElem = elem;
                    }
                });
            }
            else {
                $('.featureBox header').each(function(index, elem) {
                    $(elem).height('auto');
                });
            }
        };

        featureBoxHeight();
    });
