<ul id="features">
<li>Apply glass look to windows borders</li>
<li>Blur the content behind the borders to improve UI experience</li>
<li>Change amount of transparency in Control panels directly</li>
<li>Change inactive windows borders color</li>
<li>Skin windows borders (add glow, shadows etc.) without changing Windows theme</li>
<li>Fully native including MSStyle themes and DWM API compatibility</li>
<li>Low resources usage</li>
</ul>
