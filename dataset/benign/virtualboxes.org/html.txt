<h1>Welcome</h1>
<p data-adtags-visited="true" style="text-align:justify;">Welcome!<br/> This project provides virtual machines for <a href="http://virtualbox.org/">Oracle VM VirtualBox®</a> for several <a href="http://en.wikipedia.org/wiki/Free_Software" title="What does free software mean?">free</a> and/or <a href="http://en.wikipedia.org/wiki/Open_source" title="What does open source mean?">open-source</a> operating systems, such as <a href="http://en.wikipedia.org/wiki/GNU/Linux" title="GNU/Linux">GNU/Linux</a> or <a href="http://en.wikipedia.org/wiki/FreeBSD" title="FreeBSD">Free</a>/<a href="http://en.wikipedia.org/wiki/NetBSD" title="NetBSD">Net</a>/<a href="http://en.wikipedia.org/wiki/OpenBSD" title="OpenBSD">OpenBSD</a> for testing, security and/or entertainment purposes.</p>
<p data-adtags-visited="true" style="text-align:justify;">In most cases, we’ve done a minimal setup, to let you alter the images to your own needs and learn how to use the operating systems. We will try to provide instructions for key tasks (for example, installing Guest Additions) for each image.</p>
<p data-adtags-visited="true" style="text-align:justify;">Updates on new images and problems will be provided in the <a href="/news" title="News">News</a> page. We would like you to subscribe to our <a href="/feed/" title="RSS 2.0">newsfeed</a> or follow us by <a href="http://feedburner.google.com/fb/a/mailverify?uri=virtualbox_images&amp;loc=en_US" title="Subscribe by e-mail">by e-mail</a>, either.</p>
<p data-adtags-visited="true" style="text-align:justify;">We hope you enjoy your stay. Thank you <img alt="🙂" class="emoji" draggable="false" role="img" src="https://s0.wp.com/wp-content/mu-plugins/wpcom-smileys/twemoji/2/svg/1f642.svg"/></p>
