<div class="entry-content">
<h2>Compact and repair Access 2007-2013 database via Vb.net code</h2>
<div aria-hidden="true" class="wp-block-spacer" style="height:20px"></div>
<p>最近寫了一個小工具，資料庫使用 Access 2010 的檔案<br/>而 Access 資料庫檔案的特性是檔案大小會持續增大，即使有執行 DELETE 語法<br/>便決定寫一個 <strong>壓縮及修復資料庫</strong> 的功能，省去對 Office Access 的依賴</p>
<p>上 Google 查了一下，多數都是使用 <strong>Microsoft Jet and Replication Objects 2.6 Library</strong> 達來成<br/>但是使用 <code>JRO.JetEngine</code> 時，透過 <code>Jet OLEDB:Engine Type=?</code> 指定目標檔案時<br/>最高只能支援到 <code>JET Version 4.x</code> 也就是只能產出 Access 2003 版本檔案格式</p>
<p><span style="font-size: inherit;"><br/>後來嘗試使用</span> <strong>Microsoft DAO 3.6 Object Library</strong> <span style="font-size: inherit;">來處理<br/>但是 <code>DAO.DatabaseTypeEnum</code> 這個陳述式中只能支援到 <code>dbVersion40</code> 也就是一樣只能到 Access 2003</span></p>
<p><span style="font-size: inherit;"><br/>最後找到了</span> <strong>Microsoft 14.0 Office Access database engine Object Library</strong> (<span style="font-size: inherit;">版本12)<br/>其中 <code>Dao.DatabaseTypeEnum</code> 最高支援到 <code>dbVersion150</code> 也就是 Access 2013<br/></span></p>
<ul>
<li>dbVersion120 : Access 2007</li>
<li>dbVersion140 : Access 2010</li>
<li>dbVersion150 : Access 2013</li>
</ul>
<p>我電腦中版本的只能支援 Access 2013<br/>有較新的版本應該就可以支援到 <code>dbVersion160</code>，也就是 Access 2016 和之後的版本</p>
<p>先上程式碼範例</p>
