<h2>About Alt Codes</h2>
<p>IBM developed a method to place the characters that can not be typed by a keyboard on the screen: while keeping the Alt key down, typing the code defined for the character via the numeric keypad. The system which interprets this action and places the corresponding character at the cursor's location is BIOS.</p><p>
These codes became so popular so that Microsoft, even though developed a new set of codes, decided to keep them. The new set was named ANSI(later changed to Windows codes), and the old ones called as OEM(original equipment manufacturer) code pages. Three-digit codes represent the OEM codes. Codes with a preceding 0 represent the new ANSI codes.</p><p>
    For the last two decades, <a href='https://www.alt-codes.net/blog/unicodes-10";' title="Unicode">Unicode</a> is being adopted by many systems. After adopting Windows to Unicode,  the entry of all Unicode characters by the same method was desired, and achieved by some applications, but couldn't be spread to all system. Compatibility issues with old ANSI codes prevent the entry of all Unicode characters.</p>
    Some Tips:
    <ul>
<li>Characters produced may vary depending on the OEM Code Page setting.</li>
<li>To type a character using its Alt Code value, Num lock should be on. Otherwise unwanted results may occur.</li>
<li>The numeric keypad does not exist on every laptop. To use them, Numpad should be activated by pressing down the Fn key.</li>
</ul>
<h3>How to type an Alt Symbol on keyboard?</h3>
<p>For example, let's type a <strong>degree symbol</strong> by using its <em>Alt Code</em> value on the keyboard.</p>
<ul>
<li>Make sure you switch on the NumLock,</li>
<li>press and hold down the <kbd class="keybd">Alt</kbd> key,</li>
<li>type the Alt Code value of the degree symbol <kbd class="keybd">0</kbd><kbd class="keybd">1</kbd><kbd class="keybd">7</kbd><kbd class="keybd">6</kbd> on the <mark>numeric pad</mark>,</li>
<li>release the <kbd class="keybd">Alt</kbd> key and you got a ° <strong>degree symbol</strong>.</li>
</ul>
<p>** Above mentioned procedure is not aplicable for MacOS.</p>
