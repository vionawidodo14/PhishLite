<h2><a href="https://hackmii.com/2016/11/the-open-homebrew-channel/" rel="bookmark" title="Permanent Link to The (Open) Homebrew Channel">The (Open) Homebrew Channel</a></h2>
<h4>November 22nd, 2016 by <span class="author">marcan</span> · <a href="https://hackmii.com/2016/11/the-open-homebrew-channel/#comments">2 Comments</a></h4>
<div class="entry">
<p>Last weekend was the 10-year anniversary of the Nintendo Wii. We thought we’d dust off the blog with a little birthday present: the source code for The Homebrew Channel.</p>
<p>When we built HBC, we always wanted it to serve as a reference for what homebrew software <i>should</i> look like: good design, professional-looking, user friendly, stable, safe, and supporting features such as network connectivity. We hoped it would inspire other software to aspire to a similar level of quality. But we didn’t want it to become an instant base for quick hacks and mods and endless cheap variations, and we also didn’t think proliferation of installable “channels” on the Wii is a good idea: we still think it makes much more sense to have one entry point into the homebrew ecosystem, and then launch everything else from there (among other things, because it’s easy to brick a Wii by installing things into NAND). And, to be fair, the code is definitely not as pretty as what you get when running it.</p>
<p>However, the plan was always to <i>eventually</i> open source it. Bushing, in particular, always championed for this. This release is dedicated to him.</p>
<p>Keep in mind that, since this was never developed in public, you’ll probably find embarrassing things in the source code. We’ve kept it maintained over the various releases, and we’ve done some very minor cleanup to this release to bring it up to date with the latest version of the toolchain and remove “security” bits no longer relevant to an open source release, but other than that, what you see is what you get. This is the code that the millions of users of The Homebrew Channel are running on their consoles.</p>
<p><a href="https://github.com/fail0verflow/hbc">Enjoy</a>.</p>
<p>As a bonus, this code includes the fix for vWii aspect ratio on Wii U. The Title ID has been changed, so you can install it without clobbering your official Homebrew Channel (though telling them apart in the menu might be tricky!).</p>

<h2><a href="https://hackmii.com/2016/02/ben/" rel="bookmark" title="Permanent Link to In Memoriam: Ben “bushing” Byer">In Memoriam: Ben “bushing” Byer</a></h2>
<h4>February 9th, 2016 by <span class="author">marcan</span> · <a href="https://hackmii.com/2016/02/ben/#comments">1 Comment</a></h4>
<div class="entry">
<figure style="float: right; margin-left: 10px;"><img alt="bushing" height="300" src="https://hackmii.com/wp-content/uploads/2016/02/ben.jpg" width="200"/><p></p>
<figcaption style="text-align: center; line-height: 1.2em; font-size: 90%; margin-top: 0.5em;">Ben Byer<br/>1980 – 2016</figcaption>
</figure>
<p>We are deeply saddened by the news that our member, colleague, and friend <strong>Ben “bushing” Byer</strong> passed away of natural causes on Monday, February 8th.</p>
<p>Many of you knew him as one of the public faces of our group, fail0verflow, and before that, Team Twiizers and the iPhone Dev Team.</p>
<p>Outspoken but never confrontational, he was proof that even in the competitive and oftentimes aggressive hacking scene, there is a place for both a sharp mind and a kind heart.</p>
<p>To us he was, of course, much more. He brought us together, as a group and in spirit. Without him, we as a team would not exist. He was a mentor to many, and an inspiration to us all.</p>
<p>Yet above anything, he was our friend. He will be dearly missed.</p>
<p>Our thoughts go out to his wife and family.</p>
<p>Keep hacking. It’s what bushing would have wanted.</p>
</div>

<h2><a href="https://hackmii.com/2012/12/hbc-release-for-a-new-wii-u/" rel="bookmark" title="Permanent Link to HBC release for a new Wii U">HBC release for a new Wii U</a></h2>
<h4>December 7th, 2012 by <span class="author">dhewg</span> · <a href="https://hackmii.com/2012/12/hbc-release-for-a-new-wii-u/#comments">36 Comments</a></h4>
<div class="entry">
<p><strong>Update</strong>: <em>HackMii Installer</em> v1.2 with <em>The Homebrew Channel</em> v1.1.2 now available, see below</p>
<p>Another year, another console, another <em>Hackmii Installer</em>!</p>
<p>Despite all of the anti-reverse-engineering tricks we put into our last installment of the <em>HackMii Installer</em>, Nintendo managed to find the IOS exploit we used to install <em>The Homebrew Channel</em> and fix it sometime within the last two years. There never was a Wii system update for this, the fixed IOS versions can only be found on a Wii U.</p>
<p>They also blocked our old title ID. Consequently, we have a new release with a new version of <em>The Homebrew Channel</em>; this will install on both Wii consoles, and inside the virtual Wii sandbox inside the Wii U.  The currently used IOS exploit is courtesy of tueidj.</p>
<p>Please note that this is not running in full Wii U mode; running this on a Wii U will probably work just like on a Wii. (See if you can find any differences, we can all try to hack the Wii U together from inside Wii mode!)</p>
<p>Also, due to technical limitations of the virtual Wii mode, <em>BootMii</em> will not work on a Wii U. If we are able to resolve this, we will make a new release with <em>BootMii</em> support.</p>
<p>As usual, grab the new installer <a href="http://bootmii.org/download/">here</a>.</p>
<p>If you’re unsure what do to with the installer, see <a href="http://wiibrew.org/wiki/Homebrew_setup">this wiki page</a> for a general tutorial on how to setup homebrew on your Wii, and <a href="http://wiiubrew.org/wiki/WiiMode">this one at the brand new wiiubrew.org</a> for savegame exploits that still work on a Wii U.</p>
<p><strong>Update</strong>:<br/>
Unfortunately some bugs snuck into the v1.1 release, which are now fixed in v1.2:</p>
<ul>
<li>PAL 50Hz (576i) video mode now works properly</li>
<li><em>BootMii</em>/boot2 can be installed again on newer Wiis. <strong>This does not mean what you think it means.</strong> v1.1 had a bug that made BootMii/boot2 available to <em>fewer</em> Wiis than v1.0. v1.2 fixes that. If your boot1 is not vunerable, you still can’t and will never be able to install BootMii/boot2.</li>
<li>Icons load again in <em>The Homebrew Channel</em></li>
</ul>
<p>Sorry for the inconvenience.<em><br/>
</em></p>
