<h1 class="title">FAQ</h1>
<h1 class="home">There are two versions. Where's the difference?</h1>
<p>The Standard version is suitable for most users. With the annual subscription, you can manage up to a maximum of 5 lists. With this version you can upload a<a href="https://en.wikipedia.org/wiki/M3U" rel="noopener" target="_blank"> M3U file</a> from your computer or enter an external URL. In any case, a M3U file is processed. This can be a music, radio, video or IPTV collection.</p>
<p>The Pro version is designed for demanding users. You pay per list. This version uses an open JSON API from the server software.</p>
<h1 class="home">What can the Playlist Editor do?</h1>
<p>Playlist Editor allow you to create, edit and sort m3u playlists online. Your list gets a download URL that you can use in your client. You can link the playlist directly to an IPTV service provider or upload your file. In the editor you can create your own channel groups, sort and uncheck the channels. In the settings you can define whether the list is synchronized daily.</p>
<p>If necessary, you can supplement your playlists with our EPG data. Our collection is considerable but not complete.</p>
<h1 class="home">Which playlists contains Playlist Editor?</h1>
<p>Playlist Editor is a software for creating and managing playlists. This does not contain any content / playlists. There are also no information on where to get playlists.</p>
<h1 class="home">Can I try the editor?</h1>
<p>Yes. Registration is free. You can test the editor and if you like it, you can buy credits or subscribe via PayPal.</p>
