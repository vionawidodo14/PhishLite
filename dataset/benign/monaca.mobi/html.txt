<h1>Mobile App Development<br/>Fast, Easy and Flexible.</h1>
<p>Cross-platform hybrid mobile app development platform and tools in the cloud</p>
<a class="btn" href="https://monaca.mobi/signup">GET STARTED FREE</a>
</div>
<div><img src="/img/home/main-image.png"/></div>
</div>
</div>
<div class="container section summary">
<p>Monaca makes HTML5 hybrid mobile app development with <a href="http://phonegap.com/">PhoneGap</a>/<a href="http://cordova.apache.org/">Cordova</a> simple and easy. Monaca is the most open hybrid app development platform available and ready to be immediately plugged into your existing workflow and development environment. From Cloud IDE, CLI to debugger and remote online build, everything you need for your hybrid app development is here.</p>
</div>
<div class="container section powerup">
<h2>Give Power to Your Cordova Apps</h2>
<p>Monaca supercharges Cordova app development with easy to use tools, services and UI framework. It provides:</p>
<ul class="main-items">
<li><img alt="Development Environment" class="main-item" src="/img/home/ico-01.png"/><a href="https://docs.monaca.io/en/manual/development/">Flexible Development Environment <img alt="" src="/img/home/ico-arrow.png"/></a></li>

<li><img alt="Choose Your Frameworks" class="main-item" src="/img/home/ico-03.png"/><a href="#">Choose Your Frameworks <img alt="" src="/img/home/ico-arrow.png"/></a></li>
</ul>
<ul>
<li><img alt="Remote Build and Deploy" class="sub-item" src="/img/home/ico-04.png"/><a href="https://docs.monaca.io/en/manual/build/">Remote Build and Deploy <img alt="" src="/img/home/ico-arrow.png"/></a></li>
<li><img alt="Debugging and Testing" class="sub-item" src="/img/home/ico-05.png"/><a href="/debugger.html">Debugging and Testing <img alt="" src="/img/home/ico-arrow.png"/></a></li>
<li><img alt="Cordova Power Plugin" class="sub-item" src="/img/home/ico-06.png"/><a href="https://docs.monaca.io/en/reference/power_plugins/">Cordova Power Plugin <img alt="" src="/img/home/ico-arrow.png"/></a></li>
<li><img alt="Backend for Cordova" class="sub-item" src="/img/home/ico-07.png"/><a href="https://docs.monaca.io/en/manual/backend/">Backend for Cordova <img alt="" src="/img/home/ico-arrow.png"/></a></li>
</ul>
</div>
<div class="container section powerup-overview">
<ul>
<li>
<div class="content content-1">
<img src="/img/home/ico-01.png"/>
<h2>Flexible Development Environment</h2>
<p>Monaca started with a powerful Cloud IDE that can run in the browser. Now a desktop GUI tool (Localkit) and command-line tool (CLI) are available as its local development companions. In addition, we provide an extension for Visual Studio. Your projects can be synchronized no matter what environment you use. It's the perfect app builder.</p>
<div><a href="https://docs.monaca.io/en/quick_start/">Getting Started Guide</a></div>
</div>
<div class="content-visual content-2">
<img alt="Flexible Development Environment" src="/img/home/img01_01.png"/>
</div>
</li>
<li>
<div class="content-visual phone-display content-3">

<h2>Beautiful and High Performance</h2>
<p>Onsen UI is JS framework agnostic and packed with many UI components that help you create seamless and beautiful apps. Onsen UI can make any app look and feel like a native app. Finally, one source code for all platform designs.</p>
<div><a href="https://onsen.io">See more about Onsen UI</a></div>
</div>
</li>
<li>
<div class="content content-5">
<img src="/img/home/ico-03.png"/>
<h2>Choose Your Framework</h2>
<p>Use Monaca with any JavaScript frameworks. We support Angular 1, 2+, React and Vue.js, or you can bring your own favorite framework. There are many templates ready to use, so you can get started immediately.</p>
</div>
<div class="content-visual content-6">
<img alt="Choose Your Framework" src="/img/home/img03.png"/>
</div>
</li>
</ul>

<div class="container section more-features">
<p>And many more features!</p>
</div>
<div class="container section integration-features">
<ul>
<li class="content-left remote-build-ci">
<div class="service-visual"><img alt="Remote Build and Continuous Integration" src="/img/home/img04.png"/></div>
<div class="service-overview">
<h3>Remote Build and Continuous Integration</h3>
<p>Powerful remote online build and CI features for Cordova. All build environments are secure in the cloud, with easy access from the browser. Hook scripts, custom Cordova plugins and flexible configurations are all in your hands. It works exactly the same way as you do in the local environment.</p>
<a href="/ci.html">See more about Remote Build and CI</a>
</div>
</li>
<li class="content-right debugging">
<div class="service-visual"><img alt="Powerful Debugging and Testing" src="/img/home/img05.png"/></div>
<div class="service-overview">
<h3>Powerful Debugging and Testing</h3>
<p>Monaca Debugger brings supreme debugging experience. It adds advanced JavaScript debugging to your Cordova apps, including break points, step in/out and profiler. Supports iOS/Android debugging on Windows and Mac without installing any SDKs. The develop &amp; test cycle will be hugely improved.</p>
<a href="/debugger.html">See more about Monaca Debugger</a>
</div>
</li>
<li class="content-left power-plugins">
<div class="service-visual"><img alt="Cordova Power Plugins" src="/img/home/img06.png"/></div>
<div class="service-overview">
<h3>Cordova Power Plugins</h3>
<p>Power up your Cordova app. The Resource Encryption Plugin provides extra protection for your app. In-App Updater makes it easy to update without redeployment to the App Store. Additionally, In-App-Purchase, Secure Storage and Secure SQL Plugin and more are available.</p>
</div>
</li>
<li class="content-right backend-service">
<div class="service-visual"><img alt="Backend Services for Cordova" src="/img/home/img07.png"/></div>
<div class="service-overview">
<h3>Backend Services for Cordova</h3>
<p>Simple and easy backend service APIs are available for Cordova Apps. Push notifications, user management, remote database, email delivery and much more. Backend Management APIs is also provided for the access from your backend server.</p>
<a href="https://docs.monaca.io/en/">Read the docs</a>
</div>
</li>
</ul>
