<h1 class="entry-title"><a href="https://www.dolcn.com/archives/18355" rel="bookmark">“镇江与中国艺术史”学术研讨会会议通知</a></h1>
<div class="entry-meta">
<span class="sep">发表于</span><a href="https://www.dolcn.com/archives/18355" rel="bookmark" title="08:08"><time class="entry-date" datetime="2019-10-13T08:08:04+08:00">2019-10-13</time></a><span class="by-author"><span class="sep">由</span><span class="author vcard"><a class="url fn n" href="https://www.dolcn.com/aboutus" rel="author" title="查看所有由编辑发布的文章">编辑</a></span></span>
</div><!-- .entry-meta -->
</header><!-- .entry-header -->
<div class="entry-content">
<p>近年来，艺术史研究领域出现的“全球艺术史”的书写成为一个热门话题。“全球艺术史”的兴起主要来自于学者对于以西方艺术史研究为中心的视角及方法论的质疑与反思，提倡不同区域、国家艺术史发展模式的独特性及其价值。在全球语境的关照下，一些艺术史家开始倡导在研究、写作和教学中尝试突破国家和地区的界域，把艺术的发展看成是一种在空间中的延伸与互动的过程。中国艺术史的研究与书写无疑也纳入了这一动态之中。区域研究与国家、民族艺术的研究再次被重新审视。跨文化、跨地域的研究方法也为艺术史的书写提供了新的比较视野，这种视野将地域艺术的研究放入了一个与多种因素互动、促生的过程。 <a class="more-link" href="https://www.dolcn.com/archives/18355#more-18355">继续阅读 <span class="meta-nav">→</span></a></p>

<h1 class="entry-title"><a href="https://www.dolcn.com/archives/18283" rel="bookmark">民国建筑师在南京的民族形式建筑创作轨迹（1927-1937）</a></h1>
<div class="entry-meta">
<span class="sep">发表于</span><a href="https://www.dolcn.com/archives/18283" rel="bookmark" title="21:55"><time class="entry-date" datetime="2019-09-22T21:55:54+08:00">2019-09-22</time></a><span class="by-author"><span class="sep">由</span><span class="author vcard"><a class="url fn n" href="https://www.dolcn.com/aboutus" rel="author" title="查看所有由编辑发布的文章">编辑</a></span></span>
</div><!-- .entry-meta -->
</header><!-- .entry-header -->
<div class="entry-content">
<p><span style="color: #808080;"><strong>摘要</strong>：1927至1937年这一近代中国的“黄金十年”，孕育了中国建筑师群体探索民族形式建筑的高潮期。这批留学归国或本土培养的建筑师，在政府认定资质的机构中从事建筑活动，标志着现代化、正规化、学理化的中国职业建筑师出现。南京国民政府充满党派色彩与民族国家符号的文化、政治诉求，又促使在南京探索民族形式建筑的建筑师，主创公署类，教科研与社会服务类，体育场与纪念类等可以美化政治、传达党国权威的建筑类型。他们除了开设自营建筑设计机构以外，还积极投身建筑施工、行政管理和建筑教育领域。与此同时，政治中心南京的特殊性，变动的时局与建筑师不断自我修正的创作观念，也造成其创作高峰期，因人、因时而异。</span> <a class="more-link" href="https://www.dolcn.com/archives/18283#more-18283">继续阅读 <span class="meta-nav">→</span></a></p>

<div class="entry-meta">
<span class="sep">发表于</span><a href="https://www.dolcn.com/archives/18227" rel="bookmark" title="17:08"><time class="entry-date" datetime="2019-09-06T17:08:50+08:00">2019-09-06</time></a><span class="by-author"><span class="sep">由</span><span class="author vcard"><a class="url fn n" href="https://www.dolcn.com/aboutus" rel="author" title="查看所有由编辑发布的文章">编辑</a></span></span>
</div><!-- .entry-meta -->
</header><!-- .entry-header -->
<div class="entry-content">
<p>加热不燃烧设备（HNB），是一种加热装置加上烟弹（经过处理的烟草制品）的组合设备，外部加热装置通过高温加热到烟弹可以出烟但是却不足以燃烧的温度。在不燃烧烟草的前提下，让烟草发出烤烟的香味。由于点燃吸食的情况下，温度会达到350摄氏度到600摄氏度之间，只要温度达到这一区间，由于燃烧，会产生非常多的有害物质，如一氧化碳、尼古丁等生物碱、胺类、腈类、醉类、酚类、烷烃、醛类、氮氧化物等。而加热不燃烧方式，温度在300摄氏度左右不产生明火，有害物质会大大减少。HNB采用低温烘烤来加热，替代直接燃烧传统香烟，逐渐受到全球越来越多吸烟者的追捧，作为烟草3.0时代的产物，代表了全球烟草行业升级的新方向。 <a class="more-link" href="https://www.dolcn.com/archives/18227#more-18227">继续阅读 <span class="meta-nav">→</span></a></p>
