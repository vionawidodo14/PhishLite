<h1 class="sectionedit1 page-header" id="中国科学技术大学_linux_用户协会">中国科学技术大学 Linux 用户协会<a aria-label="Anchor link for: 中国科学技术大学_linux_用户协会" class="anchorjs-link" data-anchorjs-icon="" href="#中国科学技术大学_linux_用户协会" style="font-family: anchorjs-icons; font-style: normal; font-variant: normal; font-weight: normal; line-height: 1; padding-left: 0.375em;"></a></h1>
<div class="level1">
<p>
中国科学技术大学 Linux 用户协会（科大 LUG）是由在校的 GNU/Linux 爱好者发起并组成的全校性群众团体，是一个以推广自由软件文化、宣传自由软件价值为目的的协会组织。<a class="wikilink1" href="https://lug.ustc.edu.cn/wiki/intro" title="intro">了解更多</a>
</p>
<p>
<a class="wikilink1" href="https://lug.ustc.edu.cn/wiki/intro_english" title="intro_english">English Version</a>
</p>
</div>
<h2 class="sectionedit2 page-header" id="特色活动">特色活动<a aria-label="Anchor link for: 特色活动" class="anchorjs-link" data-anchorjs-icon="" href="#特色活动" style="font-family: anchorjs-icons; font-style: normal; font-variant: normal; font-weight: normal; line-height: 1; padding-left: 0.375em;"></a></h2>
<div class="level2">
<ul class="fix-media-list-overlap">
<li class="level1"><div class="li"><strong><a class="wikilink1" href="https://lug.ustc.edu.cn/wiki/lug/events/weeklyparty" title="lug:events:weeklyparty">LUG 每周小聚</a>:</strong><br/>
每周末由同学带来的技术分享演讲。</div>
</li>
<li class="level1"><div class="li"><strong><a class="wikilink1" href="https://lug.ustc.edu.cn/wiki/lug/events/lip" title="lug:events:lip">Linux Install Party</a>:</strong><br/>
推广和安装 Linux，宣传和鼓励开源和自由软件精神的活动。</div>
</li>
<li class="level1"><div class="li"><strong><a class="wikilink1" href="https://lug.ustc.edu.cn/wiki/lug/events/lup" title="lug:events:lup">Linux User Party</a>:</strong> <br/>
为校内乃至整个合肥地区的不同层次的 Linux 用户提供一个交流平台。</div>
</li>
<li class="level1"><div class="li"><strong><a class="wikilink1" href="https://lug.ustc.edu.cn/wiki/lug/events/sfd" title="lug:events:sfd">自由软件日</a>:</strong><br/>
在国际自由软件基金会（SFI）的领导下，由自由/开源软件爱好者自发筹集的非盈利性活动。</div>
</li>
<li class="level1"><div class="li"><strong><a class="wikilink1" href="https://lug.ustc.edu.cn/wiki/lug/events/hackergame" title="lug:events:hackergame">信息安全大赛</a>:</strong><br/>
每年秋季学期举办的信息安全竞赛。</div>
</li>
</ul>
</div>
<h2 class="sectionedit3 page-header" id="网络服务">网络服务<a aria-label="Anchor link for: 网络服务" class="anchorjs-link" data-anchorjs-icon="" href="#网络服务" style="font-family: anchorjs-icons; font-style: normal; font-variant: normal; font-weight: normal; line-height: 1; padding-left: 0.375em;"></a></h2>
<div class="level2">
<ul class="fix-media-list-overlap">
<li class="level1"><div class="li"><strong><a class="wikilink1" href="https://lug.ustc.edu.cn/wiki/lug/services/mirrors" title="lug:services:mirrors">开源软件镜像</a></strong></div>
</li>
<li class="level1"><div class="li"><strong><a class="wikilink1" href="https://lug.ustc.edu.cn/wiki/lug/services/ftp" title="lug:services:ftp">LUG FTP(各种资源汇总)</a></strong></div>
</li>
<li class="level1"><div class="li"><strong><a class="wikilink1" href="https://lug.ustc.edu.cn/wiki/lug/services/pxe" title="lug:services:pxe">网络启动服务</a></strong></div>
</li>
<li class="level1"><div class="li"><strong><a class="wikilink1" href="https://lug.ustc.edu.cn/wiki/lug/services/gitlab" title="lug:services:gitlab">GitLab 代码托管</a></strong></div>
</li>
<li class="level1"><div class="li"><strong><a class="wikilink1" href="https://lug.ustc.edu.cn/wiki/lug/services/start" title="lug:services:start">其他</a></strong></div>
