<p itemprop="description">

в браузере <span itemprop="browserRequirements">Chrome</span> для <span itemprop="operatingSystem">OS Windows, Mac и Linux</span> (для пользователей Андроид и iOS разработаны специальные <a href="https://play.google.com/store/apps/details?id=com.voicenotebook.voicenotebook" target="_blank">Android</a>, <a href="https://itunes.apple.com/ru/app/%D0%B3%D0%BE%D0%BB%D0%BE%D1%81%D0%BE%D0%B2%D0%BE%D0%B9-%D0%B1%D0%BB%D0%BE%D0%BA%D0%BD%D0%BE%D1%82/id1398027022?mt=8" target="_blank">iOS</a> приложения). <h2 itemprop="applicationCategory">Голосовой набор текста</h2>
<p class="last">
Нажмите кнопку "включить запись". При первом посещении сайта вверху браузера возникнет панелька с просьбой разрешить доступ к микрофону. Нажмите там кнопку "Разрешить"
<br/> Говорите в микрофон
<br/> Кнопка <b>A/a</b> меняет регистр первой буквы слова, рядом с которым находится курсор
<br/> Кнопка <b>Отменить</b> удаляет из результирующего поля последний введенный фрагмент
<br/>Кнопки пунктуации служат для ввода знаков с помощью мыши
<br/>Текст в результирующее поле добавляется после последней позиции курсора. Если был выделен фрагмент текста в результирующем поле, то введенный текст будет его заменять
<br/>Установка флажка <b>Отключить управление заглавными буквами Google</b> отменяет простановку заглавных букв анализатором Google.
<br/>Если отмечен флажок <b>Заменять слова пунктуации</b>, то слова в голосовом вводе, совпадающие со знаками препинания, будут  заменяться на эти знаки. Соответствующие слова можно увидеть, если навести мышь на кнопку знака.
 <span class="red">*</span>В настоящее время Google самостоятельно заменяет  слова:  точка, запятая, вопросительный и восклицательный знаки, поэтому при отключении флажка замена все равно может проводиться.  
<br/>Смена языка для голосового ввода осуществляется выбором соответствующего языка в выпадающем списке. Если языка нет  в списке, но он <a href="blog/speech-reco-languages/" target="_blank">поддерживается для голосового ввода</a>, то его можно добавить в кабинете пользователя (доступен после <a href="/regcab.php" target="_blank">регистрации</a>)
<br/>Если отмечен флажок <b>Выполнять команды</b>, то во время  ввода текста можно давать команды голосом. 
<br/>Если отмечен флажок <b>Вывод в буфер обмена</b>, то текст будет поступать не в результирующее поле, а в буфер обмена. Флажок работает только при установленном расширении блокнота.

<br/>Поле <b>Уровень распознавания</b> отображает качество распознавания речи или вид ошибки, если она возникла.
</p>
<h2>Ввод текста голосом  любое поле ввода! Интеграция с Windows, Mac и Linux</h2>
<p>Установив <a href="https://chrome.google.com/webstore/detail/speech-recognition-online/pehlbpmpoabkgenppepoaihkacolpdcf?hl=ru&amp;gl=RU" target="_blank">расширение для голосового блокнота</a>,
 вы получите возможность  вводить текст голосом в любое поле ввода напрямую. Добавив <a href="/blog/windows-integration/" target="_blank">модуль интеграции c Windows, Mac или Linux</a>,
 вы обеспечите прямой голосовой ввод во все приложения в этой OS.
</p>
<h2>Перевод аудио в текст</h2>
<p>
<br/>Кнопка <b>Транскрибация</b> включает панель воспроизведения звуковых и видео файлов. 
 В настоящее время в голосовом блокноте доступен <a href="/blog/audio-transcribing/" target="_blank">перевод аудиотекстов</a> из форматов html5 видео и аудио, а также из видеозаписей youtube.
 Для форматов html5 видео и аудио необходимо указать URL медиа файла, для воспроизведения записи youtube нужно ввести ID этой записи в Youtube. 
 После чего следует нажать на кнопку <b>включить запись</b>. 
 <br/>
</p><p>
</p><p>Снятие флажка <b>Запускать синхронно с записью</b> в модуле транскрибирования дает возможность самостоятельно проговаривать прослушиваемые фрагменты аудио или видео (при использовании наушников). 
Данная опция крайне полезна при плохом качестве роликов, когда автоматическое распознавание  невозможно.
</p>
<h2>Синхронный перевод с голоса </h2>
<p>Кнопка <b>Перевод</b> включает панель перевода произнесенного текста.
 Отметив на этой панели флажок синхронного перевода и нажав на кнопку <b>Включить запись</b>, можно видеть синхронный перевод на заданный язык.

</p>
