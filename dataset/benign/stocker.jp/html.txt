<h2 class="sprite" id="sp_po_wds"><a href="https://stocker.jp/diary/web-design-school/"><img src="/img/sp2.png?2" title="スマートフォン時代のWebデザインスクール"/></a></h2>
<p>渋谷で平日夜に開講している、主に社会人向けのWebデザインスクールです。</p>
<p>デザインの基礎知識、Photoshop や Illustrator によるPC・タブレット・スマートフォン対応のWebデザイン制作、別途レスポンシブWebデザインによる HTML/CSSコーディングまで教えています。</p>
<p>Webデザインをはじめて学ばれる方から、スキルアップを目指す方まで通われています。</p>
</div>
<div class="po_right">
<div class="po_right_main">
<a href="https://stocker.jp/diary/web-design-school/"><img alt="Photoshop" class="po_mainimg" height="290" src="/img/po_m11.png" title="スマートフォン時代のWebデザインスクール" width="290"/></a>
<div class="shadow_300"></div>
</div>
<div class="po_right_sub">
<div class="shadow_136">
<a href="https://stocker.jp/diary/web-design-school/"><img alt="Illustrator" class="po_subimg" height="128" src="/img/po_s25.png" title="スマートフォン時代のWebデザインスクール" width="128"/></a>
</div>
<p>Photoshop は、一般の解説書だと写真編集用の環境設定や操作について解説しているものが多いですが、このスクールではWebデザインに特化した環境設定や操作について解説します。</p>
<div class="shadow_136">
<a href="https://stocker.jp/diary/web-design-school/"><img alt="" class="po_subimg" height="128" src="/img/po_s26.png" title="" width="128"/></a>
</div>
<p>Illustrator は、アイコン・ピクトグラム・イラスト制作などに向いています。Webデザインで使用するアイコンの制作などは Illustrator で制作します。</p>
</div>

<div class="po_left">
<h2 class="sprite" id="sp_po_d"><a href="/diary/" target="_blank"><img alt="Stocker.jp / diary" src="/img/sp2.png?2" title="Stocker.jp / diary"/></a></h2>
<p>主にWebデザイン・Web技術について書いているブログです。</p>
<p>「見やすいブログとはどんなブログか」ということを1から考え、トップページを新聞記事のように配置し、はてなブックマーク数を表示することで記事の重要度を表しています。</p>
<p>このブログは WordPress で構築し、jQuery で見出しの文字詰めなどを調整しています（Mac のみ）。</p>
</div>
<div class="po_right">
<div class="po_right_main">
<a href="/diary/" target="_blank"><img alt="Stocker.jp / diary" class="po_mainimg" height="290" src="/img/po_m9.png" title="Stocker.jp / diary" width="290"/></a>
<div class="shadow_300"></div>
</div>
<div class="po_right_sub">
<div class="shadow_136">
<a href="/diary/" target="_blank"><img alt="Croppy" class="po_subimg" height="128" src="/img/po_s21.png" title="" width="128"/></a>
</div>
<p>はてなブックマーク数はAPIを使ってブックマーク数を取得し、MySQL にキャッシュしています。</p>
<p>Stocker.jp / diary は、はてなブックマーク数で日本のブログの上位 0.05% 以内に入っています。</p>
<div class="shadow_136">
<a href="/diary/" target="_blank"><img alt="" class="po_subimg" height="128" src="/img/po_s22.png" title="" width="128"/></a>
</div>
<p>フッターもひと工夫しています。ぜひ下までご覧ください。</p>
</div>
</div>

<div class="po_left">
<h2 class="sprite" id="sp_po_cp"><a href="https://croppy.org/" target="_blank"><img alt="Webデザインや配色をサポートする新サービス | Croppy" src="/img/sp2.png?2" title="Webデザインや配色をサポートする新サービス | Croppy"/></a></h2>
<p>Webデザインや配色をサポートするWebサービスです。</p>
<p>「ヘッダー」「サイドバー」などパーツ別に分けられたWebデザインパーツを見れるだけでなく、今見ているページをブラウザ上で切り抜き、手軽にスクラップできるのが最大の特徴です。</p>
<p>切り抜かれたパーツに含まれる配色を分析したり、好きな色を指定すると補色、類似色、その色が使われたパーツを見ることも出来ます。</p>
</div>
<div class="po_right">
<div class="po_right_main">
<a href="http://croppy.org/" target="_blank"><img alt="Croppy" class="po_mainimg" height="290" src="/img/po_m8.png" title="Webデザインや配色をサポートする新サービス | Croppy" width="290"/></a>
<div class="shadow_300"></div>
</div>
<div class="po_right_sub">
<div class="shadow_136">
<a href="http://croppy.org/" target="_blank"><img alt="Croppy" class="po_subimg" height="128" src="/img/po_s19.png" title="" width="128"/></a>
</div>
<p>ブックマークレットをクリックすると、見ているページの一部を Photoshop の切り抜きツールのように切り抜いて投稿することができます。</p>
<div class="shadow_136">
<a href="http://croppy.org/" target="_blank"><img alt="" class="po_subimg" height="128" src="/img/po_s20.png" title="" width="128"/></a>
</div>
<p>切り抜かれたパーツに含まれる色を分析する機能もあります。</p>
<p>このサービスはWordPressで構築しました。</p>
</div>
</div>

<h2 class="sprite" id="sp_po_fs"><a href="http://free.stocker.jp/" target="_blank"><img alt="フリー写真素材 :: Free.Stocker" src="/img/sp2.png?2" title="フリー写真素材 :: Free.Stocker"/></a></h2>
<p>日本やイタリアのフリー写真素材が20GB以上あり、リンク不要、著作権表示も不要で商用利用OKの無料素材集です。</p>
<p>殆どの写真素材は私が撮影したもので、WordPressを使ってギャラリーサイトを制作しました。</p>
<p>日本語だけでなく英語版も制作し、文言や写真タイトル等はフィリピン大学の方と協力して翻訳しました。</p>
<p>CSS3によるアニメーションを積極的に取り入れ、Twitter、Facebookとの連携にも対応しています。</p>
