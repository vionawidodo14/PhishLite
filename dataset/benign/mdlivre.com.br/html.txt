<h3>Dúvidas frequentes</h3>
</div>
</div>
<div class="row questions">
<div class="col-md-6">
<div class="question">
<strong>Como é feito o pagamento?</strong>
<p>
								Todos os pagamentos são realizados pelo MercadoPago e podem ser efetuados através de boleto, cartão de crédito ou saldo em conta.
							</p>
</div>
<div class="question">
<strong>Como eu faço para mudar de plano?</strong>
<p>
								Caso você esteja no Plano Gratuito, basta efetuar o pagamento que o seu plano será alterado para o Mensal. Se estiver no Plano Mensal e quiser voltar para o Gratuito basta não efetuar o pagamento e seu plano será alterado automaticamente. Simples assim.
								Para contratar ou cancelar o Plano Premium, entre em <a href="#contact">contato</a> conosco.
							</p>
</div>
</div>
<div class="col-md-6">
<div class="question">
<strong>Quantas contas posso ter?</strong>
<p>
								Você pode ter quantas contas quiser, mas cada conta é tratada de forma individual e para acessar todos os recursos com todas as contas é necessário pagar uma mensalidade para cada uma delas.
							</p>
</div>
<div class="question">
<strong>Tenho vários funcionários e não quero que eles vejam todos os dados da minha conta. Posso bloquear algumas informações?</strong>
<p>
								No momento não é possível definir diferentes permissões. Os usuários que acessarem o sistema verão todos os dados da conta.
							</p>
</div>
</div>

<p>Você tem mais de uma conta e precisa copiar anúncios entre elas? Quer importar anúncios de outra conta? Quer trocar seu template? 			var swiping = false;

				e.preventDefault();

				e.preventDefault();

				clearInterval(interval);
				interval = null;

				actualIndex++;
				if (actualIndex >= $slides.length) {
					actualIndex = 0;
				}

				updateSlides(actualIndex);
			});

			$prev.click(function (e) {
				e.preventDefault();
				if (swiping) { return; }
				swiping = true;

				clearInterval(interval);
				interval = null;

				actualIndex--;
				if (actualIndex < 0) {
					actualIndex = $slides.length - 1;
				}

				updateSlides(actualIndex);
			});

			function updateSlides(index) {
				// update nav dots
				$navDots.removeClass("active");
				$navDots.eq(index).addClass("active");

				// update slides
				var $activeSlide = $("#hero .slide.active");
				var $nextSlide = $slides.eq(index);

				$activeSlide.fadeOut();
				$nextSlide.addClass("next").fadeIn();
				
				setTimeout(function () {
					$slides.removeClass("next").removeClass("active");
					$nextSlide.addClass("active");
					$activeSlide.removeAttr('style');
					swiping = false;
				}, 1000);
			}
