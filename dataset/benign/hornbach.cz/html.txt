<div class="seoHeadline">
<h1>Podzim je obdobím renovací - s HORNBACHem to zvládnete!</h1>
</div>
<div class="seoText">
<h3 class="seoTextHeadline"> </h3>
<p><strong>HORNBACH</strong> je určen pro opravdové machry. Pro lidi, kteří chtějí vytvořit něco nového svou vlastní vůlí a vlastníma rukama nebo obnovit to zašlé. Tak dlouho šroubovat, řezat a natírat, dokud vše nebude jako nové. Je naší vášní pomáhat těmto lidem. Proto jsou každý den připraveny tisíce našich zaměstnanců. Jak v našich <a href="/cms/cs/cz/o_hornbachu/moje_prodejna/prodejny_hornbach/prodejny_hornbach.html">prodejnách</a>, tak v <a href="/shop/sortiment/sortiment.html">e-shopu</a> na vás čeká komplexní poradenství a ten nejlepší sortiment pro každý projekt.</p><p>A teď je ten správný čas - podzim – období renovací a rekonstrukcí - právě začal! Podzim bývá nejlepší čas připravit váš byt nebo dům pro pohodlnou zimu. Začněte instalací nových <a href="/shop/Krbova-kamna-a-krbove-vlozky/S12497/seznam-zbozi.html">krbových kamen</a> nebo si alespoň nezapomeňte doplnit zásoby <a href="/shop/Brikety-pelety-palivove-drevo-a-dalsi-paliva/S12498/seznam-zbozi.html">palivového dřeva, pelet a dalších paliv</a>. Pokračovat pak můžete rekonstrukcí koupelny a <a href="/shop/Koupelnova-keramika/WC/S11600/seznam-zbozi.html">WC</a>. Například <a href="/shop/Obklady-dlazby-a-prislusenstvi-obkladu-a-dlazeb/Mozaiky/S11832/seznam-zbozi.html">mozaiky</a> jsou nevyčerpatelnou zásobou inspirativních dekórů a barev. Ale hodit se vám jistě bude i nová <a href="/shop/Vany/S11638/seznam-zbozi.html">vana</a>, <a href="/shop/Sprchy/S11576/seznam-zbozi.html">sprchový kout</a> nebo <a href="/shop/Vodovodni-baterie/S11568/seznam-zbozi.html">koupelnová baterie</a>. Bez pořádného <a href="/shop/Interierove-osvetleni/S12695/seznam-zbozi.html">interiérového osvětlení</a> není žádný prostor perfektní. Koupelnou to ale nemusí skončit! Vytvořte si krásný interiér i v dalších místnostech – vyberte si z naší široké nabídky <a href="/shop/Obklady-dlazby-a-prislusenstvi-obkladu-a-dlazeb/Dlazby/S11831/seznam-zbozi.html">dlažeb</a>, <a href="/shop/Dekorace-do-bytu/Bytovy-textil/Zaclony/S12556/seznam-zbozi.html">záclon a závěsů</a>, <a href="/shop/Podlahove-krytiny/Laminatove-podlahy/S11807/seznam-zbozi.html">laminátových podlah</a>, <a href="/shop/Barvy-laky/Interierove-barvy-a-omitky/S12056/seznam-zbozi.html">interiérových barev</a> nebo <a href="/shop/Barvy-laky/Interierove-barvy-a-omitky/Vnitrni-omitky/S12060/seznam-zbozi.html">strukturálních omítek</a>. A nezapomeňte vše uzavřít za uzamykatelné <a href="/shop/Vchodove-dvere/S11799/seznam-zbozi.html">dveře</a>. A co třeba nově vydlážděný nájezd do garáže s novým <a href="/shop/Zahradni-domky-a-garazove-pristresky/Pristresky-na-auto/S12226/seznam-zbozi.html">přístřeškem pro auto</a>?</p><p>I na zahradě na vás čeká spousta úkolů. Přeci jen je podzim a padá listí. Chopte se svého <a href="/shop/Zahradni-technika/S12133/seznam-zbozi.html">zahradního nářadí</a> a jděte porazit stále padajícího nepřítele. Až <a href="/shop/Zahradni-technika/Vysavace-listi-a-fukary-na-listi/S12332/seznam-zbozi.html">vysavač listí</a> odstraní poslední lísteček z vaší posvátné půdy, je na čase se postarat o zazimování <a href="/shop/Volny-cas-na-zahrade/Bazeny-a-prislusenstvi/Pece-o-bazen-a-cisteni-bazenu/S12200/seznam-zbozi.html">bazénu</a>.</p><p>Nehledě na to, že je stále co dělat, je nutné mít také kam dát před nadcházející zimou vaše <a href="/shop/Stroje-a-pristroje-pro-stavbu/Stavebni-kolecka-zahradni-kolecka/S12912/seznam-zbozi.html">kolečka</a>, <a href="/shop/Zahradni-technika/Retezove-pily/S12337/seznam-zbozi.html">řetězové pily</a>, <a href="/shop/Skladovani-naradi-a-uskladneni/Kufry-na-naradi/S12821/seznam-zbozi.html">kufry na nářadí</a>, <a href="/shop/Substraty-a-hnojiva/Substraty-a-mulcovaci-kura/Mulcovaci-a-dekoracni-kura/S12438/seznam-zbozi.html">mulčovací kůru</a>, případně <a href="/shop/Zebriky-schudky-a-leseni/Leseni/S12921/seznam-zbozi.html">lešení</a> nebo <a href="/shop/Naradi/Pily/Stolni-pily/S12788/seznam-zbozi.html">stolní pily</a>. Vše můžete úhledně naskládat do <a href="/shop/Regaly-a-regalove-systemy/S12781/seznam-zbozi.html">regálu</a>, na větší kusy jsou ideálním řešením <a href="/shop/Zahradni-domky-a-garazove-pristresky/Zahradni-domky/S12224/seznam-zbozi.html">zahradní domky</a>. Uvidíte, že padnou jako ulité na vaší zahradu, kterou jste si vytvořili svýma vlastníma, holýma rukama.</p>
<div class="additional-text collapse">
<h2 class="seoTextAdditionalHeadline"> HORNBACH – inspirace pro vaše projekty</h2>
<p>V HORNBACHu vám rádi poradíme s vašimi zahradními, stavebními a bytovými projekty. Pomocí našich projektových návodů pro <a href="/cms/cs/cz/sortiment/zahrada.html">zahradu</a>, <a href="/cms/cs/cz/sortiment/stavebniny_drevo_okna_dvere.html">stavbu</a> nebo <a href="/cms/cs/cz/sortiment/koupelna_a_sanitrni_zarizeni.html">koupelnu a sanitární zařízení</a> zvládnete vše mnohem snadněji. Ukážeme vám, jak na to a vy se budete moci rovnou pustit do díla! Vy máte schopnosti, my zkušenosti!</p>
