<h2 style="margin-top:10px;">What is an MD5 hash?</h2>
<p>  An MD5 hash is created by taking a string of an any length and encoding it into a 128-bit   fingerprint. Encoding the same string using the MD5 algorithm will always result in the same 128-bit hash output. MD5 hashes are commonly used with smaller strings when storing passwords, credit card numbers or other sensitive   data in databases such as the popular MySQL. This tool provides a quick and easy way to encode an MD5 hash from a simple string of up to 256 characters in length. </p>
<p>MD5 hashes are also used  to ensure the data integrity of  files. Because the MD5 hash algorithm always produces the same output for the same given input, users can compare a hash of the source file with a newly created hash of the destination file to check that it is intact and unmodified. <span class="ezoic-adpicker-ad" id="ezoic-pub-ad-placeholder-104"></span><span class="ezoic-ad box-3 adtester-container adtester-container-104" data-ez-name="md5hashgenerator_com-box-3" style="display:block !important;float:none;margin-bottom:15px !important;margin-left:0px !important;margin-right:0px !important;margin-top:15px !important;min-height:90px;min-width:728px;text-align:center !important;"><span class="ezoic-ad" data-google-query-id="CNSe8qG5suUCFY1jFQgdJ6MG9w" ezah="90" ezaw="728" id="div-gpt-ad-md5hashgenerator_com-box-3-0" style="position: relative; z-index: 0; min-height: 90px; min-width: 728px;"><div id="google_ads_iframe_/1254144/md5hashgenerator_com-box-3_0__container__" style="border: 0pt none;"><iframe data-google-container-id="f" frameborder="0" height="90" id="google_ads_iframe_/1254144/md5hashgenerator_com-box-3_0" marginheight="0" marginwidth="0" name="google_ads_iframe_/1254144/md5hashgenerator_com-box-3_0" scrolling="no" srcdoc="" style="border: 0px; vertical-align: bottom;" title="3rd party ad content" width="728"></iframe></div></span></span></p>

<h3>What is an MD5 Hash?</h3>
<p>
MD5 is a 128 bit "message-digest" algorithm that was released in 1991. It creates a 16 byte hash value for the input of the algorithm.  MD5 is one-way, meaning that the original input cannot be be determined simply by knowing the hash value.  MD5 was also intended to be collision resistant, meaning that two inputs could not have the same hash value, until 2004 when it was determined not to be resistant.
</p> 
<h3>When and why would you use MD5 Hash?</h3>
<p>
MD5 is often used as a <a href="http://en.wikipedia.org/wiki/Checksum">checksum</a> algorithm.  Text or files are fed into the MD5 algorithm and the resulting hash would change if the file had been changed.  This is done to detect malicious tampering, or file corruption.<p />

MD5 has also historically been used as a password hashing algorithm.  Password hashing algorithms allow a password to be stored, in a website's database for instance, without having to store the actual password.  This makes it more difficult to steal passwords, and if the hash is taken, the user's password is not necessarily compromised.  When using a hashing algorithm for passwords it is wise to use "salt".  With MD5, salt is added by concatinating a string unrelated to the password to the user supplied password string. MD5 has since been deemed too weak for this, and was succeeded by <a href="/sha1-hash-generator">SHA-1</a> and then <a href="http://en.wikipedia.org/wiki/SHA-2">SHA-2</a>.
</p>
