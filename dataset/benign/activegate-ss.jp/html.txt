<section class="section-box approach-box2" id="approach2">
<div class="inner wide">
<h2 class="section-ttl ttl02">誤送信防止のための7つのアプローチ</h2>
<p><span class="pc-line-break">人的ミス、意図的な情報漏えいに関わらず、「Active! gate SS」はこれらをシステムによる対策でカバーします。</span></p>
<!--<p class="note">※選択したプランにより使用できる機能は異なります。</p>-->
<ul class="apblock">
<li class="apblock_item"><img alt="" src="images/ap_icon01.png"/>
<h3>送信メールの一時保留</h3>
<p>設定した条件によって送信メールを一定時間隔離・保留し、「うっかりミス」を防ぎます。</p>
</li>
<li class="apblock_item"><img alt="" src="images/ap_icon03.png"/>
<h3>時間差配信</h3>
<p>社内と社外を時間差配信することで、社外にメールが届く前にミスに気づくことが可能です。</p>
</li>
<li class="apblock_item"><img alt="" src="images/ap_icon06.png"/>
<h3>添付ファイルの暗号化</h3>
<p>メール送信時に添付ファイルをパスワード付きのファイルに自動変換します。</p>
</li>
<li class="apblock_item"><img alt="" src="images/ap_icon04.png"/>
<h3>添付ファイルの<br/>Webダウンロード</h3>
<p>添付ファイルをメール本文と分離し、パスワードを利用して別途ダウンロードします。</p>
</li>
<li class="apblock_item"><img alt="" src="images/ap_icon05.png"/>
<h3>Bcc強制変換</h3>
<p>ToやCcに一定個数以上のアドレスがある場合、Bccに自動変換します。</p>
</li>
<li class="apblock_item"><img alt="" src="images/ap_icon02.png"/>
<h3>送信拒否</h3>
<p>条件によりメールの送信自体を拒否します。送信拒否を通知するバウンスメールを送信可能です。</p>
</li>
<li class="apblock_item"><img alt="" src="images/ap_icon07.png"/>
<h3>上司承認</h3>
<p>メール送信者の上司（承認者）が承認しない限りメールが送信されません。上司がメールの内容を精査した上で社外に送信されます。</p>
</li>
</ul>
