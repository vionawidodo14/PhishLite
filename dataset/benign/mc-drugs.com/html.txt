Halloween Tag Crate keys can be purchased from our store, but Halloween Crate Keys can (currently) only be acquired by opening Trick or Treat baskets.<br/>
<br/>
The Halloween Sale has started on <a class="externalLink" href="http://store.mc-drugs.com/" rel="nofollow" target="_blank">our store</a>, and will run until the end of the month. Check out the deals, as well as the <b>Halloween donator rank prefixes </b>- buying any rank in October, or purchasing the prefix upgrade, will grant you access to use the Halloween-themed VIP, VIP+, MVP, MVP+, and MVP++ rank prefixes for whichever rank(s) you own.

<a href="threads/farm-world-2-0.9951/">Farm World 2.0</a>
</div>
<div class="primaryContent">
<div class="metaData">
<span class="statData"><div class="keyIcon comments"></div>3</span>
<span class="statData"><div class="keyIcon views"></div>849</span>
<span class="dateData">
<div class="keyIcon sticky"></div>
					by <a class="username" href="members/dakotaa.4/">Dakotaa</a> : <a href="threads/farm-world-2-0.9951/">Aug 17, 2019</a> at <a href="threads/farm-world-2-0.9951/">5:14 PM</a>
</span>
</div>
<div class="baseHtml excerptContent">
<img alt="[​IMG]" class="bbCodeImage LbImage" data-url="https://i.imgur.com/2ZvfN95.png" src="https://i.imgur.com/2ZvfN95.png" style=""/><br/>
<br/>
<b>I'd like to start this post by making it very clear that nothing is being reset - nothing is being removed or lost. The new content described below will be in addition to the current farm world.<br/>
</b><br/>
The addition of the Farm World is one of the largest changes we've made to the server, and we're glad to see how it's been used over the first couple months of the map. Recently, we took a feedback survey for the farm world, and received some very useful responses. With this data, some major changes have been made to the farm world. These changes are our attempt to make the farm world much more welcoming and lessen the gameplay impact of choosing to play there.<br/>
<br/>
<span style="font-size: 22px">New Farm World</span><br/>
<ul>
<li>A fresh world is available on /farm. You can get there by doing <b>/espawn </b>while in the Farm world (<b>/farm</b>).</li>
<li>Like the original world, this new world is completely ocean, however it is natural ocean, meaning there are structures, caves, and lava pools underground. Hopefully this will be a hard counter to the tunneling "meta" that many players have been taking advantage of in the original world.</li>
<li>The new world has ores and all other resources found in ocean biomes.</li>
<li>The border of the new world is 8000 in each direction, same as the original world currently is. In the future, the new world's border will continue to expand, while the old one will not.</li>
</ul><span style="font-size: 22px">Other Changes</span><br/>
<ul>
<li>Vote Parties  will now happen on Farm as well as Spawn/Wild.</li>
<li>Mob spawning has been enabled in Farm, however spawners will only spawn mobs half as fast as in Wild.</li>
<li>Kits now work on both servers. The kit cooldowns are separate on Farm from Spawn/Wild, so to keep it balanced we have doubled the kit cooldown time for every kit. The cooldown time is technically the same as before as long as you claim the kit both on Farm and on Spawn/Wild.</li>
<li>Obsidian now takes 3 TNT hits to destroy instead of 2 on the Farm world....</li>
</ul>
