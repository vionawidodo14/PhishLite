<div class="stx">
<p></p><h3>Welcome to the Pure Data site!</h3><p></p>
<p>This site is a contribution of the <span class="link-external"><a href="http://iem.at/">IEM</a></span> to the Pure Data community. Every Pure Data user who wants to contribute is welcome to <a href="/join_form">join</a> this portal and write/contribute some documentation, reports, news, comments and announcing events. The site is run on a Linux server with <span class="link-external"><a href="http://zope.org">Zope</a></span>  / <span class="link-external"><a href="http://plone.org/">plone</a></span> and administrated and driven by the Pure Data community.</p>
<p><br/></p>
<p></p><h2>About Pure Data (aka Pd)</h2><p></p>
<p><br/></p>
<p><strong>Pure Data</strong> (or just <code>Pd</code>) is an open source visual programming language for multimedia. Its main distribution (aka <code>Pd Vanilla</code>) is developed by <span class="link-external"><a href="http://msp.ucsd.edu/">Miller Puckette</a></span>. <strong>Pd-L2ork/Purr-Data</strong> is an alternative distribution (originally based on the now unmaintained, dead and deprecated <a href="/downloads/pd-extended">Pd-Extended</a> project), with a revamped GUI and many included external libraries.</p>
<p><br/><br/></p>
<p></p><h2>Get Pure Data (Linux/Mac/Windows)</h2><p></p>
<p><br/></p>
<p></p><h4 style="font-size:120%; text-decoration:none"><u><a href="/downloads/pure-data">Download Pure Data</a></u></h4><p></p>
<p><strong>What's New?</strong> As of Pd 0.47-0, the <b><a href="/docs/Deken">Deken</a> library manager</b> is included for easy access to community-developed external libraries that expand the capabilities of Pd such as <a href="/downloads/cyclone">Cyclone</a>, <a href="/downloads/zexy">zexy</a>, and the computer graphics library <a href="/downloads/gem/">Gem</a>. For more details on new developments, see the <span class="link-external"><a href="http://msp.ucsd.edu/Pd_documentation/x5.htm#s1">Release notes</a></span>.</p><p></p>
<p><br/>
</p><h4 style="font-size:120%; text-decoration:none"><u><a href="/downloads/purr-data">Download Pd-L2ork 2.x (Purr Data)</a></u></h4><p></p>
<p><strong>What's New?</strong> Pd-L2ork has a new cross-platform 2.x version nicknamed <strong>Purr Data</strong>. <a href="/downloads/Pd-L2Ork">Pd-L2ork 1.x</a>  is still available as well (Linux only), whereas Purr Data is available for <strong>Linux/Mac/Windows</strong>. More details in the linked download pages.</p>
<p>Find other Pd goodies to download at the <u><a href="/downloads">Downloads page</a></u></p>
<p><br/><br/></p>
<p></p><h2>More about Pure Data</h2><p></p>
<p><br/></p>
<p>Pure Data is an open source visual programming environment that runs on anything from personal computers to embedded devices (ie <a href="/docs/raspberry-pi">Raspberry Pi</a>) and smartphones (via <a href="/downloads/libpd">libpd</a>, <a href="/downloads/pddroidparty">DroidParty (Android)</a>, and <span class="link-external"><a href="http://github.com/danomatika/PdParty">PdParty (iOS)</a></span>.
It is a major branch of the family of patcher programming languages known as Max (Max/FTS, ISPW Max, <span class="link-external"><a href="http://cycling74.com/">Max/MSP</a></span>, etc), originally developed by Miller Puckette at <span class="link-external"><a href="http://www.ircam.fr/">IRCAM</a></span>.</p>
<p>Pd enables musicians, visual artists, performers, researchers, and developers to create software graphically without writing lines of code. Pd can be used to process and generate sound, video, 2D/3D graphics, and interface sensors, input devices, and MIDI. Pd can easily work over local and remote networks to integrate wearable technology, motor systems, lighting rigs, and other equipment. It is suitable for learning basic multimedia processing and visual programming methods as well as for realizing complex systems for large-scale projects.</p>
<p>Algorithmic functions are represented in Pd by visual boxes called <strong>objects</strong> placed within a patching window called a <strong>canvas</strong>. Data flow between objects are achieved through visual connections called <strong>patch cords</strong>. Each object performs a specific task, which can vary in complexity from very low-level mathematical operations to complicated audio or video functions such as reverberation, FFT transformations, or video decoding. Objects include core Pd vanilla objects, external objects or <strong>externals</strong> (Pd objects compiled from C or C++), and <strong>abstractions</strong> (Pd patches loaded as objects).</p>
<p></p><h2>Documentation and resources</h2><p></p>
<p>Please check the <a href="/docs">documentation page</a>, where you can find <a href="/docs/ResourcesToStartLearning/">Resources to start learning</a>, <a href="/docs/BooksAboutPd/">Books about Pd</a>, <a href="/docs/manuals/">Manuals</a> and more!</p>
<p>Also check out the <span class="link-external"><a href="http://www.pdpatchrepo.info/">Pure Data patch Repository</a></span></p>
<p>Find Pd people on <span class="link-external"><a href="http://www.facebook.com/groups/4729684494/">Facebook</a></span> and <span class="link-external"><a href="http://www.reddit.com/r/puredata/">Reddit</a></span> and join us on our <span class="link-external"><a href="http://lists.puredata.info/listinfo/pd-list">mailing list</a></span> (more on the <u><a href="/community">Community page</a></u> )</p>
