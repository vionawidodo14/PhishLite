<div class="modal-body">
<div class="browser-info" data-browser="chrome">
<p>Please click <strong>Add Extension</strong> on the dialog that Chrome opened to install FrankerFaceZ.</p>
<p>If Chrome didn't open a dialog, please <a class="text-success" href="https://chrome.google.com/webstore/detail/frankerfacez/fadndhdgpmmaapbmfcknlfgcflmmmieb">click here</a> to open the Chrome Web Store.</p>
<hr/>
<p>Problems installing? Try running the <a class="text-success" href="https://www.google.com/chrome/cleanup-tool/index.html" target="_blank">Chrome Cleanup Tool</a> to fix issues with your browser and then try again.</p>
<p>Getting "Network Failed"? Try reinstalling Chrome as that's an indicator that your browser has become corrupted.</p>
</div>
<div class="browser-info" data-browser="firefox">
<p>Please click <strong>Allow</strong> and <strong>Install</strong> on the dialogs that Firefox opens to install FrankerFaceZ.</p>
<hr/>
<p>Problems installing? Try <a class="text-success" download="" href="https://cdn.frankerfacez.com/script/frankerfacez-4.0-an+fx.xpi">right-clicking and saving this file</a> and then opening it locally.</p>
<p>Still not working? You might have an issue with corrupt extension files. Follow <a class="text-success" href="https://support.mozilla.org/en-US/kb/unable-install-add-ons-extensions-or-themes#w_corrupt-extension-files" target="_blank">these instructions</a> and then try again.</p>
<p>(Note: Please be sure to remove any extensions that you downloaded from websites other than Firefox's Add-ons store before following those instructions. You can reinstall them after, but leaving them installed when you delete the extension data files may cause the extensions to become unusable.)</p>
</div>
<div class="browser-info" data-browser="us">
<p>Your browser may be able to make use of a user script directly.</p>
<p>If your browser cannot use the script, you'll need to get an
extension for dealing with user scripts such as
<a class="text-success" href="https://tampermonkey.net/" target="_blank">Tampermonkey</a>.</p>
</div>
<div class="browser-info" data-browser="edge">
<p>FrankerFaceZ does not currently have an extension built for Microsoft Edge.
However, Tampermonkey <em>does</em> and it can be used to load the FFZ user script.</p>
<hr/>
<p>First, <a class="text-success" href="https://www.microsoft.com/store/apps/9NBLGGH5162S" target="_blank">install
Tampermonkey</a> from the Windows Store if you don't already have it.</p>
<p>Once that's installed, please <a class="text-success" href="https://cdn.frankerfacez.com/script/ffz_injector.user.js">click here</a>
to add the user script to Tampermonkey.</p>
</div>
<div class="browser-info" data-browser="safari">
<p>
Apple has decided to deprecate their previous extension model for Safari, in favor of what they're calling
Safari App Extensions. We have decided as a result that it is infeasible to provide support for Safari going
forward. Our user script will still function in Safari, but we will no longer be providing packaged extensions.
</p>
<hr/>
<p>
To use FrankerFaceZ with Safari, you'll need to install an extension capable of loading user scripts such as
<a class="text-success" href="https://tampermonkey.net/?browser=safari" target="_blank">Tampermonkey</a>.
</p>
<p>
Once you have an extension for user scripts, please
<a class="text-success" href="https://cdn.frankerfacez.com/script/ffz_injector.user.js">click here</a>
to get the FrankerFaceZ user script.
</p>
</div>
<hr/>
<p>Once FrankerFaceZ is installed, remember to refresh all your open Twitch tabs so that it will load.</p>
</div>

    var modal = $('#instruction');
    $('.download-btn').click(function(e) {
        var browser = this.getAttribute('data-browser');

        // Hide instructions for all browsers first.
        modal.find('[data-browser]').hide();

        // If we have instructions for this browser, show them and the  modal.
        if ( modal.find('[data-browser="' + browser + '"]').show().length )
            modal.modal('show');

        // If it's Chrome, we want to do the inline installation.
        if ( browser === 'chrome' ) {
            e.preventDefault();
            chrome.webstore.install();

        } else if ( browser === 'edge' || browser === 'safari' )
            e.preventDefault();
    });
