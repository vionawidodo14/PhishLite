<h1>Огласи за работа и совети за кариера - сè на едно место!</h1>
<p>Во потрага сте по првата работа или сакате да ја промените постоечката и да најдете подобра? Вие сте на вистинското место бидејќи vrabotuvanje.com.mk е водечки портал за огласување на слободни работни места со најголем број огласи за вработување во Македонија. Улогата на порталот е поврзување на работобарателите и работодавците. На порталот, можете да пребарувате слободни работни места по категории или области, а достапна е и понуда за вработување во странство. Освен огласи за работа, во <strong>рубриката Вести</strong> можете да прочитате за актуелните случувања на пазарот на труд во Македонија и во светот, а во <strong>рубриката Совети </strong>ќе пронајдете корисни информации за процесот на селекција, развојот на кариерата, психолошките тестирања, примери за кратки биографии и молби за вработување и правила за деловно однесување. Со креирање на <strong>онлајн биографија, т.н. Профил</strong> вие, како работобарател, имате можност да им се претставите на работодавците кои бараат нови вработени преку порталот vrabotuvanje.com.mk. Предноста на профилот е во тоа што тој ви овоможува на едно место да ги зачувате сите важни документи за аплицирање на оглас, да ги следите претходните апликации и да зачувувате огласи кои вам ви се интересни. За работодавците да можат полесно да ве најдат во базата со профили, неопходно е да го пополните профилот со што е можно повеќе релевантни информации.</p><br/>
<br/>
<p>За да им се овозможи на работодавците подобро да ја претстават својата компанија, креирани се <em><strong>Профили на работодавачи</strong></em>, кои освен што ги обезбедуваат сите релевантни информации за одредена компанија, овозможуваат и “следење“ на работодавачот. Да го следите работодавачот значи да добивате известувања за нови слободни работни места и други важни деловни вести поврзани со компанијата, директно во вашето сандаче на профилот. Огласите за вработување кои се објавени на порталот, исто така, може да се следат преку профилите на vrabotuvanje.com.mk на социјалните мрежи. Преку анализа на платата на <a href="https://www.mojaplaca.hr" target="_blank"><strong>MojaPla</strong><strong>t</strong><strong>a.</strong><strong>mk</strong></a>, можете да се подготвите за интервју за работа кога на ред ќе дојде прашањето за плата. Бесплатната анализа на платата вклучува основни информации – износот на просечната плата за избраната позиција и споредба на платата со колегите од Србија, Хрватска, Босна и Херцеговина, Романија и Бугарија. Во проширената анализа е вклучена споредба на платата според работно искуство и регион, преглед на бенефиции за вашата работна позиција и совети за преговарање за плата.</p><br/>
<br/>
<p>Vrabotuvanje.com.mk организира и учествува во серија проекти насочени кон развој на кариерата на лицата кои бараат работа. Најзначајниот меѓу нив е <strong>Виртуелни денови за вработување </strong>достапен на <strong><a href="https://www.dankarijera.com/">www.denovizavrabotuvanje.mk</a></strong>. Виртуелниот саем за вработување трае осум денови и ви овозможува да аплицирате на огласи за вработување, преглед на понудите за едукација, како и комуникација со потенцијалниот работодавач или образовна институција од удобноста на вашиот дом. Порталот е посветен на развој на човечките ресурси и преку соработка на проекти финансирани од ЕУ. </p><br/>

	var w = 0;

	var adsGrid =
	{
		container: null,

		columns: null,

		init: function()
		{
			this.container = $('#featured-jobs');
			this.columns = $('ul', this.container);

			if (!this.columns.length)
			{
				return;
			}

			adsGrid.reorderAll();
			adsGrid.normalize();

			$(window).bind('resize orientationchange', function ()
			{
				if (w != $(window).width())
				{
					// do only on width resize - fixes 'bug' on mobile chrome
					w = $(window).width();
					// check if there are hidden full columns or visible empty ones
					// dont reorder on single column views
					adsGrid.reorderAll();
					adsGrid.normalize();
				}
			});
		},

		/*
		 * normalize column height
		 */
		normalize: function()
		{
			// dont normalize heights of single column views
			if (this.container.width() <= 480) return;

			var elements = [];

			// normalize only visible columns
			var $columns = this.columns.filter(':visible');

			$columns.each(function()
			{
				var $items = $(this).children('li').slice(-5);

				$items.each(function()
				{
					$(this).data('height', $(this).height());

					elements.push($(this));
				});
			});

			elements.sort(function(a, b)
			{
				return b.data('height') - a.data('height');
			});

			for (var i in elements)
			{
				// Remove elements from DOM (keeps stored data)
				elements[i].detach();
			}

			$columns.each(function()
			{
				$(this).data('height', $(this).height());
			});

			var $firstCol = $columns.first();

			for (var i in elements)
			{
				var $smallest = $firstCol;

				$columns.each(function()
				{
					if ($(this).data('height') < $smallest.data('height'))
					{
						$smallest = $(this);
					}
				});

				$smallest.append(elements[i]);
				$smallest.data('height', $smallest.data('height') + elements[i].data('height'));
			}
		},

		reorderAll: function ()
		{
			// TODO the need for this function on mobile sucks

			adsGrid.columns.each(function ()
			{
				if (($(this).children().length == 0 && $(this).is(':visible')) || $(this).children().length > 0 && $(this).is(':hidden'))
				{
					adsGrid.reorder();
					return false;
				}
			});
		},

		/*
		 * order elements by index
		 */
		reorder: function()
		{
			var $elementCount = $('li', this.columns).length;
			// only visible columns
			var $columnCount = $('ul:visible', this.container).length;
			// element index
			var $elementIndex = 1;
			// column index
			var $columnIndex = 0;

			while ($elementIndex <= $elementCount)
			{
				var column = this.columns.eq($columnIndex);

				column.append($('li[data-index=' + $elementIndex + ']', this.columns));

				// console.log($columnIndex + ' - ' + $elementIndex);

				$columnIndex++;
				$elementIndex++;

				if ($columnIndex > ($columnCount - 1))
				{
					$columnIndex = 0;
				}
			}
		}
	};
	adsGrid.init();

</script>
