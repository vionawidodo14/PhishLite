<div id="why">
<div class="row">
<div class="col-md-4">
<h4><i class="fa fa-cogs"></i> World-class JSON Serializer</h4>
                Serialize and deserialize any .NET object with Json.NET's powerful JSON serializer.
            </div>
<div class="col-md-4">
<h4><i class="fa fa-magic"></i> LINQ to JSON</h4>
                Create, parse, query and modify JSON using Json.NET's JObject, JArray and JValue objects.
            </div>
<div class="col-md-4">
<h4><i class="fa fa-search"></i> JSON Path</h4>
                Query JSON with an XPath-like syntax. Find out more about JSON Path
                <a href="http://goessner.net/articles/JsonPath/" target="_blank">here</a>.
            </div>
</div>
<div class="row">
<div class="col-md-4">
<h4><i class="fa fa-bolt"></i> High Performance</h4>
                50% faster than DataContractJsonSerializer, and 250% faster than JavaScriptSerializer.
            </div>
<div class="col-md-4">
<h4><i class="fa fa-smile-o"></i> Easy To Use</h4>
                Json.NET makes the simple easy and the complex possible.
            </div>
<div class="col-md-4">
<h4><i class="fa fa-code"></i> XML Support</h4>
                If you need it, Json.NET supports converting between XML and JSON.
            </div>
</div>
<div class="row">
<div class="col-md-4">
<h4><i class="fa fa-github"></i> Open Source</h4>
                Json.NET is open source software and is completely
                <a href="https://github.com/JamesNK/Newtonsoft.Json/blob/master/LICENSE.md" target="_blank">free for commercial use</a>.
            </div>
<div class="col-md-4">
<h4><i class="fa fa-android"></i> Run Anywhere</h4>
                Json.NET supports Windows, Windows Store, Windows Phone, Mono, and Xamarin.
            </div>
<div class="col-md-4">
<h4><i class="fa fa-heart"></i> Most Popular .NET library</h4>
                Over 100 million downloads and counting, Json.NET is the number one library on NuGet.
            </div>
</div>
</div>
