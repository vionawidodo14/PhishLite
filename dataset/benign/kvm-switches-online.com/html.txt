text-align: left; margin-top: 20px;"><span style="font-weight: 500">Types of</span> KVM Switch</h3><ul class="unstyled listFeat" style="border-top: 1px #eee solid; padding-top: 14px; margin-top: 0px;"><li><img alt="USB KVM Switch" border="0" class="ignore-image" height="150" src="https://sep.yimg.com/ty/cdn/kvm-switch/Index-KM-Switches.jpg" style="width: auto; height: auto; max-height: 150px;" width="225"/> <div class="content"><h4 class="title">USB</h4><p style="margin-top: 0px;">A Switch that uses USB cables for keyboard and mouse connections. Some USB switches will also allow PS/2 connections and some will allow sharing of other USB devices such as printers. Other things to look for in a USB switch include ability to share audio and wireless keyboard/mouse connectivity. Also remember to note which USB specification the switch supports.</p></div></li><li><img alt="DVI KVM Switch" border="0" class="ignore-image" height="150" src="https://lib.store.yahoo.net/lib/kvm-switch/AdderView-Pro-Banner.png" style="width: auto; height: auto; max-height: 150px;" width="225"/> <div class="content"><h4 class="title">DVI</h4><p style="margin-top: 0px;">A switch for use with a DVI compatible monitor or monitors. While the standard monitor connection is typically VGA, DVI monitors are becoming more popular and widely available. DVI switches often have increased resolution capabilities</p></div></li><li class=""><img alt="HDMI KVM Switch" border="0" class="ignore-image" height="200" src="https://sep.yimg.com/ty/cdn/kvm-switch/index-extenders.jpg" style="width: auto; height: auto; max-height: 150px;" width="200"/> <div class="content"><h4 class="title">HDMI</h4><p>A new emerging market for KVMs includes HDMI ready switches like the SmartAVI HKM-02S HDMI KVM. As one might imagine, these switches are used for connecting HDMI compatible displays. This is especially useful in the audio / visual production field, as well as medical professions where high resolution displays are required. Another use for an HDMI KVM switch is for home theater setups, where a tower and laptop might share a large High-Def television.</p></div></li><li class="clearfix"><img alt="DisplayPort KVM Switch" border="0" class="ignore-image" height="150" src="https://sep.yimg.com/ca/I/kvm-switch_2268_24194609" style="width: auto; height: auto; max-height: 150px;" width="225"/> <div class="content"><h4 class="title">DisplayPort</h4><p>Another new market is for switches which support DisplayPort technology. With monitor manufacturers moving away from VGA and DVI-I interfaces, availability of switches like the Adder AV4PRO-DP-US DisplyPort KVM will become more important.</p></div></li><li class=""><img alt="Dual Display KVM Switch" border="0" class="ignore-image" height="200" src="https://sep.yimg.com/ty/cdn/kvm-switch/Index-Dual-Monitor-KVM-Switch.jpg" style="width: auto; height: auto; max-height: 150px;" width="200"/> <div class="content"><h4 class="title">Multi-Display</h4><p>A multi-display switch will allow for extended desktops across two or more displays. These space saving monitor drawers provide convenient access to servers right at the server cabinet. One import consideration is the type of mounting rails used for the LCD drawer. Not all rails will work in all server racks.</p></div></li><li class="clearfix"><img alt="Adder LED Light Module for CCS-PRO4 Free-Flow Switch" border="0" class="ignore-image" height="150" src="https://sep.yimg.com/ty/cdn/kvm-switch/Index-KVM-Over-IP2.jpg" style="width: auto; height: auto; max-height: 150px;" width="225"/> <div class="content"><h4 class="title">KVM-over-IP</h4><p style="margin-top: 0px;">IP switches use a browser to securely access servers/computers over the internet or LAN. IP KVMs are an excellent replacement for software based remote access packages such as RDP and VNC. Depending on the particular model, benefits of a hardware remote access solution include the ability to cold boot equipment, BIOS level access, port level user profiles, and robust logging.</p></div></li><li><img alt="Adder CCS-PRO4 Dual-AC redundant power" border="0" class="ignore-image" height="150" src="https://sep.yimg.com/ay/kvm-switch/adder-avx1008-diagram-4.gif" style="width: auto; height: auto; max-height: 150px;" width="225"/> <div class="content"><h4 class="title">Multi-User</h4><p style="margin-top: 0px;">A multi-user switch will allow simultaneous access to the switch by more than one user from multiple locations. This is accomplished via extension, Over-IP access or a combination of both. Multi-user switches are an excellent choice for enterprise applications where cross-platform switching is needed by multiple team members.</p></div></li></ul><div class="clearfix"></div></div><div class="divider" style="background-color: #eee;"></div><div class="icon-box-zoom"><div class="container"><h2 class="d5" style="font-weight: 400;
