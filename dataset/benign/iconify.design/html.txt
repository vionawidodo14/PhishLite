<div id="hero"><h1>Unified icons framework</h1><h3>One library, over 40,000 vector icons.<br/>Modern replacement for icon fonts. Fast, easy to use.</h3>
</div>
<div class="intro">
<p>
        There are many excellent icon sets available. Each has its own custom syntax, some are available only as fonts and almost all of them load entire set even if you are displaying just few icons. 
    </p>
<p>
        Iconify tries to combine all those icon sets. Iconify is a unified open source icon framework that makes it possible to use many icons from different icon sets on same page or in same application using one syntax.    
    </p>
<p>
        Iconify combines pixel perfect rendering of SVG with ease of use of glyph fonts, while offering more choice than any glyph font or SVG framework.
    </p>
<p>
        You can use Font Awesome, Material Design Icons, Unicons, Dashicons and many other icon sets on same page or application using one syntax.
    </p>
</div>
<section class="intro-usage">
<h1 class="subtitle">How to use Iconify</h1>
<p>
        Iconify is very easy to use: add one <span class="hljs-tag">&lt;script&gt;</span> tag in head section of your document or before <span class="hljs-tag">&lt;/body&gt;</span> to include Iconify:
    </p>
<div class="sample-input sample-input--script autoselect">&lt;script src="https://code.iconify.design/1/1.0.3/iconify.min.js"&gt;&lt;/script&gt;</div>
<p>
        Then add icons to your page with simple code like this:
    </p>
<div class="sample-input sample-input--script"><span class="autoselect">&lt;span class="iconify" data-icon="fa:home"&gt;&lt;/span&gt;</span><br/><span class="autoselect">&lt;span class="iconify" data-icon="noto:bird"&gt;&lt;/span&gt;</span></div>
<p>
        If you do not want to use script, Iconify is available as <a href="https://github.com/iconify/iconify-react" target="_blank">React</a> and <a href="https://github.com/iconify/iconify-angular" target="_blank">Angular</a> components.
        Also there are tools available for developers to render SVG (<a href="https://github.com/iconify/json-tools.php">for PHP</a>, <a href="https://github.com/iconify/json-tools.js">for Node</a>) and to <a href="https://github.com/iconify/tools">convert icons</a>.     
    </p>
</section>

<h1 class="subtitle">Many icons, one framework</h1>
<p>
        Iconify icons collection includes <a class="subtle" href="/icon-sets/">over 40,000 icons</a> from popular fonts and emoji sets: <span class="subtle-links"><a href="/icon-sets/fa/">Font Awesome 4</a> <a href="/icon-sets/fa-regular/">and 5</a>, <a href="/icon-sets/mdi/">Material Design Icons</a>, <a href="/icon-sets/ion/">IonIcons</a>, <a href="/icon-sets/vaadin/">Vaadin Icons</a>, <a href="/icon-sets/entypo/">Entypo+</a> and many many more.</span> You can use them all on same page without loading multiple glyph fonts. Only icons used on page will be loaded instead of entire fonts. 
    </p>
<p>
        Icon designers can publish their own icon sets too. Iconify offers open source tools to clean up and publish custom icon sets.     
    </p>

<li class="load-on-demand">
<section>
<h1>Load on demand</h1>
<p>Fonts and other SVG frameworks load entire collections. Even if you are using only 10-20 icons, your visitors are forced to load them all.</p>
<p>Iconify works differently. Very differently! Iconify loads only icons used on page. Icons are loaded as external resources that are cached by browser, not embedded into each page. No other SVG framework can do that.</p>
<p>What is advantage of this unique approach to handling icons? You are no longer limited to one collection. You can use them all on same page without having to load megabytes of data!</p>

<h1>Easy to use</h1>
<p>Syntax is similar to glyph fonts. Write a placeholder element, Iconify will replace it with SVG.</p>
<p>Use <span class="hljs-tag">span</span> or <span class="hljs-tag">i</span> or any other HTML tag with <span class="hljs-literal">class="iconify"</span> for inline icons that should be aligned slightly below baseline (just like glyph fonts), use <span class="hljs-tag">iconify-icon</span> tag for block icons used for decorations.</p>
<p>Icons are easy to style with CSS: size is set by <span class="hljs-attribute">font-size</span>, color for monotone icons is set by text <span class="hljs-attribute">color</span>. Just like glyph fonts.</p>
<p>Do not forget to add Iconify <span class="hljs-tag">script</span> tag in head section of your document or before <span class="hljs-tag">&lt;/body&gt;</span>!</p>

<section class="compatibility">
<h1 class="subtitle">Browser compatibility</h1>
<p>Iconify supports all modern browsers.</p>
<p>Older browsers that are supported:</p>
<ul>
<li>Internet Explorer 9 and newer.</li>
<li>iOS Safari for iOS 8 and newer.</li>
<li>Opera Mini and UC Browser are not supported.</li>
</ul>
<p>IE 9, 10 and iOS 8 Safari do not support some modern functions that Iconify relies on. Iconify will automatically load polyfills for those browsers. All newer browsers do not require those polyfills.</p>
</section>
<section class="integration">
<p>Goal of Iconify is to offer unified icon framework for multiple platforms. Currently Iconify is available only as JavaScript library for browsers, React and Angular components.</p>
<p>If you use HTML or CSS syntax, Iconify loads icons from Iconify API. To use Iconify without relying on Iconify API there is possibility to <a href="/docs/api-hosting/">host custom API</a> and <a href="/docs/icon-bundles/">bundle icons with custom scripts</a> or use <a href="https://github.com/iconify/iconify-react" target="_blank">Iconify for React</a> or <a href="https://github.com/iconify/iconify-angular" target="_blank">Angular</a>.</p>
<p>Additionally you can copy or download SVG code. You can use it in editors (if you are using Sketch, check out <a href="https://github.com/iconify/iconify-sketch" target="_blank">Iconify plug-in for Sketch</a>) or embed SVG directly into pages instead of using Iconify JavaScript.</p>
<p>See <a href="/about/">about page</a> to learn more about Iconify and project goals.</p>
</section>
