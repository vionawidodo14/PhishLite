<h1>Apotea.se – ditt apotek på nätet!</h1>
<p>Apotea är apoteket på nätet som alltid har snabba leveranser, bra priser och ett stort sortiment. Hos oss hittar du både receptfria varor och receptbelagda produkter om du vill <a href="/hämta-ut-recept">hämta ut ditt recept</a> för både dig, din familj och dina fyrbenta vänner. Du vet väl att du enkelt kan hämta ut <a href="/recept">djurrecept</a> hos oss genom att logga in med din e-legitimation?<br/>
På Apotea hittar du apoteksprodukter som skickas till dig med snabb leverans om du ligger hemma sjuk med t.ex. <a href="/feber">feber</a>. Vi har även tusentals produkter inom hälsa, skönhet och hudvård. När du hämtar ut recept hos oss tar våra farmaceuter hand om ditt ärende precis som på ett vanligt fysiskt apotek. Om du vill ha rådgivning eller har frågor om dina receptbelagda läkemedel så finns hjälp att få via mejl, telefon eller chatt. Apotea är Sveriges största apotek som enbart finns online.</p>
<p><br/>
På Apotea kan du köpa produkterna till ditt hemmaapotek, oavsett om det handlar om förkylning, <a href="/allergi">pollenallergi</a>, solskydd, <a href="/mage-tarm">orolig mage</a>, feber &amp; <a href="/feber-värk">värk</a>, <a href="/diarré">diarré</a>, huvudlöss, förstoppning eller behandling för <a href="/migrän">migrän</a>. Våra apotekare ger råd om allt från eksem, hemorrojder, ryggvärk, mensvärk till vinterkräksjukan, förstoppning och känslig mage. På Apotea kan du även köpa en mängd olika <a href="/vitaminer-mineraler">vitaminer</a> &amp; mineraler till låga priser. Vi har även brett sortiment inom kategorin mat &amp; dryck där du kan finna goda saker som kan vara en bra grund för en god hälsa. På Apoteas klimatsmarta lager finns ett stort sortiment av hudvårdsmärken som Vichy, ACO, Eucerin, Nivea, Cetaphil, Canoderm, Weleda, Hudosil och Cetaphil. Vi har även produkter från kända varumärken som kan vara bra att ha hemma t.ex. Treo, <a href="/alvedon">Alvedon</a>, Oral-B, Gillette, Otrivin, RFSU och Flux. Apotea har tusentals produkter som är ekologiska och veganska. När du handlar hos oss kan du skänka pengar till SOS Barnbyar och Världsnaturfonden WWF. Tillsammans kan vi göra världen lite bättre och Östersjön lite renare. Apotea har flera år i rad blivit framröstad till Årets nätbutik på Prisjakt och har även blivit utsedd till Sveriges starkaste apoteksvarumärke, E-handelns hetaste varumärke, Gasellföretag och svenskarnas favoritbutik på nätet. På Apotea kan du alltid handla med fri frakt och vi har många fraktalternativ så att du ska kunna få hem dina apoteksprodukter på det sätt som passar dig bäst. På apotea.se finns ett bredare sortiment jämfört med vanliga apotek och du får snabb leverans oavsett om du bor i <a href="https://www.apotea.se/apotek-uppsala">Uppsala</a>, <a href="https://www.apotea.se/apotek-malmo">Malmö</a>, <a href="https://www.apotea.se/apotek-lund">Lund</a>, <a href="https://www.apotea.se/apotek-goteborg">Göteborg</a>, <a href="https://www.apotea.se/apotek-linkoping">Linköping</a>, <a href="https://www.apotea.se/apotek-orebro">Örebro</a>, <a href="https://www.apotea.se/apotek-stockholm">Stockholm</a>, <a href="https://www.apotea.se/apotek-karlstad">Karlstad,</a> <a href="https://www.apotea.se/apotek-umea">Umeå</a>, <a href="https://www.apotea.se/apotek-lulea">Luleå</a> eller någon annanstans i vårt avlånga land. Apotea vill vara det närmaste apoteket oavsett var du bor. Apotea gör det enklare för dig att handla apoteksvaror, snabbt, billigt och fraktfritt.<br/>
Välkommen in till apotea.se!</p>
