<p style="text-align:center;color: #148dc1; font-size:24px;">О Нас</p>
<p class="z-info">Zagruzka - это уникальная закрытая платформа, для внутренней работы между производителями и прямыми поставщиками.<br/>
<br/>
На нашем сервисе у каждого производителя есть личная категория, товар из которой никогда не будет удален и будет доступен для скачивания в любое время, в независимости от сложностей с впн, блокировок и удаления страниц с товаром в социальных сетях.<br/><br/>

Функционал платформы позволяет прямым поставщикам:<br/>
- своевременно увидеть выход новинок;<br/>
- автоматически выгружать эти новинки на свои торговые страницы;<br/>
- с помощью удобного поиска быстро находить товар, описание и кто является его производителем;<br/>
- с помощью возможности Актуализации, получить актуальную базу с товаром;<br/>
- и многое другое.<br/><br/>

Сервис доступен только прямым поставщикам и производителям, что бы не нарушать цепочку «Производитель - поставщик - дропшиппер». Данное решение было принято после мониторинга работы Харькова и реализации данного проекта в Одессе.

    function add_size_for_products(product_ids)
    {
        var curl = $('#curr_url_for_add_size_url').val();
        $.each(product_ids, function( index, product_id ) {
            variant_id = $('#add_size_for_products select').val();

            $.ceAjax('request', curl + '&product_id=' + product_id + '&variant_id=' + variant_id, {
                method: 'GET',
                result_ids: 'will_add_sizes_' + product_id,
                callback: function () {
                    m_self = $('#add_size_for_product_' + product_id);
                    $('#add_size_for_products select').remove();

                    var new_html = m_self.html().replace('hidden', 'may-be-hidden-ec');
                    m_self.html(new_html);
                }
            });
        });
    }

            method: 'GET',
            result_ids: 'will_add_sizes_' + product_id,
            callback: function () {
                $('#will-size_' + product_id + '_' + variant_id).addClass('hidden');
            }
        });
