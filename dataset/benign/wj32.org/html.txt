<h2 class="entry-title"><a href="https://wj32.org/wp/2016/01/13/f-code-memoize-a-recursive-function/" rel="bookmark">F# code: memoize a recursive function</a></h2>
<div class="entry-meta">
		Posted		<span class="posted-on">on		<a href="https://wj32.org/wp/2016/01/13/f-code-memoize-a-recursive-function/" rel="bookmark"><time class="entry-date published updated" datetime="2016-01-13T22:09:56+00:00">January 13, 2016</time></a> </span>
<span class="byline">by			<span class="author vcard">
<a class="url fn n" href="https://wj32.org/wp/author/wj32/" title="View all posts by wj32"><span class="author-name">wj32</span></a>
</span>
</span>
<span class="entry-meta-sep"> / </span>
<span class="comments-link">
<a href="https://wj32.org/wp/2016/01/13/f-code-memoize-a-recursive-function/#comments">1 Comment</a> </span>
</div><!-- .entry-meta -->
</header><!-- .entry-header -->
<div class="entry-content">
<p>In this article we’ll look at how to memoize a general function <code>f : ('a -&gt; 'b) -&gt; 'a -&gt; 'b</code> in F#, along with some interesting applications.</p>
<h2>Generic version</h2>
<p>Most versions of this code that you can find online only deal with the simple case <code>'a -&gt; 'b</code>, which doesn’t allow the function to call a memoized form of itself for recursion. This version does. The trick is to define mutually recursive functions <code>g : 'a -&gt; 'b</code> and <code>h : ('a -&gt; 'b) -&gt; 'a -&gt; 'b</code>, where <code>g</code> is the memoized form of <code>f</code> that will get passed to <code>f</code> itself, and <code>h</code> does the actual work.</p>

<p>Let <span class="MathJax_Preview">F</span><script type="math/tex">F</script> be a complex Banach space, let <span class="MathJax_Preview">U\subseteq\bbc</span><script type="math/tex">U\subseteq\bbc</script> be an open set, and let <span class="MathJax_Preview">f:U\to F</span><script type="math/tex">f:U\to F</script>. Recall that the complex Fréchet derivative of <span class="MathJax_Preview">f</span><script type="math/tex">f</script> at <span class="MathJax_Preview">z\in U</span><script type="math/tex">z\in U</script>, if it exists, is a <span class="MathJax_Preview">\bbc</span><script type="math/tex">\bbc</script>-linear map <span class="MathJax_Preview">Df(z):\bbc\to F</span><script type="math/tex">Df(z):\bbc\to F</script>. Not all real differentiable functions on <span class="MathJax_Preview">\bbc</span><script type="math/tex">\bbc</script> are <em>complex</em> differentiable: for example, the (real) derivative of <span class="MathJax_Preview">f(z)=\overline{z}</span><script type="math/tex">f(z)=\overline{z}</script> (i.e. <span class="MathJax_Preview">f(x+yi)=x-yi</span><script type="math/tex">f(x+yi)=x-yi</script>) at any point is represented by the matrix <span class="MathJax_Preview">\begin{bmatrix}1 &amp; 0 \\ 0 &amp; -1\end{bmatrix},</span><script type="math/tex; mode=display">\begin{bmatrix}1 & 0 \\ 0 & -1\end{bmatrix},</script> but <span class="MathJax_Preview">Df(z)</span><script type="math/tex">Df(z)</script> is clearly not a <span class="MathJax_Preview">\bbc</span><script type="math/tex">\bbc</script>-linear map.</p>

<div class="entry-meta">
		Posted		<span class="posted-on">on		<a href="https://wj32.org/wp/2013/06/03/line-integrals-2-locally-exact-forms-and-singular-homology/" rel="bookmark"><time class="entry-date published updated" datetime="2013-06-03T00:12:21+00:00">June 3, 2013</time></a> </span>
<span class="byline">by			<span class="author vcard">

<div class="entry-content">
<p>Navigation: <a href="/wp/2013/06/01/line-integrals-1-exact-conservative-and-closed-forms/">1. Exact, conservative and closed forms</a> | <strong>2. Locally exact forms and singular homology</strong> | <a href="/wp/2013/06/10/line-integrals-3-applications-to-complex-analysis/">3. Applications to complex analysis</a></p>
<p>As in part 1, <span class="MathJax_Preview">E,F</span><script type="math/tex">E,F</script> are Banach spaces and <span class="MathJax_Preview">U\subseteq E</span><script type="math/tex">U\subseteq E</script> is an open set. Recall that a form <span class="MathJax_Preview">\omega:U\to L(E,F)</span><script type="math/tex">\omega:U\to L(E,F)</script> is <strong>exact</strong> if <span class="MathJax_Preview">\omega=Df</span><script type="math/tex">\omega=Df</script> for some <span class="MathJax_Preview">f:U\to F</span><script type="math/tex">f:U\to F</script>, <strong>closed</strong> if it is differentiable and <span class="MathJax_Preview">D\omega(x)\in L(E,E;F)</span><script type="math/tex">D\omega(x)\in L(E,E;F)</script> is symmetric for every <span class="MathJax_Preview">x\in U</span><script type="math/tex">x\in U</script>, and <strong>locally exact</strong> if it is closed and for every <span class="MathJax_Preview">x\in U</span><script type="math/tex">x\in U</script> there is a neighborhood <span class="MathJax_Preview">V\subseteq U</span><script type="math/tex">V\subseteq U</script> of <span class="MathJax_Preview">x</span><script type="math/tex">x</script> on which <span class="MathJax_Preview">\omega</span><script type="math/tex">\omega</script> is exact. Last time we showed that every closed <span class="MathJax_Preview">C^1</span><script type="math/tex">C^1</script> form is locally exact, and that every closed form on an open subset of <span class="MathJax_Preview">\mathbb{R}^2</span><script type="math/tex">\mathbb{R}^2</script> is locally exact (even if is differentiable but not <span class="MathJax_Preview">C^1</span><script type="math/tex">C^1</script>).</p>
<p>So far, we have only defined line integrals along <span class="MathJax_Preview">C^1</span><script type="math/tex">C^1</script> paths and curves. It turns out that for locally exact forms, we can extend the definition to paths that are merely continuous (and not necessarily differentiable).</p>

<p>The line integral is a useful tool for working with vector fields on <span class="MathJax_Preview">\mathbb{R}^n</span><script type="math/tex">\mathbb{R}^n</script>, (co)vector fields on manifolds, and complex differentiable functions.
