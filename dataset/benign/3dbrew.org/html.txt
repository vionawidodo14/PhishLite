<th width="50%"><b>What is Homebrew?</b>
</th>
<th width="50%"><b>How do I run homebrew?</b>
</th></tr>
<tr align="left" style="background: #F5FAFF;" valign="top">
<td><a class="external text" href="http://en.wikipedia.org/wiki/Homebrew_(video_games)" rel="nofollow">Homebrew</a> is a popular term used for applications that are created and executed on a video game console by hackers, programmers, developers, and consumers.
</td>
<td>Keep an eye out on the <a href="/wiki/Homebrew_Exploits" title="Homebrew Exploits">Homebrew Exploits</a> page for a list of available exploits and their respective requirements.
</td></tr></tbody></table>
<table bgcolor="#fff" border="0" cellpadding="2px" cellspacing="2px" style="margin:auto;" width="100%">
<tbody><tr align="center" bgcolor="#e7eef6">
<th width="50%"><b>How do I develop homebrew?</b>
</th>
<th width="50%"><b>What homebrew can I run?</b>
</th></tr>
<tr align="left" style="background: #F5FAFF;" valign="top">
<td>See the <a href="/wiki/Setting_up_Development_Environment" title="Setting up Development Environment">Setting up Development Environment‎</a> page for a guide on how to get started with homebrew development for the 3DS. The toolchain supports Windows, Linux, and Mac OS X.
</td>
<td>See the <a href="/wiki/Homebrew_Applications" title="Homebrew Applications">Homebrew Applications</a> page for a partial list of homebrew applications/games that can be downloaded and installed.
</td></tr></tbody></table>
