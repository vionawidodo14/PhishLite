<h2 class="title">
<a href="https://jaxenter.de/20-jahre-apache-software-foundation-interview-van-gulik-88454">20 Jahre Apache Software Foundation: „Wir sind von Open-Source-Foundations umgeben, die keine Community sind“</a>
</h2>
<div class="tags">
<a href="https://jaxenter.de/tag/apache">#Apache</a>
<a href="https://jaxenter.de/tag/interview">#Interview</a>
<a href="https://jaxenter.de/tag/open-source">#Open Source</a>
</div>
<div class="text">
<p>Die ApacheCon Europe steht in diesem Jahr unter einem ganz besonderen Zeichen: Die Apache Software Foundation (ASF) feiert ihr 20-jähriges Bestehen! Wir sprachen mit Gründungsmitglied, ehemaligen Präsident and Board Member der Apache Software Foundation Dirk-Willem van Gulik  über den Werdegang der ASF, ihr Erfolgsgeheimnis und die spannendsten Projekte.</p>

<h2 class="title">
<a href="https://jaxenter.de/devsecops-agile-interview-winkenwerder-88461">Automatisierung, Orchestrierung &amp; Korrelation – Der Weg zu agilem DevSecOps</a>
</h2>
<div class="tags">
<a href="https://jaxenter.de/tag/agile">#Agile</a>
<a href="https://jaxenter.de/tag/devops">#DevOps</a>
<a href="https://jaxenter.de/tag/devopscon-2019">#DevOpsCon 2019</a>
</div>
<div class="text">
<p>Mit dem zunehmenden Einsatz agiler Methoden steigt die Häufigkeit der Auslieferung von Softwareversionen und Sicherheitsanforderungen. Etablierte Sicherheitsmethoden wie Risikoanalysen, Sicherheitsanalysen und Penetrationen, die mit phasenorientierten Methoden gut funktionieren, müssen in einer agilen Umgebung neu definiert werden. Wie das funktioniert, zeigt Gunner Winkenwerder (Checkmarx Ltd.) in seiner Session auf der <a href="https://devopsconference.de/?utm_source=jaxenter.de&amp;utm_medium=referral&amp;utm_term=general&amp;utm_campaign=intext_general">DevOpsCon 2019</a>.</p>
