<h3>EasyMapMaker steps to Create a Custom Google Map</h3>
</div>
</div>
<div class="row">
<div class="span4 features"><img alt="copy and paste excel spreadsheet data" class="features-left" src="//cdn.easymapmaker.com/img/copy-180.png" style="max-width: 80px;"/>
<h4>Copy &amp; Paste Data</h4>
<p>Use EasyMapMaker to map excel or other spreadsheet data onto a google map. EasyMapMaker takes the
                            work out of manually plotting multiple locations on a map. The first step is to copy (or drag &amp; drop) your
                            spreadsheet data including the column headers into the table by clicking on the table to reveal a
                            text box.  The data must include some location information, either an address or latitude/longitude coordinates.



                        </p></div>
<div class="span4 features"><img alt="set options for your map" src="//cdn.easymapmaker.com/img/smaller_options.png" style="max-width: 150px;"/>
<div><h4 style="margin-left: 20px; padding-top: 10px;">Set Address Options and Select Features</h4></div>
<p>
                            Set the options for your map. Be sure to set location information. Location information can consist
                            of many combinations of the address (street, city, state, zip) as well as the latitude and longitude
                            (set explicitly in separate columns). The whole location can be in one column and be set as the
                            address, or it can be in multiple columns. Set other options if the data contains them. Use Advanced
                            Options to add filters, add a left direction panel with a radius filter, hide certain data, upload a
                            custom logo, or use custom markers (pins).

                        </p></div>
<div class="span4 features"><img alt="Make map is the final step to create a map" src="//cdn.easymapmaker.com/img/smaller_map.png" style="max-height: 70px;"/><h4 style="padding-top: 10px;">Process addresses to Generate Map
                        </h4>
<p>
                            Click on Make Map and wait for address location data to be translated into latitude and longitude so
                            it can be placed on the map.
                            Once the data is on the map, the pins can be moved or removed. Once the map looks good, save it. An
                            email will be sent for your records to access the map in the future.
                            After the map is saved, the map url will be provided. This url can be changed to something easier to
                            remember. You can share the map, embed the map on a webpage, or print the map.
                        </p>
</div>
</div>

<h4>Create maps up to 50 times faster</h4>
<p>EasyMapMaker Subscription services allows addresses to be geo-coded up to 90 times faster.  A subscription map with over 50 addresses to geo-code will use the server side geo-coder.
                        <strong>Maps with less than 50 locations will use the client side geo-coder in order to avoid clogging up the queue.</strong>  The old (mostly inactive) client side bulk geo-coder  could take 4 hours for
                        9,000 locations compared to under 2 minutes with a Premium &amp; Enterprise subscription.
                        <strong>Pro, Premium  &amp; Enterprise</strong>
</p></div>

<p>EasyMapMaker Subscription supports data sets of 15,000 (<strong>Premium</strong>) and 30,000 (<strong>Enterprise</strong>) locations without the supplied latitude and longitude.
                        Maps with multiple (or tens of thousands) locations can be created really fast with the address processor.  Large maps will render quickly
                        with the clustering engine.



                    </p></div>
<div class="span4 features"><img alt="Add a password to maps for extra security so they can only be viewed by people with the password" src="//cdn.easymapmaker.com/img/android-lock.png"/><h4>Password &amp; Login Protected Maps

<p>
                        Prevent anyone from viewing your map by using a password protected map.
                        Access to the edit page requires you to be logged in to add extra assurance no one will change your map.
                        Share maps with a restricted group by requiring a password to the view the map.  To allow someone to have temporary access to a map, you can give them a password
                        then change it when you don't want them to see it again.                         <strong>Pro, Premium  &amp; Enterprise</strong>
</p>

<strong>Pro, Premium  &amp; Enterprise</strong>
</p></div>
<div class="span4 features"><img alt="Create maps with larger datasets" src="//cdn.easymapmaker.com/img/png_download.png" style="max-width: 100px;"/><h4 style="margin-left: 20px;"><a href="/features/export-map-to-pdf-or-png" target="_blank">Export map to a PNG Image</a></h4>

<p>

</p>

<p>Add pin labels to your map by  selecting an option from a drop down menu.
                        Map pin labels allow for locations to be quickly identified.  They can be used to show fixed numbers,

<p>Customize your map with your own logo.  You can set the title text for the logo, a url to your site, and also upload your custom logo to replace the default logo.
                        The default logo can also be hidden. <strong>Premium &amp; Enterprise</strong>
</p></div>

<p>
                        Add a (circle) radius around one or all your pins.  Use a predefined value or add add your own custom value.  To enable a radius around certain
                        pins, set the value to 0 to hide pins that do not need a radius. <strong>Pro, Premium  &amp; Enterprise</strong>
</p></div>

<p>

</p></div>

                    </h4>
<p>

                        Access your maps anywhere and anytime you have online access.  This means there is nothing to run and download, everything

                        for you to download.
                    </p>

<p>Number pins on your custom map to reference them with other data.  Pins can be numbered 1-99 when there are less than
                        100 locations on the map.  Pins on the map can have fixed number set from the data or automatically be numbered.


                    </p></div>
<div class="span4 features"><img alt="Select pin colors while grouping and categorizing data" src="//cdn.easymapmaker.com/img/select_colors.png"/>

<p>
                        Categorize and group your markers and change the color of the pins to more accurately to reflect the data.
                        Choose a column from your data to quickly group or categorize the markers.
                        A legend will appear below the map for group markers that can also be used to filter the pins.
                        <strong>Subscribers have up to 20 marker colors.</strong>  Other maps have 7 colors.

                    </p></div>
</div>

<h4 class="features-left"> Hide Map Details</h4>
<p class="features-left">Limit the details available on the map by only allowing it to be zoomed into a certain region, or allow it to be zoomed in
                        so different addresses are more distinguishable.


                    </p></div>
<div class="span4 features"><img alt="Addresses automatically get geo-coded into latitude and longitude coordinates" src="//cdn.easymapmaker.com/img/android-globe.png"/><div>
<h4> Automatic Address processing (Geo-coding)</h4>
</div>
<div>
<p></p>
<p>EasyMapMaker uses the Google geocoder (OSM geo-coder for free maps) to process addresses and attempt to find the correct latitude and longitude to
                            place them on a map.  Create a custom pin map with thousands of locations quickly and easily.
                        </p>
</div>
</div>
<div class="span4 features"><img alt="view your maps on mobile and tablet devices without any extra effort" src="//cdn.easymapmaker.com/img/mobile_map.png"/>
<h4> Mobile Compatible Maps</h4>
<p>Maps created with EasyMapMaker automatically work on your mobile device.  You can find directions to the nearest marker location
                        or find your location on the map.

                    </p></div>
</div>
<div class="row">
<div class="span4 features"><div>
<img alt="Select to have your excel data converted into kml to use with other services such as google earth." src="//cdn.easymapmaker.com/img/kml_img.png"/>
<h4><a href="https://www.easymapmaker.com/support/how-can-i-create-a-kml-file/" target="_blank">KML Generator For Google Earth</a>
</h4>
</div>
<div>
<p></p>
<p>
                            Create a KML file to use on Google Earth or Google Maps (limited to 2,000 locations).
                            EasyMapMaker automatically generates a KML file for you when you choose to save your map and have it save KML (Keyhold Markup Language).
                            You can use the KML on Google Earth, Google Maps (limited to 2,000 locations), or any other program that accepts KML.
                            The KML file creator is only available for datasets up to 25,000 locations.
                        </p>
</div>

<div class="span4 features"><img alt="Group data items together by clustering" src="//cdn.easymapmaker.com/img/clustering.png" style="max-width: 100px;"/>
<h4><a href="features/clustering-pins/" style="text-decoration: none;" target="_blank">Clustering</a>
</h4>
<p>
                       Clustering groups large datasets by a gridbased formula so markers in certain bounds appear together in a cluster (group).  This greatly improves
                        map performance.  The EasyMapMaker cluster engine allows maps to load incredibly fast since it shows individual pins on demand.
                    </p>
</div>

</h4>
<p>
                        Turn any map into a heat map with Google's heat map layer.  Maps can be rendered by color (red for hot spots) based on the density of pins in an area relative to the overall
                        number of pins.  Heat maps can render with the pins hidden or displayed.  The opacity and radius for the heat layer can also be set.
                    </p>
</div>

Change the color of roads, the map, water, hide points of interest; there are nearly limitless options with a custom map style.
