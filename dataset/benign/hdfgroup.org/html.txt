<div class="wpb_wrapper">
<h2>What is HDF5<sup>®</sup>?</h2>
</div>
</div>
<div class="mkd-separator-holder clearfix mkd-separator-center">
<div class="mkd-separator" style="width: 53px;border-bottom-width: 3px;margin-top: 22px;margin-bottom: 46px"></div>
</div>
<div class="mkd-elements-holder mkd-responsive-mode-768"><div class="mkd-elements-holder-item mkd-width-1-2 mkd-vertical-alignment-middle mkd-horizontal-alignment-left" data-item-class="mkd-elements-holder-custom-697925">
<div class="mkd-elements-holder-item-inner">
<div class="mkd-elements-holder-item-content mkd-elements-holder-custom-697925">
<div class="mkd-elements-holder-item-content-inner">
<div class="mkd-accordion-holder clearfix mkd-accordion mkd-boxed ui-accordion ui-widget ui-helper-reset" role="tablist">
<div aria-controls="ui-id-2" aria-expanded="true" aria-selected="true" class="mkd-accordion-title-holder ui-accordion-header ui-state-default ui-accordion-header-active ui-state-active ui-corner-top" id="ui-id-1" role="tab" tabindex="0">
<div class="mkd-accordion-icon-holder"><i class="mkd-icon-simple-line-icon icon-graph" style="font-size:28px"></i></div><!-- .mkd-accordion-icon-holder -->
<h6 class="clearfix mkd-accordion-title">
    Heterogeneous Data</h6>
<div class="mkd-accordion-mark-holder">
<div class="mkd-accordion-mark-icon">
<span class="icon_minus-06 mkd-close"></span>
<span class="icon_plus mkd-open"></span>
</div>
</div><!-- .mkd-accordion-mark-holder -->
</div><!-- .mkd-accordion-title-holder -->
<div aria-hidden="false" aria-labelledby="ui-id-1" class="mkd-accordion-content ui-accordion-content ui-helper-reset ui-widget-content ui-corner-bottom ui-accordion-content-active" id="ui-id-2" role="tabpanel" style="display: block;">
<div class="mkd-accordion-content-inner">
<div class="wpb_text_column wpb_content_element">
<div class="wpb_wrapper">
<p>HDF<sup>®</sup> supports n-dimensional datasets and each element in the dataset may itself be a complex object.</p>
</div>
</div>
</div>
</div>
<div aria-controls="ui-id-4" aria-expanded="false" aria-selected="false" class="mkd-accordion-title-holder ui-accordion-header ui-state-default ui-corner-all" id="ui-id-3" role="tab" tabindex="-1">
<div class="mkd-accordion-icon-holder"><i class="mkd-icon-simple-line-icon icon-share" style="font-size:28px"></i></div><!-- .mkd-accordion-icon-holder -->
<h6 class="clearfix mkd-accordion-title">
    Easy Sharing</h6>
<div class="mkd-accordion-mark-holder">
<div class="mkd-accordion-mark-icon">
<span class="icon_minus-06 mkd-close"></span>
<span class="icon_plus mkd-open"></span>
</div>
</div><!-- .mkd-accordion-mark-holder -->
</div><!-- .mkd-accordion-title-holder -->
<div aria-hidden="true" aria-labelledby="ui-id-3" class="mkd-accordion-content ui-accordion-content ui-helper-reset ui-widget-content ui-corner-bottom" id="ui-id-4" role="tabpanel" style="display: none;">
<div class="mkd-accordion-content-inner">
<div class="wpb_text_column wpb_content_element">
<div class="wpb_wrapper">
<p>HDF<sup>®</sup> is portable, with no vendor lock-in, and is a self-describing file format, meaning everything all data and metadata can be passed along in one file.</p>
</div>
</div>
</div>
</div>
<div aria-controls="ui-id-6" aria-expanded="false" aria-selected="false" class="mkd-accordion-title-holder ui-accordion-header ui-state-default ui-corner-all" id="ui-id-5" role="tab" tabindex="-1">
<div class="mkd-accordion-icon-holder"><i class="mkd-icon-simple-line-icon icon-shuffle" style="font-size:28px"></i></div><!-- .mkd-accordion-icon-holder -->
<h6 class="clearfix mkd-accordion-title">
    Cross Platform</h6>
<div class="mkd-accordion-mark-holder">
<div class="mkd-accordion-mark-icon">
<span class="icon_minus-06 mkd-close"></span>
<span class="icon_plus mkd-open"></span>
</div>
</div><!-- .mkd-accordion-mark-holder -->
</div><!-- .mkd-accordion-title-holder -->
<div aria-hidden="true" aria-labelledby="ui-id-5" class="mkd-accordion-content ui-accordion-content ui-helper-reset ui-widget-content ui-corner-bottom" id="ui-id-6" role="tabpanel" style="display: none;">
<div class="mkd-accordion-content-inner">
<div class="wpb_text_column wpb_content_element">
<div class="wpb_wrapper">
<p>HDF<sup>®</sup> is a software library that runs on a range of computational platforms, from laptops to massively parallel systems, and implements a high-level API with C, C++, Fortran 90, and Java interfaces. HDF has a large ecosystem with 700+ Github projects.</p>
</div>
</div>
</div>
</div>
<div aria-controls="ui-id-8" aria-expanded="false" aria-selected="false" class="mkd-accordion-title-holder ui-accordion-header ui-state-default ui-corner-all" id="ui-id-7" role="tab" tabindex="-1">
<div class="mkd-accordion-icon-holder"><i class="mkd-icon-simple-line-icon icon-energy" style="font-size:28px"></i></div><!-- .mkd-accordion-icon-holder -->
<h6 class="clearfix mkd-accordion-title">
    Fast I/O</h6>
<div class="mkd-accordion-mark-holder">
<div class="mkd-accordion-mark-icon">
<span class="icon_minus-06 mkd-close"></span>
<span class="icon_plus mkd-open"></span>
</div>
</div><!-- .mkd-accordion-mark-holder -->
</div><!-- .mkd-accordion-title-holder -->
<div aria-hidden="true" aria-labelledby="ui-id-7" class="mkd-accordion-content ui-accordion-content ui-helper-reset ui-widget-content ui-corner-bottom" id="ui-id-8" role="tabpanel" style="display: none;">
<div class="mkd-accordion-content-inner">
<div class="wpb_text_column wpb_content_element">
<div class="wpb_wrapper">
<p>HDF<sup>®</sup> is high-performance I/O with a rich set of integrated performance features that allow for access time and storage space optimizations.</p>
</div>
</div>
</div>
</div>
<div aria-controls="ui-id-10" aria-expanded="false" aria-selected="false" class="mkd-accordion-title-holder ui-accordion-header ui-state-default ui-corner-all" id="ui-id-9" role="tab" tabindex="-1">
<div class="mkd-accordion-icon-holder"><i class="mkd-icon-simple-line-icon icon-equalizer" style="font-size:28px"></i></div><!-- .mkd-accordion-icon-holder -->
<h6 class="clearfix mkd-accordion-title">
    Big Data</h6>
<div class="mkd-accordion-mark-holder">
<div class="mkd-accordion-mark-icon">
<span class="icon_minus-06 mkd-close"></span>
<span class="icon_plus mkd-open"></span>
</div>
</div><!-- .mkd-accordion-mark-holder -->
</div><!-- .mkd-accordion-title-holder -->
<div aria-hidden="true" aria-labelledby="ui-id-9" class="mkd-accordion-content ui-accordion-content ui-helper-reset ui-widget-content ui-corner-bottom" id="ui-id-10" role="tabpanel" style="display: none;">
<div class="mkd-accordion-content-inner">
<div class="wpb_text_column wpb_content_element">
<div class="wpb_wrapper">
<p>There is no limit on the number or size of data objects in the collection, giving great flexibility for big data.</p>
</div>
</div>
</div>
</div>
<div aria-controls="ui-id-12" aria-expanded="false" aria-selected="false" class="mkd-accordion-title-holder ui-accordion-header ui-state-default ui-corner-all" id="ui-id-11" role="tab" tabindex="-1">
<div class="mkd-accordion-icon-holder"><i class="mkd-icon-simple-line-icon icon-refresh" style="font-size:28px"></i></div><!-- .mkd-accordion-icon-holder -->
<h6 class="clearfix mkd-accordion-title">
    Keep Metadata with Data</h6>
<div class="mkd-accordion-mark-holder">
<div class="mkd-accordion-mark-icon">
<span class="icon_minus-06 mkd-close"></span>
<span class="icon_plus mkd-open"></span>
</div>
</div><!-- .mkd-accordion-mark-holder -->
</div><!-- .mkd-accordion-title-holder -->
<div aria-hidden="true" aria-labelledby="ui-id-11" class="mkd-accordion-content ui-accordion-content ui-helper-reset ui-widget-content ui-corner-bottom" id="ui-id-12" role="tabpanel" style="display: none;">
<div class="mkd-accordion-content-inner">
<div class="wpb_text_column wpb_content_element">
<div class="wpb_wrapper">
<p>HDF5<sup>®</sup> allows you to keep the metadata with the data, streamlining data lifecycles and pipelines.</p>
