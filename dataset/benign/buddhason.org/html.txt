<h2 class="title"><a href="/node/244" title="2013~2014 清淨道禪修營 - 大乘法師">2013~2014 清淨道禪修營 - 大乘法師</a></h2>
<div class="meta">
<div class="submitted">週一, 2013/02/04 - 12:33</div>
</div>
<div class="terms">
<ul class="taxonomy"><li class="vocab-term"><a href="/taxonomy/term/34" rel="tag" title="">禪修訊息</a></li></ul> </div>
<div class="content">
<p><span style="background-color:rgb(255, 255, 255); color:rgb(0, 128, 128); font-family:Arial, Verdana; font-size:x-large">2013~2014 清淨道禪修營</span></p>
<p>
<span style="color:rgb(51, 51, 51); font-family:Arial, Verdana; background-color:rgb(255, 255, 255)"><span style="color:rgb(0, 128, 128)">內　　容：</span>依據《清淨道論》道次第指導安那般那禪修等，</span><br/>
<span style="color:rgb(51, 51, 51); font-family:Arial, Verdana; background-color:rgb(255, 255, 255)">　　　　　令禪修者達到四禪八定，證得一一清淨 ── 直至涅槃。</span><br style="color:rgb(51, 51, 51); font-family:Arial, Verdana; font-size:12px; background-color:rgb(255, 255, 255)"/><br/>
<br style="color:rgb(51, 51, 51); font-family:Arial, Verdana; font-size:12px; background-color:rgb(255, 255, 255)"/><br/>
<span style="color:rgb(51, 51, 51); font-family:Arial, Verdana; background-color:rgb(255, 255, 255)"><span style="color:rgb(0, 128, 128)">指導禪師：</span>大乘禪師（</span><span style="color:rgb(51, 51, 51); font-family:Arial, Verdana; background-color:rgb(255, 255, 255)">通達百種止觀業處　具南北藏傳禪觀實修經驗）</span><br style="color:rgb(51, 51, 51); font-family:Arial, Verdana; font-size:12px; background-color:rgb(255, 255, 255)"/><br/>
<br/>
<span style="color:rgb(51, 51, 51); font-family:Arial, Verdana; background-color:rgb(255, 255, 255)"><span style="color:rgb(0, 128, 128)">主辦單位：</span>佛文化禪觀研發社 </span><br style="color:rgb(51, 51, 51); font-family:Arial, Verdana; font-size:12px; background-color:rgb(255, 255, 255)"/><br/>
<br/>
<span style="color:rgb(51, 51, 51); font-family:Arial, Verdana; background-color:rgb(255, 255, 255)"><span style="color:rgb(0, 128, 128)">禪修日期：</span><span style="color:rgb(255, 0, 0)">(1) <strong>102年2月11日 (農曆正月初二) ~3月2日  (報名中)</strong></span></span><span style="color:rgb(51, 51, 51); font-family:Arial, Verdana; background-color:rgb(255, 255, 255)"><span style="color:rgb(255, 0, 0)">　</span> <br/>
	　　　　　(2) <strong>102年5月24日~6月14日</strong></span><br style="color:rgb(51, 51, 51); font-family:Arial, Verdana; font-size:12px; background-color:rgb(255, 255, 255)"/><br/>
<span style="color:rgb(51, 51, 51); font-family:Arial, Verdana; background-color:rgb(255, 255, 255)">　　　　　(3) <strong>102年10月1日~10月20日</strong></span><br style="color:rgb(51, 51, 51); font-family:Arial, Verdana; font-size:12px; background-color:rgb(255, 255, 255)"/><br/>
<span style="color:rgb(51, 51, 51); font-family:Arial, Verdana; background-color:rgb(255, 255, 255)">　　　　　(4) <strong>103年2月1日 (農曆正月初二)~2月20日</strong></span><br style="color:rgb(51, 51, 51); font-family:Arial, Verdana; font-size:12px; background-color:rgb(255, 255, 255)"/><br/>
<span style="color:rgb(51, 51, 51); font-family:Arial, Verdana; background-color:rgb(255, 255, 255)">　　　　  　  (以上禪修全程20天, 每期10天, 亦可隨喜參加) 　　　　  </span><br style="color:rgb(51, 51, 51); font-family:Arial, Verdana; font-size:12px; background-color:rgb(255, 255, 255)"/><br/>
<br/>
<span style="color:rgb(51, 51, 51); font-family:Arial, Verdana; background-color:rgb(255, 255, 255)"><span style="color:rgb(0, 128, 128)">禪修地點：</span>正醒禪苑 南投縣埔里鎮福興里大坑巷10號</span><br style="color:rgb(51, 51, 51); font-family:Arial, Verdana; font-size:12px; background-color:rgb(255, 255, 255)"/><br/>
<br/>
<span style="color:rgb(51, 51, 51); font-family:Arial, Verdana; background-color:rgb(255, 255, 255)"><span style="color:rgb(0, 128, 128)">費　　用：</span>隨喜</span><br style="color:rgb(51, 51, 51); font-family:Arial, Verdana; font-size:12px; background-color:rgb(255, 255, 255)"/><br/>
<br/>

<h2 class="title"><a href="/node/231" title="湧光寺、觀音精舍　一個月禪修 通告">湧光寺、觀音精舍　一個月禪修 通告</a></h2>
<div class="meta">
<div class="submitted">四, 2009/02/26 - 12:01</div>
</div>
<div class="terms">
<ul class="taxonomy"><li class="vocab-term"><a href="/taxonomy/term/34" rel="tag" title="">禪修訊息</a></li></ul> </div>
<div class="content">
<p style="text-align:center"><span style="font-size:30pt; font-family:標楷體">一個月禪修</span><span style="font-size:22pt; font-family:標楷體">通告</span></p>
<p style="text-align:justify; line-height:22pt"><span style="font-size:14pt; font-family:標楷體">一、禪修時間：</span><span style="font-size:14pt"></span></p>
<p style="margin-left:1cm; text-align:justify; text-indent:62.5pt; line-height:22pt"><span style="font-size:14pt">2009</span><span style="font-size:14pt; font-family:標楷體">年</span><span style="font-size:14pt">2</span><span style="font-size:14pt; font-family:標楷體">月</span><span style="font-size:14pt">24</span><span style="font-size:14pt; font-family:標楷體">日</span><span style="font-size:14pt; font-family:標楷體">至</span><span style="font-size:14pt">3</span><span style="font-size:14pt; font-family:標楷體">月</span><span style="font-size:14pt">5</span><span style="font-size:14pt; font-family:標楷體">日</span><span style="font-size:14pt; font-family:標楷體; color:black">：湧光寺禪修營</span><span style="font-size:14pt; color:black"></span></p>
<p style="margin-left:1cm; text-align:justify; text-indent:62.5pt; line-height:22pt"><span style="font-size:14pt">2009</span><span style="font-size:14pt; font-family:標楷體">年</span><span style="font-size:14pt">3</span><span style="font-size:14pt; font-family:標楷體">月</span><span style="font-size:14pt">7</span><span style="font-size:14pt; font-family:標楷體">日</span><span style="font-size:14pt; font-family:標楷體">至</span><span style="font-size:14pt">3</span><span style="font-size:14pt; font-family:標楷體">月</span><span style="font-size:14pt">28</span><span style="font-size:14pt; font-family:標楷體">日</span><span style="font-size:14pt; font-family:標楷體; color:black">：觀音精舍禪修營</span><span style="font-size:14pt; color:black"></span></p>
<p style="margin-left:1cm; text-align:justify; text-indent:55.45pt; line-height:22pt"><span style="font-size:14pt; font-family:標楷體; color:black">歡迎參</span><span style="font-size:14pt; font-family:標楷體">加。</span><span style="font-size:14pt"></span></p>
<p style="margin-top:12pt; text-align:justify; line-height:22pt"><span style="font-size:14pt; font-family:標楷體">二、指導老師：</span><span style="font-size:14pt"></span></p>
<p style="margin-left:1cm; text-align:justify"><span style="font-size:14pt; font-family:標楷體">（</span><span style="font-size:14pt">1</span><span style="font-size:14pt; font-family:標楷體">）悉臘尊者（</span><span style="font-size:14pt">Ven.Sila</span><span style="font-size:14pt; font-family:標楷體">）緬甸籍</span><span style="font-size:14pt"></span></p>
<p style="margin-left:59.4pt"><span style="font-size:14pt">Sila</span><span style="font-size:14pt; font-family:標楷體">尊者，十三歲就開始在不同的禪修中心修學，明暸各種禪法之間的不同。</span><span style="font-size:14pt">1994</span><span style="font-size:14pt; font-family:標楷體">年受戒為比丘僧，</span><span style="font-size:14pt">1997</span><span style="font-size:14pt; font-family:標楷體">年跟隨帕奧禪師修學。之後，受聘為帕奧禪林多處分支機構的禪修指導師。為推廣內觀禪修，曾以兩年時間，遊走各地區，舉辦短期的禪修課程。</span><span style="font-size:14pt">2005</span><span style="font-size:14pt; font-family:標楷體">年受邀到韓國教授禪法。目前在帕奧禪林教導出家、在家的禪修學員。</span><span style="font-size:14pt"></span></p>
<p style="margin-left:1cm; text-align:justify"><span style="font-size:14pt; font-family:標楷體">（</span><span style="font-size:14pt">2</span><span style="font-size:14pt; font-family:標楷體">）翻譯：</span><span style="font-size:14pt"></span></p>
<p style="margin-left:28.4pt; text-align:justify; text-indent:32pt"><span style="font-size:14pt; font-family:標楷體">慈得尊者</span><span style="font-size:14pt">( U. Laddhametta) </span><span style="font-size:14pt; font-family:標楷體">台灣籍</span><span style="font-size:14pt"></span></p>
<p style="margin-left:59.4pt; text-align:justify"><span style="font-size:14pt">Laddhametta</span><span style="font-size:14pt; font-family:標楷體">尊者，</span><span style="font-size:14pt">1968</span><span style="font-size:14pt; font-family:標楷體">年出生於台灣高雄，</span><span style="font-size:14pt">2003</span><span style="font-size:14pt; font-family:標楷體">年</span><span style="font-size:14pt">8</span><span style="font-size:14pt; font-family:標楷體">月</span><span style="font-size:14pt">9</span><span style="font-size:14pt; font-family:標楷體">日</span><span style="font-size:14pt; font-family:標楷體">在帕奧禪師座下出家。</span><span style="font-size:14pt">2004</span><span style="font-size:14pt; font-family:標楷體">年</span><span style="font-size:14pt">4</span><span style="font-size:14pt; font-family:標楷體">月</span><span style="font-size:14pt">4</span><span style="font-size:14pt; font-family:標楷體">日</span><span style="font-size:14pt; font-family:標楷體">受比丘戒，巴利名</span><span style="font-size:14pt">Laddhametta</span><span style="font-size:14pt; font-family:標楷體">。在緬甸帕奧國際禪修中心研習比丘戒，浸習禪法，緬文巴利，歷經五個雨安居，在</span><span style="font-size:14pt">2008</span><span style="font-size:14pt; font-family:標楷體">年</span><span style="font-size:14pt">10</span><span style="font-size:14pt; font-family:標楷體">月底回台灣。尊者精進又善巧。尊者通英語和緬語，使禪修者獲益良多。</span><span style="font-size:14pt"></span></p>

<div class="content">
<p>
毘婆舍那禪修營</p>
<p>指導禪師：般 若 諦 帕 禪師 Sayādaw U Paññadipa (Beelin Sayādaw)<br/>
(美國如來禪修中心．緬甸班迪達禪修中心)</p>
<p>日 期： <br/>
◆精進禪：98年3月1日~ 4月6日<br/>
◆十日禪：
</p>
<p>
第一梯次 98年3月 1日~ 3月10日<br/>
第二梯次 98年3月14日~ 3月23日<br/>
第三梯次 98年3月28日~ 4月 6日</p>
<p>主 辦： 過坑內觀禪修中心<br/>
地 址： 南投縣埔里鎮過坑路69號，寶相禪寺內。</p>
<p>報名專線：<br/>
◎過坑內觀中心：049-292-7869<br/>
◎蔡瑞興：05-268-4012<br/>
◎張瓈月：05-203-0477（早上十點~下午六點）</p>
<p>注意事項：山區氣候嚴寒，請必備睡袋、禦寒衣物。<br/>
報到時間：參加梯次之第一日，下午一點~三點。</p>
