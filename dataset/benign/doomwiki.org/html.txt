<h2 style="padding: 0.2em 0.4em; margin: 3px 0 10px 0; border:1px solid #12228D; background:#21487d; color:#FDFDFD; font-size:120%; font-weight:bold; text-align:left;"><span class="mw-headline" id="About_DoomWiki.org">About DoomWiki.org</span></h2>
<p>The <b><a href="/wiki/Doom_Wiki" title="Doom Wiki">Doom Wiki</a></b> is an extensive community effort to document everything related to <a href="/wiki/Id_Software" title="Id Software">id Software</a>'s masterpiece games <a href="/wiki/Doom" title="Doom">Doom</a> and <a href="/wiki/Doom_II" title="Doom II">Doom II</a>, other <a class="mw-redirect" href="/wiki/Games" title="Games">games</a> based on the <a href="/wiki/Doom_engine" title="Doom engine">Doom engine</a>, <a href="/wiki/Doom_3" title="Doom 3">Doom 3</a>, <a href="/wiki/Doom_(2016)" title="Doom (2016)">Doom (2016)</a>, <a href="/wiki/Doom_Eternal" title="Doom Eternal">Doom Eternal</a>, and more. We have created <b>9,046</b> articles to date. 
</p><p>This site is a <a href="/wiki/Wiki" title="Wiki">wiki</a>, so everyone is encouraged to create and edit articles. New contributors should read our <a href="/wiki/Doom_Wiki:FAQ" title="Doom Wiki:FAQ">FAQ</a> first. If this is your first time using a wiki, be sure to check out the <a class="extiw" href="https://meta.wikimedia.org/wiki/Help:Editing" title="m:Help:Editing">basic editing instructions</a> as well. If you need additional help, or wish to discuss general aspects of this wiki, pay a visit to the <a href="/wiki/Doom_Wiki:Central_Processing" title="Doom Wiki:Central Processing">Central Processing</a> discussion board.
</p><p>See the <a href="/wiki/News_board" title="News board">news board</a> to read and post news about ongoing or upcoming events in the Doom universe.
</p>

<h3><span class="mw-headline" id="Doom_II"><a href="/wiki/Doom_II" title="Doom II">Doom II</a></span></h3>
<p><b>Doom II: Hell on Earth</b> is the first sequel to Doom, released by id Software on September 30, 1994. Featuring 32 levels in a single linear episode, Doom II continues Doom's story, seeing the player returning to Earth to single-handedly fight off an invasion of the planet by demons.
</p><p>Doom II includes several gameplay enhancements over the original Doom. Most notable are the introduction of several new monster types, plus an additional weapon (the super shotgun).
<br/>(<a href="/wiki/Doom_II" title="Doom II">read more</a>)<i> </i>(<a href="/wiki/Doom_Wiki_talk:Featured_articles" title="Doom Wiki talk:Featured articles">feature nominations</a>)
</p>
