function getCookie(cname)
{
var name = cname + "=";
var ca = document.cookie.split(';');
for(var i=0; i<ca.length; i++) 
  {
  var c = ca[i].trim();
  if (c.indexOf(name)==0) return c.substring(name.length,c.length);
  }
return "";
}

String.prototype.replaceAt=function(index, character) {
    return this.substr(0, index) + character + this.substr(index+character.length);
}

function donnecode(aoter)
{
var date = new Date();
date.setDate(date.getDate() - parseInt(aoter,10));

jours=date.getDate();
mois=date.getMonth() + 1;

if(date.getMonth() + 1<10)
mois='0'+String(date.getMonth() + 1);

if(date.getDate() <10)
jours='0'+String(date.getDate());

codedate = String(jours) + mois + String(date.getFullYear());
return codedate;
}

<br/>

<br/>
        Parce que ce cours de piano est particulièrement adapté aux débutants.<br/>

<strong>Le secret est le suivant:</strong><br/>
<br/>
        La méthode essaie de tendre à vous apprendre le piano sans solfège. Ainsi, la première partie du cours est ciblée sur la lecture de partition tout en limitant au maximum le solfège.

<li>Une série d'exercice vous est proposée pour tester vos connaissances

<li>Puis, pour certaines leçons, des partitions de piano faciles adaptées à votre niveau vous sont présentées

<p class="fakeh2" style="color:black;padding-bottom:20px;">
        Mon histoire perso<br/>
        (et comment vous allez en bénéficier)
    </p>
<p>
        J'ai toujours voulu apprendre à jouer du piano, mais n'ai pas eu la chance d'avoir appris à y jouer étant enfant... Alors que certains jouaient de la guitare ou du violon, moi je ne savais
        rien faire...<br/>
<br/>
<img alt="notes de musique" src="https://u.jimcdn.com/www9/o/s9a5e96a10a799cfa/img/i5e8ea82cb6cc5fb0/1305816692/std/image.png" style="margin:20px auto;"/><br/>
        Quand on est entré dans la cour des grands, franchir le pas est toujours plus compliqué: on se demande parfois si ce n'est pas trop tard.<br/>
<br/>
<span class="fakeh3">Trop vieux? Plus capable?</span><br/>
<br/>
        Ainsi, pensant qu'il était trop tard pour commencer, j'avais abandonné l'idée de suivre des cours de piano.
    </p>
<br/>
<p>
        J'ai donc décidé de me débrouiller tout seul et d'apprendre le piano en autodidacte, je me suis dit qu'appuyer sur des touches dans un certain ordre n'était pas physiquement très compliqué.
        Pour moi, le piano était un code, ou une langue inconnue qu'il faut décrypter. J'ai donc pris une partition et appris à la lire. Quelques mois plus tard, je jouais mes premiers morceaux, sans
        comprendre le "pourquoi", mais juste en exécutant.<br/>
<br/>
<span class="fakeh3">Et c'est là que ça commence à être intéressant:</span>
</p>
<br/>
<p>
        Plus les morceaux s'enchaînaient, plus je commençais à apercevoir la façon dont les morceaux sont construits et l'apparition récurrente des mêmes accords. Ainsi, j'ai commencé à découvrir des
        "règles", des "principes", bref des "trucs" pour <strong>ne pas simplement apprendre, mais comprendre le piano</strong>. Ces astuces-ci me permettent maintenant de trouver un morceau sans
        l'aide de partitions.
    </p>
<br/>
<p>
        En comparant ma vision du piano aux cours de musique traditionnels, je me suis rendu compte qu'il était possible d'améliorer les cours de piano. J'ai donc décidé de créer ce site en 2008,
        afin de permettre un apprentissage du piano pour adultes plus efficace. Une nouvelle façon d'apprendre autrement.<br/>
<br/>
        Du coup?<br/>
<br/>
        Dans ces leçons, vous allez apprendre le minimum de solfège et de théorie musicale pour jouer un morceau avec les partitions, puis vous allez surtout bénéficier de tous les trucs que j'ai
        découverts.<br/>
<br/>
        Vous allez donc apprendre mais surtout <strong>comprendre</strong> le piano.
    </p>
<br/>
<p>
<span class="fakeh3">Et est-ce que tout le monde peut y arriver?</span><br/>
<br/>
        La vitesse d'apprentissage dépend surtout du temps que vous consacrez à l'apprentissage et de votre oreille mais rassurez-vous, n'importe qui peut jouer du piano facilement! Si vous êtes
        vraiment motivés, vous y arriverez.<br/>
<br/>
        Et si vous pensez être <a href="https://www.francemusique.fr/savoirs-pratiques/la-musique-enseignee-aux-adultes-35707">trop vieux pour apprendre le piano</a>, alors sachez que l'apprentissage
        d'un instrument de musique permet justement de créer des connexions neuronales qui compensent le déclin cognitif dû au vieillissement. <strong>Alors plus d'excuses!</strong>
</p>

<a href="http://www.pianofacile.com/le-clavier" style="text-decoration:none;">Aller, je me lance!</a>

</div></div><div class="j-module n j-htmlCode" id="cc-m-7201737311"><div class="hr hrhome" id="programme">
</div></div><div class="j-module n j-htmlCode" id="cc-m-7201738511"><div style="margin:0 auto;width:80%;min-width: 280px;background-color:#f4f4f9;border:1px solid #e1e1eb;padding:10%;box-sizing:border-box;">
<p class="fakeh2" style="color:black;padding-bottom:20px;">
        Quel est le programme du cours?
    </p>
<p>
<span class="fakeh3">Commençons par la première partie...</span>
</p>
<p>
        Pour apprendre le piano sur ce site, il suffit de suivre toutes les leçons et les exercices dans l’ordre. Brique après brique, le savoir se construit. Lors de la première leçon, le concept
        principal enseigné est simple : <a href="/le-clavier">apprendre le nom des notes sur le clavier de piano</a>.<br/>
<br/>
        Quel intérêt?<br/>
<br/>
<img alt="piano clavier touches" src="https://image.jimcdn.com/app/cms/image/transf/none/path/saaf38ec3b868f270/image/ib61f9df798611703/version/1370538333/image.png" style="margin:0 auto;"/><br/>
        Le but est de pouvoir nommer chaque touche blanche du piano. C’est une étape indispensable afin de pouvoir ensuite facilement passer aux étapes suivantes. En effet, avant d’apprendre une
        langue, on apprend l’alphabet. Ici c’est pareil, <strong>à la première leçon, on apprend les notes sur le clavier</strong>. Vous pourrez alors dire « cette touche c’est un sol », « et
        celle-ci un ré ». Pour cela, il vous sera indispensable de faire un petit effort de mémorisation pour vous rappeler de la suite de note suivante : <em>do, ré, mi, fa, sol, la et si</em>. Mais
        avec un peu de chance, cette connaissance ne fera que ressurgir du fond de votre mémoire de vos cours de musique à l’école. Vous vous rappelez? La flûte à bec ou le xylophone?<br/>
<br/>
        Et ensuite?<br/>
<br/>
        Lorsqu’on commence le piano, on n’a pas forcément d’instrument à disposition. Une leçon bonus arrive à ce moment dans le programme pour vous présenter les différentes possibilités que vous
        avez parmi le très large choix qui est proposé sur Internet et dans les magasins d’instruments de musique. <strong>Un synthétiseur ou un clavier maître ? Un piano droit ou un piano numérique
        ?</strong> Il n’y a pas de réponse toute faite à ces questions. Chaque instrument a ses avantages et ses inconvénients qui sont présentés points après points, pas à pas. Vous saurez ensuite,
        en fonction également de votre budget et de vos attentes, vers quel instrument se tourner.<br/>
<br/>
        Vous voyez?<br/>
<br/>
        Ensuite on enchaine avec la <a href="/partition">lecture d’une partition simple</a> qui présente une mélodie facile. Vous apprendrez alors ce qu’est une portée et comment les notes sont
        présentées. C’est à ce moment qu’on va parler de <strong>clé de sol</strong>. En gros, vous verrez comment on peut écrire la musique de façon plus compacte et complète que de simplement
        écrire « <em>do, mi, la, sol, si, ré</em> » sur un bout de papier. <strong>Vous apprendrez à lire votre première partition</strong>.<br/>
<br/>
<img alt="partition clé de sol" src="https://image.jimcdn.com/app/cms/image/transf/none/path/s9a5e96a10a799cfa/image/ifd00b4287fbcdf64/version/1518367386/image.png" style="margin:0 auto;"/><br/>
        Cette connaissance sera tout de suite utilisée lors de l’exercice pratique de la leçon où vous apprendrez un nouveau petit morceau à l’aide pour la première fois de la partition. Vous pouvez,
        pour vous aider au début, télécharger la partition avec le nom des notes déjà indiqué dessus.<br/>
<br/>
        Un des premiers défis lors de l’apprentissage du piano est de <strong>bien positionner ses mains</strong> et son corps par rapport au piano. En effet, une fois en face du clavier, on peut
        être facilement impressionné par les 88 touches du piano. Avec seulement 10 doigts <em>(pour la plupart d’entre nous)</em>, il parait presque impossible de pouvoir jouer simplement sans se
        tordre la main dans tous les sens. <strong>Pourtant c’est bien possible.</strong> Grâce à quelques conseils, vous verrez <span class="fakeh3">comment positionner ses mains</span> de sorte de
        pouvoir jouer de façon confortable sans trop de tensions. Attendez, ce n’est pas tout ! Si vous êtes coincés et que vous ne savez pas comment utiliser vos doigts lors des exercices pratiques,
        alors <em>vous pouvez simplement regarder sur la partition le doigté utilisé</em>. En effet, au-dessus de chaque note est placé un chiffre de 1 à 5 qui correspond aux doigts de la main.<br/>
<br/>
        Facile n’est-ce pas? Est-ce que ça ce complique ensuite?<br/>
<br/>
        Quand on commence à apprendre le piano, il n’est pas toujours simple de savoir comment s’y prendre pour apprendre un nouveau morceau ni quelles ressources utiliser. <strong>« Bin, pour
        apprendre un morceau, il faut juste une partition ! »</strong> allez-vous me dire… <strong>Et bien pas forcément</strong>. D’abord, il existe plusieurs type de partition et certaines
        partitions ne sont pas vraiment adaptées à vos besoins. Il faut bien faire la différence entre une partition de piano solo et d’accompagnement par exemple… Cependant, la partition n’est de
        loin pas le seul moyen d’apprendre le piano. On trouve de plus en plus de tutoriels <em>(dit « tutos »)</em> sur YouTube par exemple. Ou alors, si on a un sens musical développé, on peut
        carrément tenter le jeu à l’oreille. Bref, voilà un aperçu des sujets discutés durant le cours de piano PianoFacile.<br/>
<br/>
<img alt="tutoriels apprendre le piano" src="https://image.jimcdn.com/app/cms/image/transf/none/path/s9a5e96a10a799cfa/image/i5606965674835b2b/version/1467660652/image.png" style="margin:0 auto;"/><br/>
        Une fois arrivé à cette étape du cours, on commence les choses sérieuses car on part sur la <strong>lecture de partition un peu plus évoluée</strong>, c’est-à-dire qu’on ne parle plus d’une
        simple mélodie d’une note après l’autre (comme Frère Jacques par exemple), mais plutôt d’accords, c’est-à-dire <a href="/accords-simples">jouer plusieurs notes en même temps</a>. Et vous
        allez le voir, ça fait toute la différence. Mais rassurez-vous, il n’y aura pas beaucoup de théorie supplémentaire à lire pour comprendre comment on présente les accords sur une partition.
        Assez rapidement vous sauterez directement à l’exercice pratique de la leçon et testerez vos nouvelles connaissances avec votre premier morceau avec des accords.<br/>
<br/>
<span class="fakeh3">Ensuite vous ferez face à un mur.</span><br/>
<br/>
        Sérieux ? Un mur, carrément ?<br/>
<br/>
        C’est l’étape qui est, à mon avis, la plus difficile à surmonter lors de l’apprentissage du piano : <a href="/deuxieme-main">jouer avec les deux mains</a>. Un peu comme lorsqu’on apprend le
        vélo, on commence par les petites roues, puis quand on les enlève, on a l’impression de ne plus savoir rouler et de devoir tout recommencer. Ici c’est un peu le cas, mais conservez toute
        votre énergie et votre motivation car, une fois cette étape derrière vous, vous avez fait le plus dur et vous pourrez ensuite <strong>jouer déjà une large palette de morceau de difficulté
        normale</strong> pour un pianiste amateur.<br/>
<br/>
        A ce stade du cours, on fera un petit détour vers le <a href="/pedale">pédalier du piano</a>. Vous ne vous êtes jamais demandé <strong>à quoi servent les trois pédales du piano ?</strong> La
        plus importante est celle de droite, peut-être que vous la connaissez déjà ? On verra alors quel est l’effet de chaque pédale et surtout comment les utiliser. Vous verrez qu’en maitrisant la
        pédale principale <em>(appelée pédale de sustain ou pédale forte)</em> vous apprendrez à jouer en liant les notes ensemble. Ainsi votre jeu sonnera moins saccadé et plus harmonieux.<br/>
<br/>
        Ensuite vient une des dernières étapes avant la fin de la première partie du cours : la <a href="/alterations">lecture des altérations sur la partition</a>. C’est quoi ça ? Et bien à partir
        de ce moment, vous apprendrez à utiliser les touches noires du piano. Vous verrez ce qu’est un bémol ou un dièse. Vous verrez qu’<strong>un dièse n’est pas seulement utile sur
        Twitter</strong> et qu’il a une utilité plus marquée dans la musique ;-)<br/>
<br/>
<img alt="bémols" src="https://image.jimcdn.com/app/cms/image/transf/none/path/s9a5e96a10a799cfa/image/i8c8117068caade9f/version/1518367803/image.png" style="margin:0 auto;"/><br/>
        Dans cette partie vous verrez aussi comment on transcrit le <a href="/rythme">rythme d’un morceau sur une partition</a>. <em>On apprendra alors ce qu’est une ronde, une blanche, une noire,
        une croche et une double croche par exemple.</em> Et ainsi se terminera la première partie du cours.<br/>
<br/>
        C’est déjà fini ? Non, <strong>c’est là que ça commence à être vraiment intéressant</strong>.<br/>
<br/>
        Et c’est surtout cette partie du cours qui est unique. Et vous allez voir pourquoi:<br/>
<br/>
<span class="fakeh3">Deuxième (et dernière) partie du cours</span><br/>
<br/>
        En effet, la première partie du cours est finalement assez banale. Les autres méthodes présentent également les mêmes concepts. Apprendre à lire une partition est ce que veulent savoir la
        plupart des débutants au piano et c’est à ça que sert cette première partie. Pourtant, si le cours s’arrêtait là, vous seriez incapable de comprendre ce que vous jouez, <strong>incapable de
        se détacher des partitions</strong> et du coup incapable d’improviser ou de composer. C’est pourtant un tel plaisir de voir un piano dans une gare ou dans un bar et pouvoir s’y assoir et
        improviser sans votre cahier de partition avec vous. <em>Vous vous imaginez ?</em> Et bien c’est justement l’objectif de la deuxième moitié du cours. C’est dans cette partie que vous vous
        direz plusieurs fois « Ahhh ! C’est pour ça qu’on fait ça ! ».<br/>
<br/>
        On commencera déjà par comprendre <a href="/transposition-principe">comment fonctionnent les gammes</a> et pourquoi certains morceaux contiennent beaucoup de bémols ou de dièses alors que
        d’autre n’en ont pas du tout. Vous verrez comment <strong>transformer un morceau à l’apparence difficile en un morceau plus facile</strong>. En effet, la plupart des gens pensent que
        lorsqu’on joue au piano, on utilise toutes les touches du clavier. Or c’est faux. Parmi les 12 touches uniques du piano, on n’en utilise que 7 (la plupart du temps). Comprendre cet aspect
        simplifie beaucoup la compréhension de la structure des morceaux de musique.<br/>
<br/>
        Une fois le principe des gammes compris, on verra ensemble <a href="/famille-accords">comment on construit un accord</a>. Et aussi, comment on imbrique la mélodie et l’accord ensemble. Aussi,
        suivant le type d’accord utilisé, la partie qui se joue avec la main gauche est automatiquement déterminée. Cela veut dire que <strong>si je vous donne un accord avec la main droite, vous
        savez exactement quoi faire avec votre main gauche</strong>. Comprendre cela permet également de minimiser les informations à retenir lorsque vous voulez apprendre par cœur ce que vous jouez.
        Car, il est tout à fait possible de réduire une série de 8 touches jouées d’un coup en une seule information à retenir. Cette compression simplifie la musique de façon très importante.<br/>
<br/>
        Pour tester ces nouveaux concepts, on prendra l’exemple de <a href="cas-beatles">Let it Be des Beatles</a> et on décortiquera le morceau. Vous verrez, on y retrouve les structures et les
        accords qui sont présentés dans le cours.<br/>
<br/>
        Pour terminer le cours en apothéose, les dernières leçons viserons le Graal ultime : <strong>savoir composer ses propres morceaux</strong> au piano. Qui n’a pas rêvé d’inventer de la musique
        lui-même ? Et bien c’est plus facile que vous le pensez. S’il vous est déjà arrivé de chanter une mélodie qui n’existe absolument pas sous la douche, alors vous avez déjà fait la moitié du
        chemin. Ces dernières leçons présenteront la structure d’un morceau et comment on peut, à partir d’un squelette simple, choisi au hasard, ajouter les accords et la mélodie pour créer un
        morceau compact et cohérent. <em>Et c’est ainsi que se terminera le cours</em>.
    </p>

</p></div><div class="j-module n j-header" id="cc-m-7249182111"><h2 class="" id="cc-m-header-7249182111">L'histoire des notes de musique</h2></div><div class="j-module n j-hr" id="cc-m-7249180811"> <div class="hr"></div>
</div><div class="j-module n j-htmlCode" id="cc-m-7249181711"><p style="font-weight:bold;">
    Par Lauren, de <a href="http://coursdesolfegeetpiano.fr/">Cours de solfège et piano</a>
</p>
<p style="font-style:italic;">
    Publié le 11 juin 2018
</p></div><div class="j-module n j-text" id="cc-m-7249182211"><div style="margin-left: 3%; border-left: 2px solid #f0f0e9; padding-left: 3%;">
<p>
<strong>Do, Ré, Mi, Fa, Sol, La, Si... </strong>Ces sept notes de musique ont marqué notre apprentissage du piano et il ne se passe pas un jour sans que nous ne soyons confrontés à elles
        sur nos partitions ou sur notre clavier. Mais d'où viennent-elles ? Pourquoi les a-t-on appelées ainsi ? Quelle est leur histoire ? C'est ce que je vous propose de découvrir dans cet article.
    </p>
<p>
         
    </p>
<p class="fakeh3">
        Un peu d'Histoire: avant les notes, il y avait quoi ?
    </p>
<p>
        Avant les notes de musique, il n'existait pas de vrais repères sur la partition, donc pas de quoi reconnaître en un instant la différence entre un Si et un Mi.
    </p>
<p>
        On savait, bien évidemment, que les sons étaient différents, que la hauteur variait et qu'un Si était plus haut qu'un Do. Mais on ne les avait, jusqu'alors, que matérialisés sous forme de
        traits. Aucun nom n'avait été donné à ces différentes hauteurs.
    </p>
<p>
         
    </p>
<p class="fakeh3">
        Guido d'Arezzo : le fondateur des sept notes
    </p>
<p>
        C'est le moine italien Guido d'Arezzo qui, au XIe siècle, a l'idée de donner des noms spécifiques aux différentes hauteurs que l'on chante. Il serait plus facile pour le clergé de se repérer
        et de savoir quelle hauteur jouer à un moment donné.
    </p>
<p>
         
    </p>
<p class="fakeh3">
        L'Hymne à Saint Jean-Baptiste
    </p>
<p>
        Pourquoi le moine Guido d'Arezzo a-t-il choisi d'appeler les notes Do, Ré, Mi, Fa, Sol, La et Si, et non Lo, Sé, Vi, Ma, Dol, Na et Pi?
    </p>
<p>
        C'est que le nom de ces sept notes n'est pas dû au hasard. Toutes proviennent d'un chant grégorien connu du clergé au Moyen-Âge : il s'agit de l'Hymne à Saint Jean-Baptiste. Les notes de ce
        chant étaient présentées sous forme de petits carrés.
    </p>
<p>
         
    </p>
<p>
        Voici le chant en question: <em>“Utqueant laxis, Resonare fibris, Mira gestorum, Famuli tuorum, Solve polluti, Labii reatum, Sancte Joannes”.</em>
</p>
<p>
         
    </p>
</div></div><div class="j-module n j-imageSubtitle" id="cc-m-7249182911"><figure class="cc-imagewrapper cc-m-image-align-3">

</div><div class="j-module n j-text" id="cc-m-7249182311"><div style="margin-left: 3%; border-left: 2px solid #f0f0e9; padding-left: 3%;">
<p class="fakeh3">
         
    </p>
<p class="fakeh3">
        Do, Ré, Mi, Fa, Sol, La, Si: pourquoi?
    </p>
<p>
        Guido d'Arezzo a eu l'idée de préserver le début de chaque mot du chant pour en faire un nom de notes. C'est ainsi que les sept notes reprennent les abréviations des 7 expressions suivantes:
    </p>
<ol>
<li>Ut pour <em><strong>Ut</strong>queant laxis</em>
</li>
<li>Ré pour <em><strong>Re</strong>sonare fibris</em>
</li>
<li>Mi pour <em><strong>Mi</strong>ra gestorum</em>
</li>
<li>Fa pour <em><strong>Fa</strong>muli tuorum</em>
</li>
<li>Sol pour <em><strong>Sol</strong>ve polluti</em>
</li>
<li>La pour <em><strong>La</strong>bii reatum</em>... et le Si?
        </li>
<li>Si pour <em><strong>Sa</strong>ncte Joannes</em>?
        </li>
</ol>
<p>
        En réalité, les notes de musique Do et Si ont été nommées ainsi bien plus tard. Ce n'est donc pas Guido d'Arezzo qui est à l'origine du nom de ces deux notes. On lui doit seulement le Ut qui
        est l'ancienne appelation du Do.
    </p>
<p>
         
    </p>
<p class="fakeh3">
        Le Do et le Si: deux notes particulières
    </p>
<p>
        Si vous avez bien suivi, le Do n'existait pas dans le chant grégorien d'origine. Il s'agissait d'une autre note : le Ut de "Utqueant laxis". Ce Ut a donné la clé d'Ut, utilisée par d'autres
        instrumentistes, tels que les violonistes ou les guitaristes dans leurs partitions.
    </p>
<p>
         
    </p>
<p>
        La clé d'ut ou la note Ut n'existe pas au piano. Elle est remplacée par la note Do au sous l'impulsion du compositeur italien Giovanni Bononcini en 1673.
    </p>
<p>
         
    </p>
<p>
        La note Si, quant à elle, provient du "Sancte Joannes" mais n'est appelé comme cela que depuis le XVIe siècle. Le SI est la fusion de l'initiale Sancte et Joannes, que l'on écrit aussi
        Ioannes : d'où le SI. Cette note a été mise en place peu de temps avant Bononcini, grâce au moine Anselme de Flandres.
    </p>
<p>
         
    </p>
