<div class="col-md-12 col-lg-6">
<div class="desc">
<h1>MCreator Minecraft Mod Maker</h1>
<p>
                        Using MCreator mod generator, you can make Minecraft modifications without a single line of
                        code. Although MCreator is a complete IDE, anyone can use it without prior programming
                        knowledge.
                        MCreator is a good tool to learn Minecraft computer programming and to learn basic concepts of
                        software programming.
                    </p>
<p>
                        Design your mods using forms, wizards, tooltips and other elements of the interface that ease
                        development of your mod idea.
                    </p>
</div>
</div>
<div class="col-md-12 col-lg-6">
<a class="fagallery cboxElement" href="/image/frontimages/full/aboutf1.png" title="Create mods without code">

</a>
</div>
</div>
</div>
<div class="frow rdesc il">
<div class="container">
<div class="col-md-12 col-lg-6 col-lg-push-6">
<div class="desc">
<h2>Packed with features and tools</h2>
<p>
                        We developed tools such as texture maker that allows you to create textures in seconds thanks to
                        the
                        presets included.
                        The animation maker allows you to create animated textures that can be created from templates,
                        GIFs
                        or custom images.
                    </p>
<p>
                        Integrated resource browser allows you to easily manage your sounds, textures, models and other
                        assets of your mod.
                    </p>
</div>
</div>
<div class="col-md-12 col-lg-6 col-lg-pull-6">
<a class="fagallery cboxElement" href="/image/frontimages/full/aboutf2.png" title="Make mods using familiar tools">

</a>
</div>
</div>
</div>
<div class="frow rdesc ir">
<div class="container">
<div class="col-md-12 col-lg-6">
<div class="desc">
<h2>Your imagination is the limit</h2>
<p>
                        Using MCreator, you can do virtually anything. From a basic block to a dimension that involves
                        custom biomes with mobs that do whatever you wish by customising their AI. Make the Minecraft
                        game
                        the way you want!
                    </p>
<p>
                        You can create anything from a simple ore extension mod to advanced technology mod that includes
                        a
                        custom energy system. MCreator offers ways to make simple mods and also create customized mods
                        with custom code. This makes it ideas for Minecraft summer camps and a great tool for kids to
                        learn
                        programming while having fun.
                    </p>
</div>
</div>
<div class="col-md-12 col-lg-6">
<a class="fagallery cboxElement" href="/image/frontimages/full/aboutf3.png" title="Your imagination is the limit">
<img alt="Your imagination is the limit" class="center-block img-responsive" src="/image/frontimages/fronta3.png"/>
</a>
</div>
</div>
</div>
<div class="frow rdesc il">
<div class="container">
<div class="col-md-12 col-lg-6 col-lg-push-6">
<div class="desc">
<h2>Integrated code editor</h2>
<p>
                        The code editor implements syntax highlighter, advanced autocomplete and the tools that every
                        code
                        editor has. In addition to that, you can inspect Minecraft's and Minecraft Forge's source code
                        from
                        within the editor.
                    </p>
<p>
                        The code editor also has an import organizer and code templates that speed up the process of
                        programming custom mod code.
                    </p>
</div>
</div>
<div class="col-md-12 col-lg-6 col-lg-pull-6">
<a class="fagallery cboxElement" href="/image/frontimages/full/aboutf4.png" title="Integrated code editor">
<img alt="Integrated code editor" class="center-block img-responsive" src="/image/frontimages/fronta4.png"/>
</a>
</div>
</div>
</div>
<div class="frow rdesc ir last">
<div class="container">
<div class="col-md-12 col-lg-6">
<div class="desc">
<h2>Test and deploy with ease</h2>
<p>
                        MCreator has a built-in test environment for both Minecraft client and server, which makes it
                        possible to test your mod during the development process.
                    </p>
<p>
                        After you are complete with the development, you can export your mod to a valid mod file which
                        can
                        be installed by any Minecraft user.
                    </p>
</div>
</div>
<div class="col-md-12 col-lg-6">
<a class="fagallery cboxElement" href="/image/frontimages/full/aboutf5.png" title="Test and deploy with ease">
