                // Find the param with regex
                // Grab the first character in the returned string (should be ? or &)
                // Replace our href string with our new value, passing on the name and delimeter

                var matches = re.exec(string);
                var newString;

                if (matches === null) {

<h1 style="text-align: center;">What is BREEAM?</h1>
<p style="text-align: center;"><strong>BREEAM is the world’s leading sustainability assessment method for <a href="https://breeam.com/discover/technical-standards/communities/">masterplanning</a> projects, <a href="https://breeam.com/discover/technical-standards/infrastructure/">infrastructure</a> and <a href="https://www.breeam.com/discover/technical-standards/">buildings</a>. It recognises and reflects the value in higher performing assets across the built environment lifecycle, from <a href="https://breeam.com/discover/technical-standards/newconstruction/">new construction</a> to <a href="https://breeam.com/discover/technical-standards/breeam-in-use/">in-use</a> and <a href="https://breeam.com/discover/technical-standards/refurbishment-and-fit-out/">refurbishment</a>.</strong></p>
<p style="text-align: center;">BREEAM does this through third party certification of the assessment of an asset’s environmental, social and economic sustainability performance, using standards developed by BRE. This means BREEAM rated developments are more sustainable environments that enhance the well-being of the people who live and work in them, help protect natural resources and make for more attractive property investments.</p>
<p style="text-align: center;">
