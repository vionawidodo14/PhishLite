<h2>BIENVENIDO A EDITORIAL SALVAT</h2>
<p>Editorial Salvat, fundada en Barcelona en 1869, forma parte de la multinacional francesa HACHETTE LIVRE, y  está presente en los países de habla hispana y portuguesa: España, Portugal y Latinoamérica (Brasil, Argentina, México, Chile, Perú). </p>
<p>Editorial Salvat lleva más de medio siglo ofreciendo en el quiosco productos editoriales de calidad. Un catálogo con productos enfocados a  nuevas tendencias y a intereses particulares de los lectores concentrados en los segmentos infantil, coleccionismo masculino y femenino, coleccionables de figuras, modelismo, cómics y libros.</p>

                    function getCookie(cname) {
                        var name = cname + "=";
                        var ca = document.cookie.split(';');
                        for (var i = 0; i < ca.length; i++) {
                            var c = ca[i];
                            while (c.charAt(0) == ' ') c = c.substring(1);
                            if (c.indexOf(name) == 0)
                                return c.substring(name.length, c.length);
                        }
                        return "";
                    }
