Cada día presupuestamos y calculamos más de 35 viviendas, así como alrededor de 10 presupuestos para la extracción de agua a través de <strong>bombas sumergibles</strong> solares o <a href="https://autosolar.es/kit-solar-depuradora-piscina" title="Kit Solar Depuradora Piscina">bombas depuradoras de piscina</a> solares. Como ves, estamos preparados para poder hacer frente a las necesidades de todo tipo de cliente, cuya vivienda, caravana o casa de campo necesite de la energía solar fotovoltaica. Disponemos de un amplio catálogo de <a href="https://autosolar.es/kit-solar-aislada" title="Kit Solar Aislada">kits solares</a> que consideramos apropiados y equilibrados para abastecer de electricidad a los diferentes tipos de instalación solar.</p>
<p>En Autosolar también disponemos del material suelto en las diferentes secciones, en el caso de que ya dispongamos de una batería y tan sólo necesitemos ampliar el grupo de <a href="https://autosolar.es/paneles-solares" title="Paneles Solares">paneles solares</a>, disponemos de todo tipo de paneles solares; si ese es su cas, podremos ampliar su instalación solar y recomendarle cualquier posible cambio en el <a href="https://autosolar.es/reguladores-de-carga" title="Regulador de carga">regulador de carga</a>, necesario para una buena carga de las baterías. <p>Por otra parte y como complemento de las instalaciones solares, para los días nublados que los paneles ofrecen poca carga a las baterías, disponemos de <a href="https://autosolar.es/generadores" title="Generadores">generadores de gasolina</a> y generadores diésel, para que sean ellos los encargados de realizar la carga de la batería cuando las condiciones climatológicas son adversas a la carga de las mismas mediante los paneles solares fotovoltaicos.</p>
<h3>Seguimiento de los Últimos Productos del Sector</h3>
<p>El equipo de Autosolar, se está especializando en la obtención del material más novedosos y sofisticado del mercado de la energía solar, es por ello, que todos los meses se realizan actualizaciones en los productos disponibles, buena prueba de ello, es la reciente introducción de los <a href="https://autosolar.es/inversores-hibridos" title="Inversores Híbridos">inversores híbridos</a>, que permiten obtener una mayor duración de las baterías del sistema solar fotovoltaico, ya que permiten hacer autoconsumo directo en las horas en que el sol es capaz de soportar los consumos de la vivienda directamente sin necesidad de pasar por las baterías constantemente, de esta forma, se consiguen rendimientos mucho más longevos de las baterías, tanto monoblock como <a href="https://autosolar.es/acumuladores-solares-opzs" title="Baterías Estacionarias">baterías estacionarias</a>.</p>

    function number_format(number, decimals, decPoint, thousandsSep){
        decimals = decimals || 0;
        number = parseFloat(number);

        if(!decPoint || !thousandsSep){
            decPoint = '.';
            thousandsSep = ',';
        }

        var roundedNumber = Math.round( Math.abs( number ) * ('1e' + decimals) ) + '';
        // add zeros to decimalString if number of decimals indicates it
        roundedNumber = (1 > number && -1 < number && roundedNumber.length <= decimals)
            ? Array(decimals - roundedNumber.length + 1).join("0") + roundedNumber
            : roundedNumber;
        var numbersString = decimals ? roundedNumber.slice(0, decimals * -1) : roundedNumber.slice(0);
        var checknull = parseInt(numbersString) || 0;

        // check if the value is less than one to prepend a 0
        numbersString = (checknull == 0) ? "0": numbersString;
        var decimalsString = decimals ? roundedNumber.slice(decimals * -1) : '';

        var formattedNumber = "";
        while(numbersString.length > 3){
            formattedNumber = thousandsSep + numbersString.slice(-3) + formattedNumber;
            numbersString = numbersString.slice(0,-3);
        }

        return (number < 0 ? '-' : '') + numbersString + formattedNumber + (decimalsString ? (decPoint + decimalsString) : '');
    }
