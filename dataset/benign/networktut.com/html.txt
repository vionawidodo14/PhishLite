<h1><a class="title" href="https://www.networktut.com/a-guide-for-the-tshoot-exam" rel="bookmark">A guide for the TSHOOT Exam</a></h1>
<div class="info">
<span class="date">March 7th, 2019</span>
<span class="categories_above">in <a href="https://www.networktut.com/category/tshoot/guide" rel="category tag">Guide</a></span>
<!-- <span class="author"></span> -->
<!-- <span class="comments"><a href="https://www.networktut.com/a-guide-for-the-tshoot-exam#comments">849 comments</a></span> -->
<div class="fixed"></div>
</div>
<div class="content">
<p>For the TSHOOTv2 exam we will encounter:</p>
<p>+ <a href="https://www.networktut.com/category/tshoot-v2/simlets" rel="noopener noreferrer" target="_blank">2 Simlets</a> (small troubleshooting sim)<br/>
+ <a href="https://www.networktut.com/multiple-choice-questions" rel="noopener noreferrer" target="_blank">Multiple Choice Questions &amp; Drag Drop Questions</a><br/>
+ 12 Troubleshooting Tickets (check them at the right-side menu)</p>
<p>Notice that in the exam, the tickets are randomly given so the best way to troubleshooting is to try pinging to all the devices from nearest to farthest from the client until you don’t receive the replies.</p>
<p>In each ticket you will have to answer three types of questions:</p>
<p>+ Which device causes problem<br/>
+ Which technology is used<br/>
+ How to fix it</p>
<p>One more thing to remember: you can only use “show” and “ping” commands to find out the problems and you are not allowed to make any changes in the configuration. In fact, in the exam you can not enter the global configuration mode!</p>
<p>Screenshots for your reference:</p>
<p style="text-align: center;"><img alt="Layer2_3_Topology_small.jpg" height="438" src="https://www.networktut.com/images/TSHOOT/Labsim/Layer2_3_Topology_small.jpg" width="600"/></p>
<p> </p>
<p style="text-align: center;"><img alt="IPv4Layer3Topology_networktut.com_small.jpg" src="https://www.networktut.com/images/TSHOOT/Labsim/IPv4Layer3Topology_networktut.com_small.jpg"/></p>
<p style="text-align: left;">(Please visit <a href="https://www.networktut.com/share-your-tshoot-v2-0-experience" rel="noopener noreferrer" target="_blank">Share your TSHOOT v2.0 Experience </a> for bigger images)</p>
<p style="text-align: left;">Also you can find more information about TSHOOT exam in <a href="https://www.networktut.com/tshoot-faqs-tips">TSHOOT FAQs and Tips</a>.</p>

<h1><a class="title" href="https://www.networktut.com/practice-tshoot-tickets-with-packet-tracer" rel="bookmark">Practice TSHOOT Tickets with Packet Tracer &amp; EVE-NG</a></h1>
<div class="info">
<span class="date">March 6th, 2019</span>
<span class="categories_above">in <a href="https://www.networktut.com/category/tshoot/guide" rel="category tag">Guide</a></span>
<!-- <span class="author"></span> -->
<!-- <span class="comments"><a href="https://www.networktut.com/practice-tshoot-tickets-with-packet-tracer#comments">485 comments</a></span> -->
<div class="fixed"></div>
</div>
<div class="content">
<p>Special thanks to <span class="pinkandbold">Buddy </span>who sent us these files. Please say thanks to him. Now you can practice most TSHOOT Tickets with Packet Tracer v6.1. Please download all the tickets in one file here: <a href="https://www.networktut.com/download/Cisco_PT_6_1_TSHOOT_Package.zip" rel="noopener" target="_blank">https://www.networktut.com/download/Cisco_PT_6_1_TSHOOT_Package.zip</a>. All the guides were included in that file.</p>
<p>Note: Please use at least the final Packet Tracer v6.1 (STUDENT Release) or above to open them. Below is a screenshot of the pkt files:</p>
<p> <img alt="TSHOOT_Tickets_PT61.jpg" height="429" src="https://www.networktut.com/images/TSHOOT/Labsim/TSHOOT_Tickets_PT61.jpg" width="829"/></p>
<p>*********************<br/>
From Buddy:</p>
<p>Please notice: It’s mainly all the Packet Tracer TSHOOT L2 based trouble tickets, that needs to be reconfigured with STATIC IP addresses at the PC Clients by today</p>
<p>Thus when reconfiguring the two PC Clients with static IP addresses, please remember to also EXCLUDE the two Client IP addresses (.3 and .4) within the DHCP Pool at DHCP Server R4, at the same time.</p>
<p>****************************</p>
<p>Special thanks to <span class="pinkandbold">Marcus</span> for creating the TSHOOT topology with EVE-NG network emulator (currently this is one topology file with working configuration, not the tickets). You can download this file here: <a href="https://www.networktut.com/download/TShoot_300-135-TT_EVE-NG.zip" rel="noopener" target="_blank">https://www.networktut.com/download/TShoot_300-135-TT_EVE-NG.zip</a>. Below is screenshot of the EVE-NG file:</p>
<p><img alt="TSHOOT_Working_topology_EVE-NG.jpg" class="aligncenter" height="718" src="https://www.networktut.com/images/TSHOOT/Labsim/TSHOOT_Working_topology_EVE-NG.jpg" width="847"/></p>
<p><strong>Note:</strong> <br/>
+ <a href="https://www.eve-ng.net/" rel="noopener" target="_blank">EVE-NG emulator</a> must be installed to open this file.<br/>
+ This file uses these IOL images (but you may use other IOL images): <br/>
 – i86bi_LinuxL2-AdvEnterpriseK9-M_152_May_2018.bin<br/>
 – i86bi_LinuxL3-AdvEnterpriseK9-M2_157_3_May_2018.bin<br/>
+ Importing steps:<br/>
1. click ACTIONS/Import external labs<br/>
2. select target lab but don’t unzip it then import<br/>
3. BEFORE starting any nodes on ASW1,ASW2,DSW1,DSW2 select the Layer2 IOL image that is present in your eve.<br/>
4. click More actions/Start all nodes</p>
