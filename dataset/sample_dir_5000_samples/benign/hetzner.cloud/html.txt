<h2 class="text-center">Frequently Asked Questions</h2>
<div class="container-list-faqs">
<div class="row">
<div class="col-lg-12 col-md-12 col-sm-12 col-xs-12">
<ul class="list-unstyled list-faqs">
<li>
<strong aria-expanded="true" class="faq-question" data-target="#faq-8659" data-toggle="collapse"><i class="fa fa-chevron-right"></i> How do you bill your servers?</strong>
<div class="collapse" id="faq-8659">
<div class="faq-answer"><p>Servers have both a monthly price cap and a price per hour. Your server's bill will never exceed its monthly price cap. If you delete your Cloud Server before the end of the billing month, you will only be billed the hourly rate. We will bill you for each cloud server until you choose to delete them. Even if you aren't actively using your server, we will bill you for it.</p></div>
</div>
</li>
<li>
<strong aria-expanded="true" class="faq-question" data-target="#faq-8660" data-toggle="collapse"><i class="fa fa-chevron-right"></i> Do you bill servers that are off?</strong>
<div class="collapse" id="faq-8660">
<div class="faq-answer"><p>Yes. All servers that have finished their creation process will be billed until they are deleted, regardless of their state.</p><p>This is because, internally, we allocate full resources to servers regardless of their power state. And it enables rapid startup and boot times for you, the customer.</p></div>
</div>
</li>
<li>
<strong aria-expanded="true" class="faq-question" data-target="#faq-8661" data-toggle="collapse"><i class="fa fa-chevron-right"></i> Is there any way to get a custom configuration?</strong>
<div class="collapse" id="faq-8661">
<div class="faq-answer"><p>Customized virtual servers (additional RAM, additional/larger drives etc.) are not currently available.</p></div>
</div>
</li>
<li>
<strong aria-expanded="true" class="faq-question" data-target="#faq-8662" data-toggle="collapse"><i class="fa fa-chevron-right"></i> What is the difference between local and ceph disks for servers?</strong>
<div class="collapse" id="faq-8662">
<div class="faq-answer"><p>Servers with local disks keep all data on a local RAID mirror on the host system. They are optimized for high I/O performance and low latency and are especially suited for applications which require fast access to disks with low latency, such as databases.</p><p>Servers with ceph disks store their data on a remote filesystem. Each block is stored on three different servers. They are especially suited for higher availability needs: If the local host hardware fails, we will boot the server on a different machine.</p></div>
</div>
</li>
<li>
<strong aria-expanded="true" class="faq-question" data-target="#faq-8663" data-toggle="collapse"><i class="fa fa-chevron-right"></i> Can I install Windows?</strong>
<div class="collapse" id="faq-8663">
<div class="faq-answer"><p>Right now we are focusing on support for Linux as an operating system. If you wish, you may install Windows on your own, and we have seen successful installations done. However, we will not provide any support for Windows.</p></div>
</div>
</li>
<li>
<strong aria-expanded="true" class="faq-question" data-target="#faq-8664" data-toggle="collapse"><i class="fa fa-chevron-right"></i> Do you plan to add x feature?/Will you add more features?</strong>
<div class="collapse" id="faq-8664">
<div class="faq-answer"><p>We started Hetzner Cloud with the minimal feature set we think is necessary to enter the market. However we intend to continually add new features and services. We have designed our internal development methods and systems to allow us to add more features.</p><p>Unfortunately we cannot provide you with a precise roadmap of the things we are working on. However you can stay up to date by following us on Twitter at <a class="link-single-external" href="https://twitter.com/hetzner_online" target="_blank">https://twitter.com/hetzner_online</a></p></div>
</div>
</li>
<li>
<strong aria-expanded="true" class="faq-question" data-target="#faq-8665" data-toggle="collapse"><i class="fa fa-chevron-right"></i> Will you add additional locations in different geographic regions?</strong>
<div class="collapse" id="faq-8665">
<div class="faq-answer"><p>We are actively looking into this option right now.</p></div>
</div>
</li>
<li>
<strong aria-expanded="true" class="faq-question" data-target="#faq-8666" data-toggle="collapse"><i class="fa fa-chevron-right"></i> Is there a library to access Hetzner Cloud from my programming language?</strong>
<div class="collapse" id="faq-8666">
<div class="faq-answer"><p>We currently provide a library for Go as Open Source under <a class="link-single-external" href="https://github.com/hetznercloud/hcloud-go" style="word-break: break-all;" target="_blank">https://github.com/hetznercloud/hcloud-go</a>.</p><p> </p><p>Libraries for other languages are not available at this time. However our API is very easy to use; check out our API documentation at <a class="link-single-external" href="https://docs.hetzner.cloud" target="_blank">https://docs.hetzner.cloud</a></p></div>
</div>
</li>
<li>
<strong aria-expanded="true" class="faq-question" data-target="#faq-12206" data-toggle="collapse"><i class="fa fa-chevron-right"></i> What are the Hetzner Cloud Volumes?</strong>
<div class="collapse" id="faq-12206">
<div class="faq-answer"><p>It is a feature for fast, flexible, and cost-effective (SSD based) block storage which you can attach to your Hetzner Cloud Server.</p></div>
</div>
</li>
<li>
<strong aria-expanded="true" class="faq-question" data-target="#faq-12207" data-toggle="collapse"><i class="fa fa-chevron-right"></i> How does Hetzner Online store the data in volumes?</strong>
<div class="collapse" id="faq-12207">
<div class="faq-answer"><p>Every block of data is stored on three different physical servers (triple replication).</p></div>
</div>
</li>
<li>
<strong aria-expanded="true" class="faq-question" data-target="#faq-13627" data-toggle="collapse"><i class="fa fa-chevron-right"></i> How many servers can I create?</strong>
<div class="collapse" id="faq-13627">
<div class="faq-answer"><p>Each customer has a default limit for the number of Cloud resources that we simultaneously provide. If you would like to increase your limit, you can send a request to our support team by opening a support ticket via Cloud Console. Our team will quickly review your request and, if everything is in order, they will increase your limit.</p></div>
</div>
</li>
