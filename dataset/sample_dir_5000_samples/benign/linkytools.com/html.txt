<span class="dxpc-headerText dx-vam" id="ctl00_ContentPlaceHolderBody_ASPxPopupControl1GetBoth0_PWH-1T">What is a Blog Hop?</span>
</div><b class="dx-clear"></b>
</div><div class="dxpc-contentWrapper">
<div class="dxpc-content" id="ctl00_ContentPlaceHolderBody_ASPxPopupControl1GetBoth0_PWC-1">
<p>
                                                A blog hop is a linky list that is SHARED ON MULTIPLE BLOGS.<br/>
<br/>
                                                When several blogs put the same linky list code on their blog, the exact same 
                                                list appears on each blog.
                                                <br/>
<br/>
                                                Blog visitors can submit their entries on any blog that contains the list. The 
                                                entries will appear on each blog where the list resides.<br/>
<br/>
                                                Blog readers see the same list on each blog, and can "HOP" from blog to blog 
                                                seeing the same list of links to follow: BLOG HOP!<br/>
<br/>
<strong>By designating your linky list as a BLOG HOP, a link will appear below 
                                                your linky list where your blog readers can get the blog hop code for your 
                                                linky.</strong><br/>
<br/>
                                                If you want to do a 'PRIVATE' blog hop, then do NOT check the blog hop checkbox, 
                                                and simply share the code PRIVATELY with the other blog owners.</p>
<p>
<span style="font-weight: bold;">Brent Riggs &amp; Linky Tools create the concept of 
                                                the "blog hop" as it is used on so many blogs today. </span>
<br/>
</p>

<br/><ul>

        your linky code.</li>

        HTML view or mode when you paste it in.</li>
