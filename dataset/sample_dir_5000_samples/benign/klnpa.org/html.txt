<h1 class="entry-title">Keystone Library Network</h1> </header><!-- .entry-header -->
<div class="entry-content">
<p>The <strong>Keystone Library Network</strong> is a consortium of <a href="/klnpa/member-libraries/">academic and research libraries</a>. The network provides members with access to a number of services, which are briefly described below. Images and links in each description lead to pages with more detail.</p>
<p>Information about the network can be found on the <a href="https://www.klnpa.org/about/">About KLN </a>page and details about membership can be found on the<a href="https://www.klnpa.org/membership/"> Membership </a>page. To contact the network staff, please see the <a href="https://www.klnpa.org/contact-hub/">How to Contact </a>page.</p>
<p><a class="has-image" href="https://www.klnpa.org/almaprimo/"><img alt="" class="wp-image-1486 alignleft" height="71" src="https://www.klnpa.org/wp-content/uploads/2017/08/alma2.jpg" width="254"/></a>Ex Libris next-generation integrated library services platform. Read <a href="https://www.klnpa.org/almaprimo/">more details</a> and access <a href="https://www.klnpa.org/primo-library-catalogs/">Primo library catalogs</a>.</p>
<p> </p>
<p><a class="has-image" href="https://www.klnpa.org/rpas/"><img alt="" class="wp-image-1230 alignleft" height="227" src="https://www.klnpa.org/wp-content/uploads/2013/07/remote-patron-authentication.jpg" width="219"/></a></p>
<p> </p>
<p><a href="https://www.klnpa.org/rpas/">Remote Patron Authentication System (RPAS) with Ezproxy</a>  allows you to create direct links to resources including databases, journals, and articles.</p>
<p> </p>
<p> </p>
<p><a class="has-image" href="https://www.klnpa.org/wp-content/uploads/2017/08/aspace_icon.jpg"><img alt="" class="size-full wp-image-1388 alignleft" height="133" src="https://www.klnpa.org/wp-content/uploads/2017/08/aspace_icon.jpg" width="197"/></a></p>
<p>Built for archives by archivists, <a href="https://www.klnpa.org/archives-space/">ArchivesSpace</a> is the open source archives information management application for managing and providing web access to archives, manuscripts, and digital objects.</p>
<p> </p>
<p> </p>
<p><a class="has-image" href="https://www.klnpa.org/islandora/"><img alt="" class="wp-image-1229 alignleft" height="134" src="https://www.klnpa.org/wp-content/uploads/2013/07/islandora.jpg" width="319"/></a> <a href="https://www.klnpa.org/islandora/">Islandora</a> is an open-source software framework designed to help institutions, organizations, and their audiences collaboratively manage and discover digital assets using a best-practices framework.</p>
<p> </p>
<p> </p>
<p><a class="has-image" href="https://www.klnpa.org/contentdm/"><img alt="CONTENTdm logo" class="alignleft wp-image-1228" height="65" src="https://www.klnpa.org/wp-content/uploads/2013/07/contentdm.jpg" width="337"/></a><a href="https://www.klnpa.org/contentdm/">Contentdm</a> is a digital collection management system consisting of a server on which content is stored, a web-based content discovery interface, and tools to upload and manage content.</p>
<p> </p>
