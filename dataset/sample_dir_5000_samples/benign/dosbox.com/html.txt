<td><table cellpadding="0" cellspacing="0" width="100%"><tbody><tr><td align="left" valign="top"><font size="+1">DOSBox 0.74-3 has been released!</font>
<br/>
<br/>A security release for DOSBox 0.74:
<br/><ul><li>Fixed that a very long line inside a bat file would overflow the parsing buffer. (CVE-2019-7165 by Alexandre Bartel)</li><li>Added a basic permission system so that a program running inside DOSBox can't access the contents of /proc (e.g. /proc/self/mem) when / or /proc were (to be) mounted. (CVE-2019-12594 by Alexandre Bartel)</li><li>Several other fixes for out of bounds access and buffer overflows.</li><li>Some fixes to the OpenGL rendering.</li></ul>
<br/>The game compatibility should be identical to 0.74 and 0.74-2.
<br/>It's recommended to use config -securemode when dealing with untrusted files. 
<br/>

<br/>
<br/>A maintenance release for DOSBox 0.74, which solves the following problems:
<br/><ul><li>Windows: Fix auto/max cycles algorithm on Windows 7, which helps with stuttering audio.</li><li>Mac OS X: Bring a 64 bit version and improve performance.</li><li>Linux: Fix the 64bit dynrec cpu core and a lot of compilation problems. Add patches for the WINE Team.</li></ul>
<br/>The game compatibility should be identical to 0.74.
<br/>
<br/><b>We have saved all game fixes for the upcoming 0.75 release, which will enter regression testing soon. This release has been created so you can go back to 0.74-2, in case we happen to break your favourite game in 0.75.</b></td></tr></tbody></table></td></tr></tbody></table></td></tr></tbody></table><br/></td></tr></tbody></table>
