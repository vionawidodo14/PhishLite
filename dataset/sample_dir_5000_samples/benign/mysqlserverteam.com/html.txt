<div class="entry-meta">

<div class="entry-content">

<ul>
<li>Migration to Python 3</li>
<li>Built-in thread reports</li>
<li>Ability to use an external editor</li>
<li>Ability to execute system commands within the shell</li>
<li>Admin API Improvements:
<ul>
<li>New options to log all the SQL used on the different operations</li>
<li>Support for IPv6 in InnoDB Clusters</li>
<li>New function to reset the InnoDB Cluster recovery accounts</li>
</ul>
</li>
<li>General maintenance and bug fixing</li>
</ul>
